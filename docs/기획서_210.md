# 기획서 210: 4대 저격 매트릭스 ✕ 롱/숏 청산 주도 비율(Dominant Liq Ratio) 2차 안전 방화벽 장착 (V6.07)

## 📌 1. 개요 및 배경
- **현상 (양방향 휩쏘 폭발장에서의 불필요한 위험 노이즈 차단):**
  - **폐하의 어명 지침:** *"그러니까 신호는 롱인데, 롱청산이 더 많을 때는 쉬어야 한다 이거지?"*
  - 대규모 변동성 폭발 장세에서 위아래로 롱/숏 포지션이 동시에 터질 때, 신호 방향과 청산 주도 세력이 부합하지 않는 위험한 휩쏘 구간을 100% `NONE`으로 기각하여 폐하의 계좌를 철통 보호합니다.
- **목적:**  
  1. 4대 저격 매트릭스에 **[롱/숏 청산 주도 비율 2차 검증 방화벽]**을 장착합니다.
  2. 신호 조건과 청산 주도 세력이 불일치하는 혼조세 구간에서는 진입을 기각(`NONE`)하고 100% 안전하게 휴식합니다.

## 🎯 2. V6.07 4대 저격 매트릭스 ✕ 청산 주도 비율 2차 방화벽 수식 명세

| 경우의 수 | 1분 지수가중 기울기 (`ema_slope`) | 1분 OI속도 (`oi_delta_1m`) | 청산 주도 비율 2차 검증 수식 | 최종 깃발 방향 | 저격 및 안전 처리 팩트 |
|---|---|---|---|---|---|
| **Case A** | 📉 **`ema_slope < 0`** (하락 중) | 📉 **`oi_delta < 0`** (OI 감소) | **`long_liq >= short_liq`** (롱 청산 주도!) | 🟢 **`LONG`** | **개미 롱 손절 털기 완료 팩트 검증 ➡️ 바닥 LONG 저격!** |
| **Case B** | 📈 **`ema_slope > 0`** (상승 중) | 📉 **`oi_delta < 0`** (OI 감소) | **`short_liq >= long_liq`** (숏 청산 주도!) | 🔴 **`SHORT`** | **개미 숏스퀴즈 털기 완료 팩트 검증 ➡️ 꼭대기 SHORT 저격!** |
| **Case C** | 📈 **`ema_slope > 0`** (상승 중) | 📈 **`oi_delta > 0`** (OI 증가) | **`short_liq >= long_liq`** (숏 청산 돌파!) | 🟢 **`LONG`** | **세력이 숏 청산 먹으며 상승 ➡️ 상승 추세 LONG 탑승!** |
| **Case D** | 📉 **`ema_slope < 0`** (하락 중) | 📈 **`oi_delta > 0`** (OI 증가) | **`long_liq >= short_liq`** (롱 청산 돌파!) | 🔴 **`SHORT`** | **세력이 롱 청산 먹으며 하락 ➡️ 하강 추세 SHORT 탑승!** |
| **불일치** | 위 조건 미달 또는 청산 주도 세력 불일치 시 | | | ⚪️ **`NONE`** | **위험한 휩쏘/혼조세 100% 기각 ➡️ 안전하게 휴식 (NONE)!** |
