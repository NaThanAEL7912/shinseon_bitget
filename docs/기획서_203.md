# 기획서 203: 엑셀 네이티브 유니코드 UTF-16 LE 규격 전면 개편으로 한글/이모지 100% 선명 완치 수술

## 📌 1. 개요 및 원인 분석
- **현상 (엑셀에서 한자 `緑(KST)`, `청 緞치($)`, `타 참柳`로 나오는 현상):**
  - **폐하의 캡처 화면 팩트:** 엑셀 상단 헤더가 `緑(KST)`, `청 緞치($)`, `타 참柳` 등의 한자 및 오역 문자로 인쇄됨.
  - **10000% 정격 팩트 원인 (MS 엑셀 유니코드 해석 엔진 특성):**
    - 마이크로소프트 엑셀은 다국어 한글 및 이모지가 포함된 CSV 파일에 대해 **마이크로소프트 공식 엑셀 유니코드 규격인 UTF-16 LE (Little Endian) 식별자(`\xff\xfe`)**를 가장 완벽하게 오역 없이 읽어 들입니다.
    - 이전 CP949 규격은 특수 기호 및 일부 텍스트 바이트 배열이 엑셀 기본 폰트와 매핑될 때 한자 표 형태로 엉키는 팩트이옵니다.
- **목적:** CSV 기록 엔진을 **마이크로소프트 엑셀 네이티브 유니코드 UTF-16 LE 규격으로 전면 수술**하여, **더블 클릭 즉시 100% 깨끗한 한글(`일시(KST)`)과 🟢LONG/🔴SHORT 이모지가 선명하게 출력**되도록 완치합니다.

## 🛠️ 2. 정공법 완치 수술 상세 명세 (`shinseon_server.py`)

### 2.1. MS 엑셀 네이티브 UTF-16 LE 규격 및 🟢LONG/🔴SHORT 완벽 연동
1. **타점 시그널 100% 원복:**
   - **LONG 시그널:** **`🟢 LONG`** (진한 초록색 이모지)
   - **SHORT 시그널:** **`🔴 SHORT`** (빨간색 이모지)
   - **NONE 시그널:** `NONE`

2. **MS 엑셀 네이티브 UTF-16 LE 바이너리 기록 함수 (`_write_csv`):**
```python
def _write_csv(path, content):
    try:
        os.makedirs(os.path.dirname(path), exist_ok=True)
        header_str = "일시(KST)\t비트코인 시세($)\t1분 누적 청산($)\t1분 롱 청산($)\t1분 숏 청산($)\t청산 임계치($)\t1분 OI 속도(%)\tOI속도 임계치(%)\t타점 시그널\t봇 구동 상태\n"
        bom_utf16 = b'\xff\xfe'
        
        file_exists = os.path.exists(path) and os.path.getsize(path) >= 2
        has_bom = False
        if file_exists:
            with open(path, "rb") as f:
                if f.read(2) == bom_utf16:
                    has_bom = True

        if not file_exists or not has_bom:
            with open(path, "wb") as f:
                f.write(bom_utf16)
                f.write(header_str.encode('utf-16-le'))
                f.write(content.encode('utf-16-le'))
        else:
            with open(path, "ab") as f:
                f.write(content.encode('utf-16-le'))
    except Exception as e:
        logger.error(f"CSV 레코더 쓰기 에러: {e}")
```
