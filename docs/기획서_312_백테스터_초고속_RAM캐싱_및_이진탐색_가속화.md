## 1. 🔍 병목 원인 분석 (왜 백테스트 실행이 늦었는가?)

1. **디스크 I/O 반복 병목:** 백테스트를 실행할 때마다 80MB에 달하는 피클 파일(parsed_session_data.pkl)을 디스크에서 매번 새로 로드함 (~0.8초 소요).
2. **110만 틱 중복 제거 및 정렬 반복:** 8개 세션 버킷을 돌며 1,096,490개 틱을 파싱하고 매번 sort(key=...)를 수행함 (~1.2초 소요).
3. **선형 탐색(O(N)) 날짜 필터링:** 날짜 범위를 자를 때 110만 개 딕셔너리를 일일이 비교함.
