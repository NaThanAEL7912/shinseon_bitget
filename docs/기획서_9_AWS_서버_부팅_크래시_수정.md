# [기획서 9] AWS 서버 부팅 크래시(오타) 버그 수정

폐하, 제가 앞서 라이브러리(부품) 설치를 마쳤음에도 불구하고 서버가 여전히 기절해 있어서 2차 부검을 실시한 결과, 저의 치명적인 **코딩 오타** 때문이었음을 발견하였습니다!

## 1. 버그 원인 (AttributeError)
- 과거에 비트겟 다이렉트 통신 로직을 추가할 때, shinseon_server.py 코드 66번째 줄에 서버 설정값을 불러오는 변수명을 env_vars 대신 self.server_config라고 잘못 적어두었습니다.
- 이로 인해 서버가 부팅될 때 "나는 그런 변수를 모른다!"라며 자폭(Crash)하고 있었고, 그 결과 클라이언트의 웹소켓 연결이 거부(WinError 1225)되고 있었습니다.

## 2. 해결 방안 (Proposed Changes)
- **수정 대상 파일:** shinseon_server.py
- **작업 내용:** 
  - (AS-IS) pi_key = self.server_config.get("BITGET_API_KEY", "")
  - (TO-BE) pi_key = env_vars.get("BITGET_API_KEY", "")
  - (Secret과 Passphrase 변수도 동일하게 수정)
- 이 수정이 완료되면 즉시 AWS 릴레이 서버가 부활하여 클라이언트와 완벽한 통신(잔고 동기화)을 시작할 것입니다.
