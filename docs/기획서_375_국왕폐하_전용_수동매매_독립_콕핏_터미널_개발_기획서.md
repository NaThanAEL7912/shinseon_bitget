## 3. 세부 기능 명세

1. **초경량 가로형 슬림 위젯** :
   - 가로 500px 초슬림 창으로 모니터 우측/좌측 구석이나 웹 브라우저 옆에 찰떡같이 밀착 배치 가능!
   - `📌 항상 위에 표시 (Always on Top)` 체크박스 지원.
2. **🚀 원클릭 초고속 시장가 진입** :
   - 수량(BTC) 원클릭 프리셋 버튼 ➔ `[ 🟢 시장가 롱 ]` / `[ 🔴 시장가 숏 ]` 0.05초 초광속 발주!
3. **🛡️ 원클릭 무위험 본전가드 (BE Shield)** :
   - 클릭 즉시 진입 평단가로 스탑로스를 걸어 **절대 무손실(0원 손실)** 확정!
4. **🔔 3대 AND 찐신호 사운드 알림** :
   - 미장에서 찐 신호 발생 시 "딩동~" 사운드 알림.
5. **🛡️ 2단 안전방패 & 50% 분할청산 & 🚨 비상탈출** :
   - 검증된 리스크 관리 도구 100% 장착.
6. **📊 실시간 본 계정 HUD & 레이더** :
   - 비트겟 본 계정 API 직접 통신으로 평단가, 미실현 손익, 강제 청산가와의 안전거리 실시간 감시.
