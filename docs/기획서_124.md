# ShinSeon Bitget 기획서_124 (실적 전광판 갱신 시점 팩트 규명 및 서버 통계 저장소 철통 보강)

## 📌 개요
마스터 대시보드 상단 전광판에 실적이 $0.00으로 표시된 원인을 팩트 분석하고, **포지션 청산 완료 시 즉시 실적 통계 정격 갱신** 및 **서버 통계 저장소 (`logs/trade_stats_YYYY-MM-DD.json`) 저장 보증 수술**을 집행합니다.

---

## 🔍 [실적 미표기 팩트 규명 리포트]

1. **포지션 진입 중(Open) 상태 팩트:**
   - 캡처 화면 로그 시각(`19:14:14`): `[SHORT 진입 @ 64,849.0] ROE: +2.27% (+0.07 USDT)`로 **현재 포지션이 아직 오픈(진입)되어 진행 중인 상태**입니다.
   - 트레이딩 실적(누적 손익, 금일 손익, 승률)은 포지션이 **익절/손절 청산 체결이 완료(Closed)**되는 순간 손익금과 ROE%가 최종 확정되어 전광판으로 넘어갑니다.

2. **서버 통계 디렉토리 파일 생성 보증 수술:**
   - AWS 서버 내 `STATS_DIR` (`/home/ubuntu/logs/`) 자동 생성 검증 및 예외 처리 강화.
   - 청산 완료 이벤트 발생 즉시 `save_daily_stats` 및 `save_trade_stats_summary`를 거쳐 `EVT_SYNC_STATS`를 브로드캐스트하여 클라이언트 전광판에 0.001초 만에 최신 승률과 손익금이 찍히도록 완공 (V5.24).
