# ShinSeon Bitget 기획서_178 (세션 가드레일 설정 웹서버 수송/저장/실행 및 양방향 신호 완전 이관 완치안)

## 📌 1. 개요 및 폐하의 아키텍처 지시사항

폐하께서 하사해주신 핵심 아키텍처 지시:
> **"이 설정 값(세션별 분할익절 임계값, 본전/버퍼가드, 가드레일 설정)도 웹서버로 전송되어 웹서버에서 영구 보관/처리되어야 하고, 웹서버에서 처리된 실행 신호를 클라이언트 대시보드로 다시 받아서 보여주는 구조가 되어야 한다!"**

대시보드는 오직 **설정 컨트롤러 및 실시간 상태 렌더러(Display Controller)** 역할만 전담하고, 세션 가드레일의 모든 설정 저장, 24시간 감시, 비트겟 API 발주, 텔레그램 발송 및 결과 통보는 **100% AWS 웹서버 단독 중앙집중형 엔진**으로 완벽히 이관/구조 개편합니다.
