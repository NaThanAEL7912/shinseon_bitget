# ShinSeon Bitget 기획서_120

## 📌 개요
장기 가동 시 데이터 비대화를 예방하기 위해 **서버 트레이딩 실적을 날짜별 파일 (`logs/trade_stats_YYYY-MM-DD.json`)로 분리 영구 보관**하고, 클라이언트 데이터 다운로드/동기화 시 **마지막 다운로드 날짜를 체크하여 신규 일별 데이터만 똑똑하게 가져오는 증분 동기화(Incremental Sync) 엔진**을 완공합니다.
