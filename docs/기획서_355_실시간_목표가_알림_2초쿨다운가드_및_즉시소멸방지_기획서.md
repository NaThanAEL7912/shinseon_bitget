# [기획서_355] 실시간 목표가 알림 2초 쿨다운 가드 및 등록 즉시 소멸 방지 기획서

## 1. 개요 및 원인 분석
- **현상**: GUI 대시보드에서 목표가(,600 등) 입력 후 [🔔 알림 등록] 버튼 클릭 시, 등록 로그는 찍히나 하단 라벨이 즉시 🔔 감시 중인 알림 없음으로 복귀하여 등록이 안 되는 것처럼 보임.
- **원인 분석**:
  1. 등록 시점의 cur_price 판별 로직 미비로 ABOVE 방향으로 오판정되거나,
  2. 1초 뒤 수신된 틱 시세와 목표가 비교 시 즉시 돌파 조건(price >= target or price <= target)이 참(True)이 되어 0.1초 만에 리스트에서 삭제(
emove)됨.
