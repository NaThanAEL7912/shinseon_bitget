# [기획서 383] 황실 콕핏 상단 100px 공백 원천 박멸 및 완전 밀착 레이아웃 개혁 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 스크린샷에 빨간 박스를 치시며 **"상단 공간이 100px이나 비어 있는데 이거 조절 왜 안 되냐"**는 준엄한 지적을 내리심.
  - 정밀 진단 결과: 상단 `header_layout`이 독립 컨테이너 없이 메인 레이아웃에 직접 등록되어 있었고, 최하단에 빈 공간을 흡수하는 스페이서(`addStretch`)가 없어, 윈도우 창이 커질 때 PyQt 엔진이 헤더 위아래로 빈 공간을 강제 분산 배치하여 100px의 거대한 검은 공백이 발생함을 확인.

- **목적**:
  1. `header_widget = QWidget()` 고정 컨테이너(`setFixedHeight(32)`)를 신설하여 헤더를 맨 위 Y=8px 지점에 자석처럼 고정.
  2. 메인 레이아웃 최하단에 `main_layout.addStretch(1)`를 장착하여, 창 높이를 마우스로 늘려도 모든 카드들이 맨 위에서부터 1mm의 틈도 없이 상단에 완벽 밀착되도록 원천 개혁.
  3. 콕핏 버전을 **V1.03**으로 순차 상향 및 이력 관리 대장 등재.

---

## 2. 세부 개발 명세

### ① 상단 헤더 컨테이너화 및 상단 밀착 고정
```python
# 상단 타이틀 바 컨테이너 (고정 높이 32px)
header_widget = QWidget()
header_widget.setFixedHeight(32)
header_layout = QHBoxLayout(header_widget)
header_layout.setContentsMargins(0, 0, 0, 0)
header_layout.setSpacing(8)

lbl_crown = QLabel(f"👑 <b style='color:#DEBA9D; font-size:14px;'>황실 수동 콕핏 {self.COCKPIT_VERSION}</b>")
header_layout.addWidget(lbl_crown)
header_layout.addStretch()
header_layout.addWidget(self.chk_top)
header_layout.addWidget(self.lbl_ws_status)

main_layout.addWidget(header_widget) # 최상단 밀착 등록!
```

### ② 최하단 빈 공간 흡수 스페이서 장착
- 로그창(`self.txt_log`) 바로 아래에 `main_layout.addStretch(1)` 장착.
- 창이 아무리 세로로 길어져도 빈 공간은 맨 밑으로만 내려가며, 위쪽의 모든 패널(헤더, 레이더, 주문창, HUD, 방패, 스마트스탑, 로그)은 상단에 빈틈없이 착 달라붙음!

### ③ 콕핏 전용 버전 V1.03 갱신
- `self.COCKPIT_VERSION = "V1.03"` 및 `VERSION = "V1.03"`
- 윈도우 타이틀: `[SHINSEON] 황실 수동 콕핏 V1.03 (가로 500px 초슬림 · 비트겟 직통)`
- 상단 헤더: `👑 황실 수동 콕핏 V1.03`
