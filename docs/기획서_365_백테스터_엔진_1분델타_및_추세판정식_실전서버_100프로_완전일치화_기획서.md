# [기획서 365] 백테스터 엔진 1분 델타 및 추세 판정식 실전 서버 100% 완전 일치화 (V7.68)

## 1. 개요 및 목적
- **개요**: 신선 전략 백테스터 엔진(`backtest_engine.py`)의 가격 추세 판정식에서 1분 가격 델타(`price_delta_1m`) 산출 로직을 정확히 연동하고, `is_price_up` 및 `is_price_down` 추세 판정식을 실전 서버(`shinseon_server.py`)와 글자 하나까지 100% 동일하게 일치화(디지털 트윈 완결)한다.
- **목적**: 실전 서버의 1분 가격 변화 방향(`price_delta_1m > 0 / < 0`)과 1분 EMA 추세 슬로프(`price_slope_1m >= +0.30 / <= -0.30`) 결합 조건을 백테스터에 정확히 일치시켜, 백테스팅과 실전 운용 간의 오더플로우 저격 판정 괴리를 0.000%로 완벽 소멸시킨다.

## 2. 세부 개발 명세

### 1) 백테스터 엔진 1분 델타 산출 및 추세 판정식 100% 일치화 (`backtest_engine.py`)
- **1분 가격 델타(`price_delta_1m`) 산출**:
  - `price_delta_1m = cp - history_60s[0][1] if history_60s else 0.0`
- **0.035% 동적 가격 불감대 및 실전 서버 100% 완전 일치 판정식**:
  - `deadband_val = cp * 0.00035` (0.035% 동적 불감대, 약 $27달러)
  - `is_price_up = (price_delta_5s >= deadband_val) or (price_delta_1m > 0 and price_slope_1m >= +0.30)`
  - `is_price_down = (price_delta_5s <= -deadband_val) or (price_delta_1m < 0 and price_slope_1m <= -0.30)`
- **버전 헤더 주석 갱신**: V7.68
