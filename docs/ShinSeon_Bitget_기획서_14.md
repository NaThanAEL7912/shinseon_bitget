# 신선 비트겟 유지보수 기획서

## 1. 개요
* **목적**: 기존 버전업 관리 체계를 계승하여 신선 비트겟 UI 및 설정 파일의 버전을 `v4.08`로 상향 조정
* **상태**: [ ] 진행 중

## 2. 작업 계획
1. `docs/프로젝트_버전_관리.md` 장부 내역 수정:
   - v2.0.0, v2.1.0, v2.1.1 로 표기된 이력을 삭제하거나 `v4.08` 통일안으로 통합 반영
2. `shinseon_master_app.pyw`의 `self.CURRENT_VERSION` 하드코딩 값을 `v4.07`에서 `v4.08`로 변경
3. `shinseon_config.json`의 `CURRENT_VERSION` 값을 `v4.05`에서 `v4.08`로 변경

## 3. 검증 계획
* 앱 재시작 시 마스터 앱 창 제목 및 하단 상태 표시줄 등에 `v4.08`이 정상 노출되는지 확인.
