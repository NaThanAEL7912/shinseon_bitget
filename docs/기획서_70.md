# [기획서 70] 비트겟 v2 API 직송 + 소액 포지션(0.001 BTC 이하) 스마트 전량 청산 승환 50% 시장가 분할 청산 마스터 기획서 (V4.70)

## 1. 개요 및 폐하께서 하사하신 캡처 화면 팩트 분석
- **폐하의 질문:**
  "포지션 물량이 이만큼인데 문제 없나?" (캡처 화면: `BTCUSDT Isolated Long 30x`, 포지션 수량: `0.0009 BTC`)

- **소신의 캡처 화면 100% 팩트 분석 및 문제 원인 적출:**
  1. **현재 실전 포지션 수량:** `0.0009 BTC` (약 $58.3 USDT)
  2. **비트겟 거래소 선물 API 최소 발주 제한:** 비트겟 USDT 선물 API의 최소 주문 가능 수량은 **`0.001 BTC`**입니다.
  3. **발생하던 오류 팩트:** 
     - `0.0009 BTC` 상태에서 50% 분할 청산을 계산하면 `0.00045 BTC`가 됩니다.
     - 이 수량(`0.00045 BTC`)으로 비트겟 API에 청산 주문을 전송하면 거래소 서버가 `0.001 BTC 미만 발주 불가` 예외(Code 22006)를 발생시키며 청산을 튕겨내고 묵묵부답이 되었던 것입니다!

- **소신의 100% 스마트 해결 수술 방안:**
  - **`포지션 수량 > 0.001 BTC` (예: 0.002 BTC 이상):** 정확히 50% 시장가 분할 청산 집행!
  - **`포지션 수량 <= 0.001 BTC` (현재 0.0009 BTC처럼 소액 시):** 비트겟 API 최소 제한을 우회하기 위해 **자동으로 50% 분할 대신 잔여 포지션 전량({size} BTC)을 깔끔하게 시장가 청산** 승환 집행!
  - **생생한 실시간 로그 및 팝업 안내:**  
    `ℹ️ [스마트 수량 가드] 포지션 수량({size} BTC)이 최소 발주 단위(0.001 BTC) 이하이므로 전량 시장가 청산을 진행합니다.`

## 2. 50% 분할 청산 & 소액 포지션 스마트 승환 처리 4단계 아키텍처

```
[대시보드 클릭 (0.001s)] ──(WSS 패킷 CMD_CLOSE_50)──> [AWS 릴레이 서버]
                                                           │
                                            (수량 > 0.001 BTC ? 50% 청산 : 전량 청산)
                                                           │
[실시간 4단계 로그 & 팝업창] <──(포지션 자동 동기화 0.1s)─────┘
```

### 가. 50% 시장가 분할 청산 4단계 정밀 프로세스

#### [1단계: 클릭 즉시 비프음 & 1단계 보고 (0.001초)]
- 마우스 클릭 0.001초 즉시 **윈도우 비프음(`QApplication.beep()`)** 발송
- 실시간 거래 로그창 최하단 자동 스크롤 이동 & 1단계 보고:  
  `🚀 [수동 50% 청산 개시] 비트겟 실전 포지션 50% 분할 시장가 청산 명령을 집행합니다.`

#### [2단계: AWS 릴레이 서버 패킷(CMD_CLOSE_50) 전송 (0.005초)]
- AWS 릴레이 서버로 `CMD_CLOSE_50` WSS 명령 전송:  
  `📡 [서버 릴레이] AWS 릴레이 서버로 50% 청산 명령 패킷(CMD_CLOSE_50) 전송 완료`

#### [3단계: 스마트 수량 검증 & 비트겟 v2 API 주문 직송 (0.05초)]
- AWS 서버(`shinseon_server.py`)가 현재 비트겟 실전 포지션 수량(`size`) 조회
- **수량 가드 조건문:**
  - `size > 0.001 BTC`: `close_size = round(size * 0.5, 4)` (50% 청산)
  - `size <= 0.001 BTC`: `close_size = size` (소액 단위 비트겟 거부 방지용 전량 청산 승환)
- 비트겟 v2 API 정격 파라미터로 시장가 청산 주문 POST 직송:
  - LONG 청산: `side: "buy"`, `tradeSide: "close"`, `holdSide: "long"`, `size: str(close_size)`
  - SHORT 청산: `side: "sell"`, `tradeSide: "close"`, `holdSide: "short"`, `size: str(close_size)`
- 서버 로그 텔레메트리 릴레이:  
  `🎯 [비트겟 v2 API 직송] 시장가 청산 발주 집행 (청산 수량: {close_size} BTC)`

#### [4단계: 체결 검증 + 포지션 자동 동기화(`do_position_sync`) + 팝업 안내 (0.1초)]
- 청산 체결 즉시 서버와 대시보드가 **`do_position_sync()` 포지션 자동 동기화를 즉시 실행**
- **체결 성공 시:**
  - 실시간 로그: `✅ [청산 완료] 비트겟 {close_size} BTC 시장가 청산 성공! (포지션 동기화 완료)`
  - 화면 중앙 안내 팝업창(`QMessageBox.information`):
    `🌓 비트겟 {close_size} BTC 시장가 청산이 완료되었습니다!\n(포지션 상태 동기화 완료)`
- **체결 실패 시:**
  - 실시간 로그: `❌ [청산 실패] 사유: {error_msg}`
  - 화면 중앙 알림 팝업창(`QMessageBox.warning`):
    `❌ 청산 실패 (사유: {error_msg})`
