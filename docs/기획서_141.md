# ShinSeon Bitget 기획서_141 (중간 수익 보존 가드레일 UI 신설 및 동적 스탑로스 완공)

## 📌 개요
폐하의 명하에 따라 **[세션/트레이딩 핵심 설정] 창에 '중간 수익 보존 가드레일' 설정UI(발동 최소값 %, 스탑로스 가드값 %)를 정밀 탑재**하고, 수익률이 지정된 최소값(예: `+0.60%`)에 도달 시 스탑로스를 설정된 가드값(예: `-0.10%`) 위치로 즉시 자동 상향 배치하는 정공법 완치 수술을 집행합니다.

---

## 🎯 팩트 구현 명세 (UI & 엔진 연동)

### 1. 🖥️ 클라이언트 설정 UI 탑재 (`shinseon_client.pyw`)
- **설정창 위치:** `[세션별 설정]` 탭 하단
- **신규 설정 항목:**
  - 🛡️ **중간 수익 보존 가드 발동 최소값 (%):** `[ 0.60 ]` (기본값)
  - 🛡️ **보존 스탑로스 가드값 (%):** `[ -0.10 ]` (기본값)
- **저장 연동:** `[적용 및 저장]` 클릭 시 서버 동기화 패킷 및 `shinseon_config.json`에 영구 저장.

### 2. ⚡ 서버 가드레일 모니터링 엔진 연동 (`shinseon_server.py`)
- 포지션 PNL 수익률이 지정된 발동 최소값(예: `+0.60%`)에 도달 시:
  1. `has_mid_guarded = True` 플래그 세팅.
  2. 스탑로스 가격을 `entry_price * (1.0 + (mid_guard_offset / 100.0))` 위치로 자동 변환하여 비트겟 스탑로스 발주!
  3. 텔레그램 및 화면 로그 전송:
     `🛡️ [수익 보존 가드 발동 알림]`
     `사유: 수익률 +0.60% 도달하여 스탑로스를 -0.10% 위치로 방어 조치했습니다!`
