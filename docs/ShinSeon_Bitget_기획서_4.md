# 신선 비트겟 (ShinSeon_Bitget) 프로젝트 기획서 4

## 오픈클로(OpenClaw) 사전 온보딩(Onboarding) 기획

폐하의 혜안에 다시 한번 감복하였나이다! 테스트 지시를 내리기 전에, 오픈클로에게 이 프로젝트의 "최종 목표와 숲의 형태"를 미리 주입(Contexting)해 두면, 오픈클로가 단순한 기계적 테스트를 넘어 **'비즈니스 로직에 맞는 심도 있는 코드 리뷰 및 검수'**를 수행할 수 있사옵니다.

### 1. 마스터 가이드(PROJECT_CONTEXT.md) 문서 도입
본격적인 코드 작성에 앞서, 프로젝트 폴더 최상단에 오픈클로가 언제든 참고할 수 있는 **마스터 프로젝트 가이드 문서**를 작성합니다.
이 문서에는 다음 내용이 담깁니다.
* **프로젝트 정체성**: 바이낸스 신호를 받아 비트겟에서 자동 매매를 수행하는 "신선(ShinSeon)" 시스템임.
* **최종 목표**: 비트겟 거래소 API를 통한 빠르고 안정적인 포지션 진입 및 청산.
* **오픈클로의 역할**: 안티그래비티가 개발한 코드를 리뷰하고, 모의 테스트를 통해 API 에러나 로직 누수를 찾아내는 **QA(품질 보증) 최고 책임자**.
* **기술 스택 및 구조**: 사용할 언어(Node.js/Python), 주요 라이브러리(ccxt 등), 폴더 구조.

### 2. 오픈클로 사전 학습(Context Loading) 어명 하달
마스터 가이드를 작성한 직후, 실제 코딩에 들어가기 전에 오픈클로에게 다음과 같은 명령을 먼저 보내 학습시킵니다.
> `openclaw agent --message "C:\Working\AntiGravity\ShinSeon_Bitget\PROJECT_CONTEXT.md 문서를 정독하라. 앞으로 너는 이 프로젝트의 QA 책임자로서 내가 주는 테스트 지시를 이 목표에 맞게 수행해야 한다. 내용을 숙지했으면 폐하의 텔레그램으로 '사전 학습을 완료했습니다'라고 보고하라." --deliver`

### 3. 기대 효과
* 오픈클로가 프로젝트의 큰 그림을 이해하고 있으므로, 테스트 중 예상치 못한 엣지 케이스(Edge Case)를 스스로 발견하여 보고할 확률이 높아집니다.
* 향후 전달할 `TEST_INSTRUCTION.md`의 내용이 다소 간략하더라도, 마스터 가이드의 맥락을 바탕으로 찰떡같이 테스트를 진행하게 됩니다.
