## 🛠️ 2. 정공법 완치 수술 상세 내역

### 2.1. `shinseon_server.py` 텔레메트리 루프 수술
1. **대시보드 UI 전송 힌트(`expected_dir`)를 백서 헌법(Case A~D) 100% 동일 로직으로 교체:**
   - 1분 가격 변화량(`price_delta_1m = current_price - price_1m_ago`)과 1분 OI속도(`oi_delta_1m`)를 결합하여 대시보드 카드 힌트 방향을 백서와 1:1로 정확히 통일합니다.

```python
# --------------------------------------------------------------------------
# 🎯 [대시보드 UI 힌트] 백서 헌법 100% 정격 4대 저격 매트릭스 연동
# --------------------------------------------------------------------------
price_1m_ago = self.price_history[0][1] if self.price_history else self.current_price
price_delta_1m = self.current_price - price_1m_ago

if price_delta_1m < 0 and display_oi < 0:
    direction = "LONG"    # Case A: 📉 가격하락 + OI감소 ➡️ 🟢 LONG
elif price_delta_1m > 0 and display_oi < 0:
    direction = "SHORT"   # Case B: 📈 가격상승 + OI감소 ➡️ 🔴 SHORT
elif price_delta_1m > 0 and display_oi > 0:
    direction = "LONG"    # Case C: 📈 가격상승 + OI증가 ➡️ 🟢 LONG
elif price_delta_1m < 0 and display_oi > 0:
    direction = "SHORT"   # Case D: 📉 가격하락 + OI증가 ➡️ 🔴 SHORT
else:
    direction = "LONG" if price_delta_1m >= 0 else "SHORT"
```

2. `ws_frame` 패킷에도 `price_delta_1m` 수치를 명시적으로 추가하여 실전 오더플로우 저격 엔진과 대시보드 UI 화면 힌트가 단 0.001%의 오차도 없이 100% 동기화되도록 완치합니다.
