01 프로젝트 개요 및 목표

신선(ShinSeon) 프로젝트란?

신선 비트겟 시스템은 전 세계 최대 거래량을 자랑하는 Binance 선물 시장의 세력 오더플로우 데이터를 극초음속으로 스캐닝하여 Bitget 거래소에 0.0019초(1.9ms) 만에 시장가 타점 및 리스크 관리를 꽂아넣는 '초고속 오더플로우 융합 자동 트레이딩 봇'입니다.

[🔥 극초음속 스캐닝 엔진 스펙]
  • 청산(Liquidation) 수집: 실시간 (0초 딜레이)
    바이낸스 WebSocket을 통해 청산 이벤트 발생 즉시 서버로 다이렉트 푸시(Push)됩니다.
  • 미결제약정(OI) 스캐닝: 0.2초 단위 폴링
    1초에 5번씩 타격하며 세력 자금의 유입/유출을 초정밀 감시합니다.
  • 딥다이브 레코더(CSV): 1초 상시 기록 (무조건)
    사후 완벽한 복기 및 AI 머신러닝 데이터 축적을 위해, 조건이나 임계치를 따지지 않고 24시간 내내 1초 간격으로 초고밀도 폭포수 로깅을 수행합니다.
핵심 철학 (The Core Philosophy) "개미들의 눈물이 세력의 자양분이 되는 순간을 포착하라."

대중의 거대한 손절(청산)이 발생할 때, 스마트머니(세력)가 그 물량을 받아먹고 추세를 반전시킵니다. 신선은 이 변곡점(Pivot)을 정확히 타격합니다.
최종 목표 (The Ultimate Goal) 인간의 감정과 뇌동매매를 100% 배제하고, 수학적 임계치와 오더플로우 팩트(Fact)에만 기반하여 '무손실에 가까운 최적의 타점'을 기계적으로 선점하여 누적 수익을 극대화합니다.

03 핵심 판단 코어 엔진 (4대 완성형 저격 헌법)

🚨 0단계: 듀얼 임계치 & 0.02% 동적 불감대 절대 룰

주문이 발생하기 위한 최소한의 자격 요건입니다. 아래 조건이 동시에 충족되지 않으면 시스템은 절대 움직이지 않습니다.

rolling_1m_liq_usd >= target_liq
AND
abs(oi_delta_1m) >= target_oi (음수/양수 전수 감지!)
AND
abs(price_delta_5s) >= current_price * 0.0002 (0.02% 동적 불감대)

📊 1단계: 4대 완성형 오더플로우 저격 매트릭스 (abs(OI) 전수 적용)

번호 전략 명칭 1분 청산액 1분 OI 속도 0.02% 동적 5초 가격 턴 1분 추세 기울기 최종 진입 방향
1️⃣ 강력한 불장 돌파 롱 >= Target +OI (양수) delta_5s >= +0.02% 기울기 ≥ 0 🟢 LONG 탑승
2️⃣ 강력한 폭락 추세 숏 >= Target +OI (양수) delta_5s <= -0.02% 기울기 ≤ 0 🔴 SHORT 탑승
3️⃣ V자 바닥 반등 롱 >= Target -OI (음수) delta_5s >= +0.02% (반등턴) 무관 🟢 LONG 저격 🏹
4️⃣ 역V자 천장 덤핑 숏 >= Target -OI (음수) delta_5s <= -0.02% (덤핑턴) 무관 🔴 SHORT 저격 🏹

🛡️ 2단계: 안전 스위칭 및 락다운 로직

  • 안전 쿨타임 (Lockdown): 주문 청산 후 대시보드 UI 설정창에서 지정한 손절 쿨타임(기본 30초) / 익절 쿨타임(기본 15초) 동안은 어떠한 추가 진입 신호도 무시합니다. 이는 연쇄 청산 꼬리에 휩쓸리는 뇌동매매를 방지합니다.
  • 진성 자금 스위칭 허용: 포지션 보유 중 반대 방향의 진성 자금 신호 발생 시, 먼저 기존 포지션을 안전하게 전량 청산한 후 쿨타임 종료 후 신규 진입을 집행합니다.

04 3중 주문 청산 & 무위험 스윙 가드레일

1. 최초 손절선 (Hard Stop Loss)

Why: 돌발적인 시장 역주행 시 원금을 철통같이 방어하는 최후의 안전벨트.

How: 비트겟 REST API loss_plan을 통해 세션별 설정된 손절선(-0.6% ~ -1.3%) 도달 시 100% 전량 즉시 시장가 손절을 집행합니다.

2. 50% 부분 분할 익절 (Partial TP)

Why: 목표 수익률 도달 시 선제적으로 현금을 확보하여 원금 리스크를 영구 제거하기 위함.

How: 1차 목표 수익률(+0.9% ~ +1.2%) 도달 시 profit_plan으로 진입 수량의 정확히 50%만 시장가 익절하여 현금을 락인합니다.

3. 무위험 본전 스탑 가드 (Breakeven Guard)

Why: 50% 익절 후 남은 잔여 물량으로 대세 랠리를 무위험(Zero-Risk) 완주하기 위함.

How: 50% 익절 체결 즉시, 남은 50% 포지션의 손절선을 진입가 본전(+0.10% BEP)으로 자동 상향 이동시켜 손실 확률을 0.00%로 소멸시킵니다.

4. 다단계 계단식 분할 손절 방패 (Scaled SL)

Why: 야간 수면 시간 및 주말 돌발 변동성에 대비한 리스크 분산 방패.

How: 거래소 서버에 1.0 BTC 단위로 계단식 분할 손절선(예: .2k / .0k)을 사전 예약 발주하여 급격한 꼬리 찌르기 시에도 리스크를 단계별로 차단합니다.

09 🛠️ 유지보수 가이드 (Troubleshooting)

  • 증상: 비트겟 주문이 안 나가거나 에러가 뜸 (예: 400172)
    해결: shinseon_server.py의 execute_bitget_internal_packet() 함수 내부 잔여 수량 처리 로직을 점검하십시오.
  • 증상: 오더플로우 깃발 방향이 엉뚱하게 뜰 때
    해결: abs(oi_delta_1m) 및 price_delta_5s 0.02% 불감대 조건이 백서와 일치하는지 대조하십시오.
  • 증상: 클라이언트와 AWS 서버 간 로그 동기화가 끊어짐
    해결: shinseon_server.py의 start_socket_server() TCP 소켓 유지 로직을 점검하십시오.
