# [기획서 382] 황실 콕핏 3중 신호등 스토캐스틱 RSI (Stoch RSI 14, 14, 3, 3) 전면 동기화 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 **"지금처럼 거래량이 적은 장세에서는 1분/5분 스토캐스틱 RSI가 기가 막히게 잘 맞는다. 콕핏의 둔직한 일반 RSI를 내가 트레이딩뷰 차트에서 보는 스토캐스틱 RSI로 전면 변경하라"**는 거룩한 어명을 내리심.
  - 실측 결과: 일반 RSI는 1m/5m/15m 모두 49% 근처에서 둔하게 멈춰 있으나, 스토캐스틱 RSI(Stoch RSI 14, 14, 3, 3 %K)는 15분봉 과매수(75%), 1분봉 바닥(7%) 등 생생한 변곡점 파동을 10배 더 날렵하게 포착함을 확인함.

- **목적**:
  1. `shinseon_cockpit.pyw`의 `MultiRsiWorker` 연산 엔진을 **정통 스토캐스틱 RSI (Stoch RSI 14, 14, 3, 3) %K 산출식**으로 전면 교체.
  2. 콕핏 3중 신호등 뱃지를 **`[ 1m Stoch: XX.X% ] [ 5m Stoch: XX.X% ] [ 15m Stoch: XX.X% ]`**로 개편 및 80%/20% 기준 네온 레드/그린/화이트 신호등 점등.
  3. 콕핏 버전을 **V1.02**로 순차 상향 및 이력 관리 대장 등재.

---

## 2. 세부 개발 명세

### ① 스토캐스틱 RSI(14, 14, 3, 3) %K 실시간 연산 엔진 구축
- `MultiRsiWorker(QThread)` 내부 알고리즘 개편:
  1. Bitget REST API를 통해 1m, 5m, 15m 캔들 100개 수집.
  2. Wilder's Smoothing 방식 정통 RSI(14) 시계열 배열 산출.
  3. 최근 14개 RSI의 최소값($	ext{Min}$)과 최대값($	ext{Max}$)을 이용해 Raw Stochastic RSI 연산:
     $$	ext{Stoch RSI} = rac{	ext{RSI} - 	ext{Min}}{	ext{Max} - 	ext{Min}} 	imes 100$$
  4. 최근 3개 Stoch RSI의 단순 이동평균(SMA)으로 최종 **%K** 산출!
  5. 1초 주기로 UI에 `rsi_updated = Signal(float, float, float)` 방출.

### ② 콕핏 3단 신호등 뱃지 UI 시각화 개편
- 텍스트 표기:
  - `1m Stoch: XX.X% 🟢` (20% 이하 과매도 바닥 / 롱 유리)
  - `5m Stoch: XX.X% ⚪` (20%~80% 중립 수렴)
  - `15m Stoch: XX.X% 🔴` (80% 이상 과매수 천장 / 숏 유리)
- 스타일시트:
  - 80% 이상 : `background: rgba(255, 51, 102, 0.25); border: 1px solid #FF3366; color: #FF6688;`
  - 20% 이하 : `background: rgba(0, 230, 118, 0.25); border: 1px solid #00E676; color: #00FFCC;`
  - 20~80% : `background: rgba(60, 60, 60, 0.3); border: 1px solid #757575; color: #CBD5E1;`

### ③ 콕핏 전용 버전 V1.02 갱신
