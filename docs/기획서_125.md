# ShinSeon Bitget 기획서_125 (비트겟 체결 이력 서버 자동 복원 및 전 청산 실적 100% 강제 저장 엔진)

## 📌 개요
서버 재가동이나 체결 통보 누수로 인해 아까 수행된 매매 실적이 빠지는 현상을 원천 방지하기 위해, **비트겟 거래소 API 체결 내역(`fetch_my_trades`)을 수집하여 누락된 거래 실적을 100% 자동 복원하는 스마트 동기화 엔진** 및 **모든 청산 시점 실적 강제 기록 보증 장치**를 완공합니다.

---

## 🔍 [매매 실적 복원 및 강제 저장 수술안]

1. **비트겟 거래소 최근 체결 내역 기반 서버 실적 자동 복원 엔진:**
   - 서버 구동 시 또는 클라이언트 동기화 요청 시 비트겟 선물 체결 내역(`fetch_my_trades`)을 조회.
   - 오늘 일자의 실전 체결(진입/청산 짝) 내역을 분석하여 당일 통계 파일(`logs/trade_stats_YYYY-MM-DD.json`)에 누락된 거래가 있으면 **실제 체결 단가/수량/PnL 그대로 100% 자동 복원**!

2. **모든 청산 루틴 실적 강제 기록 장치:**
   - 1차 분할 익절, 가드레일 익절, 세션 손절, 추적 익절, 반대 신호 청산, 비상 탈출, 스마트 스탑 청산 등 모든 청산 발생 즉시 `record_trade_history_event(...)`를 무조건 강제 호출하여 파일 저장 및 `EVT_SYNC_STATS` 실시간 브로드캐스트 보증 (V5.25).
