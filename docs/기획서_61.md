# [기획서 61] 대시보드 PNL 명칭 전환 및 가드레일 문구 단축 정밀 수술 (V4.62)

## 1. 개요 및 폐하의 명철하신 어명 분석
- **폐하의 어명:**
  1. "그럼 변동이라고 하지말고 PNL 이라고 적어줘라"
  2. "가드레일 도약 대기도, 줄여서 가드레일 이라고 수정하고"
- **개편 목적:**
  대시보드 상태창 표기 문구를 간결하고 직관적으로 수술하여 시가독성을 극대화합니다.
  - `(변동: +0.01%)` $\rightarrow$ **`(PNL: +0.01%)`**
  - `(가드레일 도약 대기: +0.40%)` $\rightarrow$ **`(가드레일: +0.40%)`**

## 2. 상세 수술 및 배포 계획 (V4.62)

### 가. 소스코드 텍스트 명칭 수술 (`shinseon_server.py`)
- `shinseon_server.py` 내 `pnl_hdr` 및 `status_msg` 생성 수식 교정:
  ```python
  # 기존 1: pnl_hdr
  pnl_hdr = f"[{direction_active} 진입 @ {entry:,.1f}] ROE: {roe_pct:+.2f}%{usdt_str} (변동: {live_pnl:+.2f}%)"
  # 개편 1: pnl_hdr
  pnl_hdr = f"[{direction_active} 진입 @ {entry:,.1f}] ROE: {roe_pct:+.2f}%{usdt_str} (PNL: {live_pnl:+.2f}%)"

  # 기존 2: status_msg
  status_msg = f"{pnl_hdr}\n(가드레일 도약 대기: +{guard_trig:.2f}%)"
  # 개편 2: status_msg
  status_msg = f"{pnl_hdr}\n(가드레일: +{guard_trig:.2f}%)"
  ```

- 최종 화면 및 로그 표기 결과 예시:  
  `[LONG 진입 @ 64,822.0] ROE: +0.24% (+0.00 USDT) (PNL: +0.01%)`  
  `(가드레일: +0.40%)`
