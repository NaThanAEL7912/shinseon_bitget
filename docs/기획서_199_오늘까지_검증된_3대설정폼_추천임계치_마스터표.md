# 기획서 199: 백테스트 데이터 기반 3대 설정 UI 폼 추천 임계치 마스터 수치표 작성

## 1. 개요 및 목적
폐하의 어명(**"오늘까지 백테스트 데이터로 나온 추천 임계치 값을 통합 표로 만들어라"**)에 부응하여, 1~3대 대화상자 UI 폼과 1:1로 정확하게 짝을 이루는 **[8대 세션 최적 임계치 마스터 수치표]**, **[트레이딩 핵심 설정 마스터표]**, **[가드레일 최적 수치 마스터표]**를 팩트 기반으로 정리하여 완공합니다.

---

## 2. 🎯 통합 3대 UI 폼 1:1 매핑 추천 수치 명세

### [1] 1번째 대화상자: 세션별 오더플로우 임계치 UI 폼
- **평일 아시아**: $200,000 / 0.1200% / -0.3%
- **평일 유럽**: $1,500,000 / 0.1200% / -0.3% *(안정 방어형)* (또는 $1,800,000 / 0.2400% / -0.3% 100% 무손실형)
- **평일 미국 본장**: $650,000 / 0.3200% / -0.3% 💥 *(대폭발 수익형)*
- **평일 태평양**: $200,000 / 0.2600% / -0.3%
- **주말 4개 세션**: $200,000 / 0.2100%~0.30% / -0.3%~-0.5% *(보수적 방어)*

### [2] 2번째 대화상자: 트레이딩 핵심 설정 UI 폼
- **레버리지**: 30배
- **현금배팅 비중**: 750.0%
- **1차 매수 비중**: 500.0 / **2차 매수 비중**: 250.0 (2 : 1 비중)
- **2차 진입 조건**: PnL <= -0.30% 이하 AND 동일 방향 오더플로우 신호 재발생 시 추매

### [3] 3번째 대화상자: 가드레일 설정 UI 폼
- **평일 아시아**: 분할익절 +0.60% / 본전가드 +0.05%
- **평일 유럽**: 분할익절 +0.80% / 버퍼가드 0.00%
- **평일 미국 본장**: 분할익절 +1.50% / 이익보존가드 +0.10% 💥 *(수익 극대화)*
- **평일 태평양**: 분할익절 +0.90% / 본전가드 0.00%
- **보존가드 스탑**: 최고 PnL +0.60% 도달 후 반락 시 PnL 0.00% 청산

- [ ] **[1단계]** 오늘 진행된 백테스트 데이터 결과 파싱 및 세션별 최적치 종합
- [ ] **[2단계]** 3대 UI 대화상자 폼과 1:1 매핑되는 한눈에 보는 통합 추천표 작성
- [ ] **[3단계]** 폐하 최종 보고 및 문서 완공 / 프로젝트 버전 관리 업데이트
