# [기획서 76] 수동 50% 분할 청산과 자동 세션 본전가드(-0.15%) 완전 독립 분리 기획서 (V4.76)

## 1. 개요 및 폐하의 지적 팩트 분석
- **폐하의 지적:**
  - "아니 분할 익절 본전 가느 먼지 모르냐? 첨부한 부분이 적용 된거 같다고 말하는거야. 이 익절 청산하고는 상관이 없는데 저게 작동 된거 같아"
- **소신의 팩트 분석 (100% 적출):**
  - 대시보드의 **`세션별 설정`**에 등록된 **`분할익절 임계값(+0.90%)` 및 `본전/버퍼 가드(-0.15%)`**는 자동 봇 전략 엔진이 +0.90% 수익에 도달했을 때 자동으로 발동시키는 세션 가드 로직입니다.
  - 하지만 기존 코드(line 1319)에서 폐하께서 **수동으로 `🌓 50% 시장가 분할 청산` 버튼을 눌렀을 때도 플래그(`is_half_exited = True`)를 공용으로 공유**하는 바람에, 자동 전략 엔진이 "아, +0.90% 세션 자동 익절이 끝났구나!"라고 착각하고 **자동 본전가드(-0.15%)를 강제로 세팅하여 포지션을 밀어버리는 치명적 비동기 간섭 버그**가 적출되었습니다.

---

## 2. 세부 개조 내역 (독립 분리 수술)

### 가. 플래그 이원화 독립 분리 (`is_half_exited` vs `is_manual_half_exited`)
1. **자동 세션 익절 전용 플래그 (`is_half_exited`):**
   - 오직 자동 전략 엔진이 세션 임계값(+0.90% ROE 등)에 스스로 도달하여 50% 익절을 수행했을 때만 `is_half_exited = True`가 작동하며, 이때만 세션 본전가드(`-0.15%`)가 발동됩니다.
2. **수동 50% 청산 전용 플래그 (`is_manual_half_exited`):**
   - 폐하께서 수동 제어판의 `🌓 50% 시장가 분할 청산` 버튼을 누르셨을 때는 **수동 전용 플래그(`is_manual_half_exited = True`)만 작동**합니다.
   - 자동 전략 엔진의 `is_half_exited` 플래그를 **절대 건드리지 않으며**, 세션 자동 본전가드(`-0.15%`)가 수동 청산에 간섭하거나 발동하지 않도록 100% 차단 격리합니다!

### 나. 레이더 스캔 상태 문구 깔끔한 원복
- 수동 50% 청산 시 자동 본전가드 문구(`🛡 50% 분할익절 완료 | 본전가드: -0.15%`)가 레이더 로그에 오해를 일으키지 않도록 완전 원복 및 정화합니다.
