# 기획서 220: 비트겟 거래소 서버사이드 듀얼 TP/SL 선주문 및 캔슬 정화 엔진 전격 가동 (V6.18)

## 📌 1. 개요 및 팩트 목적
- **목적:**  
  진입 즉시 비트겟 거래소에 **익절(TP) 지정가/조건가 및 손절(SL) 조건가 선주문(Plan Order)**을 0.001초 만에 미리 박아두고, 청산/스위칭/손절/익절 발생 시 미체결 예약 주문을 100% 캔슬 정화(Cancel All)하여, 0.000ms 레이턴시 무결점 청산 및 웹서버 다운 시 시드 100% 철통 방화를 달성함.

- **폐하의 특명 방화벽 (스마트 스탑 Smart Guard & 눌림목 불타기 Pyramiding 정격 반영):**  
  1. **스마트 스탑(Smart Stop / 본절가드) 발동 시:** 기존 옛날 손절가 SL 선주문을 캔슬하고, 새로 상향 갱신된 **"스마트 본전/버퍼 보존가 (Entry + Buffer Price)"**로 비트겟 SL 선주문을 즉시 상향 재배치함.
  2. **눌림목 불타기(Pyramiding) 체결 시:** 새로 형성된 **가중 평단가 및 새로 갱신된 손절 라인**으로 비트겟 TP & SL 선주문을 정격 재배치함.

- **설정값 연동 원칙:**  
  모든 TP/SL 목표 수치는 하드코딩을 100% 배제하고 **UI 대시보드 설정값(`initial_sl_pct`, `profit_tp_pct`, `entry_sl_guard`)과 1:1 완벽 연동**.

## 🛠️ 2. 작업 상세 내역

### 1) 진입 시 TP/SL 선주문 박기 함수 구축 (`place_bitget_tpsl_preorders`)
- 진입 체결 팩트 수량/평단가 확인 즉시:
  - **TP 선주문:** `entry_p * (1.0 + tp_pct)` (LONG) / `entry_p * (1.0 - tp_pct)` (SHORT) ➡️ 비트겟 Plan Order 배치.
  - **SL 선주문:** `entry_p * (1.0 - sl_pct)` (LONG) / `entry_p * (1.0 + sl_pct)` (SHORT) ➡️ 비트겟 Plan Order 배치.

### 2) 눌림목 불타기(Pyramiding) 체결 시 SL 재배치
- 기존 예약 주문 취소(`side="CLEAR", order_type="CANCEL_ALL"`) ➡️ **새로 갱신된 스마트 본전/버퍼 보존 손절가**로 SL 선주문 재배치.

### 3) 청산/스위칭/50%익절 시 미체결 예약 주문 캔슬 정화 (`cancel_all_open_plan_orders`)
- `side="CLEAR"` 진입 시 비트겟 `fetch_open_orders` ➡️ `cancel_order` 로 미체결 스탑/TP 예약 주문 100% 전량 정화.
