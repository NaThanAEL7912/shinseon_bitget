# [기획서 380] 황실 콕핏 실시간 다이버전스 자동 탐지, 듀얼 임계치 저격 사운드 개편 및 임계치 설정 UI 탑재 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 차트 분석 중 **'5분봉 정규 하락 다이버전스'를 날카롭게 포착하여 숏 덤핑 수익을 거두신 후, 이 다이버전스를 콕핏 화면에서 자동으로 탐지하여 뱃지로 알려주는 기능**을 하사하심.
  - 또한, 콕핏은 봇과 목적이 다른 수동매매 전용 툴이므로 **독립적인 버전 체계(`👑 황실 수동매매 콕핏 V1.00`)**를 적용하고자 함.
  - 포지션 변경 시 울리는 불필요한 사운드는 끄고, **오직 1분 청산액과 1분 OI 속도라는 2대 핵심 임계치가 동시에 100% 충족되는 진짜 저격 찬스에만 사운드 비프음이 울리도록 개편**을 명하심.
  - 폐하께서 언제든 원하는 임계치 숫자를 파일 열람 없이 콕핏 화면에서 즉시 수정할 수 있도록 UI 인터페이스를 요청하심.

- **목적**:
  1. `shinseon_cockpit.pyw`에 **[ 5분봉/15분봉 정규 상승/하락 다이버전스 실시간 자동 탐지 엔진 & 뱃지 ]** 신설.
  2. 콕핏 타이틀 및 헤더를 **`👑 황실 수동매매 콕핏 V1.00 (비트겟 직통)`** 전용 독립 버전으로 정립.
  3. 사운드 개편: 포지션 변경음 완전 음소거 & **[ 청산액 >= Target Liq AND |OI속도| >= Target OI ] 듀얼 100% 동시 충족 시에만 맑은 저격 비프음 송출**.
  4. 콕핏 상단에 **[ ⚙️ 임계치 직접 수정 입력창 (청산액 / OI속도 / 적용 버튼) ]** 탑재.

## 2. 세부 개발 명세

### ① 5분봉/15분봉 정규 다이버전스 실시간 자동 탐지 엔진
- `MultiRsiWorker` 또는 `DivergenceWorker`를 통해 최근 30개 캔들의 High/Low와 Stoch RSI / RSI의 Peak/Trough를 실시간 스캔:
  - **정규 하락 다이버전스 (Regular Bearish Divergence)**:
    - 가격은 전고점 돌파 (Higher High) BUT RSI는 고점 하락 (Lower High)
    - ➔ 레이더 뱃지에 `[ 🐻 5m 하락 다이버전스 감지! (숏 저격) ]` (네온 레드) 점등!
  - **정규 상승 다이버전스 (Regular Bullish Divergence)**:
    - 가격은 전저점 이탈 (Lower Low) BUT RSI는 저점 상승 (Higher Low)
    - ➔ 레이더 뱃지에 `[ 🐂 5m 상승 다이버전스 감지! (롱 저격) ]` (네온 그린) 점등!

### ② 콕핏 전용 독립 버전 명문화 (`V1.00`)
- 윈도우 타이틀: `[SHINSEON] 황실 수동 콕핏 V1.00 (가로 500px 초슬림 · 비트겟 직통)`
- 좌측 상단 헤더: `👑 황실 수동 콕핏 V1.00`
- 비트겟 본 계정 API 직접 통신 상태를 녹색 뱃지로 명확히 표기.

### ③ 사운드 알림 완벽 개편 (듀얼 임계치 100% 동시 충족 시만 격발)
- 포지션 진입/종료/스위칭 시의 사운드는 **완전 음소거 (Mute)**.
- 오직 아래 2가지 조건이 동시에 100% 달성될 때만 비프음 알림:
  ```python
  if rolling_1m_liq >= target_liq and abs(oi_delta_1m) >= target_oi:
      # 진짜 100% 저격 찬스 비프음 격발! (60초 쿨타임)
      winsound.Beep(1200, 200)
  ```

### ④ 콕핏 화면 내 실시간 임계치 직접 수정 UI 패널
- 1분 청산 및 OI 게이지 바로 위에 컴팩트한 임계치 입력 바 배치:
  ```text
  ┌─────────────────────────────────────────────────────────────┐
  │ ⚙️ 임계치: 청산 $[ 200,000 ] | OI [ 0.12 ]%   [ 💾 적용 ]     │
  └─────────────────────────────────────────────────────────────┘
  ```
  - 폐하께서 숫자를 타이핑하고 `[ 💾 적용 ]` 버튼을 누르면 즉시 메모리와 `shinseon_config.json`에 동시 저장되어 게이지 기준선이 즉시 변경됨!
