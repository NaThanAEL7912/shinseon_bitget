## 2. 🔍 [백테스터 엔진(`backtest_engine.py`) 4번 알고리즘 명세]

### 1️⃣ 진입 시그널 판정 공식 (4번 청산 주도권 ✕ +OI 헌법)
```python
# [4번 청산 주도권 볼륨 저격 헌법]:
# 1단계: 청산액 임계치 돌파 AND 세력 신규 자금 유입 (+OI) 돌파 검사
if rolling_1m_liq >= target_liq and oi_speed >= target_oi:
    # 2단계: 최근 1분간 터진 청산 주도권 볼륨 비교
    if short_liq >= long_liq:
        sig_dir = "LONG"
        strat_name = "🟢 롱 저격 (숏 청산 압도 + 매수 자금 유입)"
    else:
        sig_dir = "SHORT"
        strat_name = "🔴 숏 저격 (롱 청산 압도 + 매도 자금 유입)"
```

### 2️⃣ OI 모드 듀얼 지원 (설정 파일 및 GUI 연동)
- **`POSITIVE_ONLY` (기본값 / 추천):** `oi_speed >= target_oi` (+OI 양수만 진입 ➡️ 휩소 34회 회피)
- **`ALL` (절댓값 모드):** `abs(oi_speed) >= target_oi` (음수 청산 휩소 포함 전수 진입 ➡️ 거래량 극대화 모드)
