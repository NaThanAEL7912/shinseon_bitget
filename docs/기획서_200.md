# 기획서 200: CSV 타점 시그널 🟢LONG(진한 초록) / 🔴SHORT(빨강) 시각 강조 완치 수술

## 📌 1. 개요 및 원인 분석
- **현상 (엑셀 CSV 내 타점 시그널 텍스트 밋밋함):**
  - **폐하의 어명 지침:** *"롱은 찐한 초록색, 숏은 빨간색으로 굵은 글씨로 표시 할 수 있나?"*
  - **기술적 팩트:** 텍스트 기반 순수 `.csv` 파일은 폰트 색상(RGB) 텍스처 태그를 직접 포함할 수 없으나, **컬러 이모지 이중 직관 표기법 (`🟢 LONG` / `🔴 SHORT`)**을 적용하면 엑셀 화면에서 즉시 **진한 초록색 원과 빨간색 원이 굵고 선명하게 100% 직관적**으로 구분되어 출력됩니다!
- **목적:** CSV 기록 엔진의 `signal_val` 값을 **`🟢 LONG` (진한 초록) / `🔴 SHORT` (빨간색)**으로 정격 개편하여 엑셀 오픈 시 1초 만에 타점 시그널을 눈에 띄게 식별하도록 완치합니다.
