01 프로젝트 개요 및 목표

신선(ShinSeon) 프로젝트란?

신선 비트겟 시스템은 전 세계 최대 거래량을 자랑하는 Binance 선물 시장의 세력 오더플로우 데이터를 극초음속으로 스캐닝하여 Bitget 거래소에 0.1초 내외로 시장가 타점을 꽂아넣는 '초고속 오더플로우 융합 자동 트레이딩 봇'입니다.

[🔥 극초음속 스캐닝 엔진 스펙]
  • 청산(Liquidation) 수집: 실시간 (0초 딜레이)
    바이낸스 WebSocket을 통해 청산 이벤트 발생 즉시 서버로 다이렉트 푸시(Push)됩니다.
  • 미결제약정(OI) 스캐닝: 0.2초 단위 폴링
    1초에 5번씩 타격하며 세력 자금의 유입/유출을 초정밀 감시합니다.
  • 딥다이브 레코더(CSV): 1초 상시 기록 (무조건)
    사후 완벽한 복기 및 AI 머신러닝 데이터 축적을 위해, 조건이나 임계치를 따지지 않고 24시간 내내 1초 간격으로 초고밀도 폭포수 로깅을 수행합니다.
핵심 철학 (The Core Philosophy) "개미들의 눈물이 세력의 자양분이 되는 순간을 포착하라."

대중의 거대한 손절(청산)이 발생할 때, 스마트머니(세력)가 그 물량을 받아먹고 추세를 반전시킵니다. 신선은 이 변곡점(Pivot)을 정확히 타격합니다.
최종 목표 (The Ultimate Goal) 인간의 감정과 뇌동매매를 100% 배제하고, 수학적 임계치와 오더플로우 팩트(Fact)에만 기반하여 '무손실에 가까운 최적의 타점'을 기계적으로 선점하여 누적 수익을 극대화합니다.

🚨 황금 전성기 절대 룰 (0단계 듀얼 임계치)

주문이 발생하기 위한 최소한의 자격 요건입니다. 이 두 가지가 동시에 충족되지 않으면 시스템은 절대 움직이지 않습니다.

rolling_1m_liq_usd >= target_liq
AND
abs(oi_delta_1m) >= target_oi

📊 1단계: 방향성 4대 매트릭스 ✕ 롱/숏 청산 주도 비율 3중 검증 (V6.07)

Case 1분 EMA 추세 기울기 (price_slope_1m) 1분 OI 속도 (oi_delta_1m) 롱/숏 청산 주도 비율 2차 검증 오더플로우 팩트 (세력의 의도) 신선 포지션
A 지속 하락 ( < 0 ) 감소 ( < 0 ) long_liq ≥ short_liq (롱 청산 주도) 개미 롱 손절 털기 팩트 검증. 바닥 저격. LONG (매수) 🟢
B 지속 상승 ( > 0 ) 감소 ( < 0 ) short_liq ≥ long_liq (숏 청산 주도) 개미 숏스퀴즈 털기 팩트 검증. 꼭대기 저격. SHORT (매도) 🔴
C 지속 상승 ( > 0 ) 증가 ( > 0 ) short_liq ≥ long_liq (숏 청산 돌파) 세력이 숏 청산 먹으며 상승. 추세 지속. LONG (매수) 🟢
D 지속 하락 ( < 0 ) 증가 ( > 0 ) long_liq ≥ short_liq (롱 청산 돌파) 세력이 롱 청산 먹으며 하락. 추세 지속. SHORT (매도) 🔴

🛡️ 2단계: 안전 스위칭 및 락다운 로직

  • 안전 쿨타임 (Lockdown): 주문 청산 후 대시보드 UI 설정창에서 지정한 손절 쿨타임(기본 30초) / 익절 쿨타임(기본 15초) 동안은 어떠한 추가 진입 신호도 무시합니다. (폐하의 필요에 따라 설정창에서 실시간 동적 변경 가능) 이는 연쇄 청산 꼬리에 휩쓸리는 다중 진입을 방지합니다.
  • 가짜 찌꺼기 스위칭 방지: 포지션 보유 중 반대 신호가 떴을 때, OI 델타가 감소(<0)하는 신호(A, B)면 스위칭하지 않고 기존 포지션을 유지합니다. (단순 손절 물량에 속지 않음)
  • 진성 자금 스위칭 허용 (쿨타임 기반 연속 진입): 포지션 보유 중 반대 방향의 OI 델타가 증가(>0)하는 진성 자금 신호(C, D)가 뜨더라도 즉시 반대 포지션으로 무조건 스위칭(Flip)하는 것이 아닙니다. 먼저 기존 포지션을 전량 청산(익절 또는 손절)한 뒤 안전 쿨타임(Lockdown)에 돌입하며, 쿨타임 종료 후에도 해당 반대 신호가 계속 유효하게 발생하고 있다면 그때 자연스럽게 신규 진입(스위칭)이 이루어집니다.

04 전술 기능 상세 명세서

1. 스마트 수량 가드 (400172 방어)

Why: 비트겟의 최소 주문 수량 제약(BTC의 경우 통상 0.001 또는 0.0001)으로 인해 분할 익절 시 잔여 수량이 최소 수량 미만이 되면 API 에러(400172)가 발생하여 포지션이 영원히 갇히는 버그를 방지하기 위함.

How: 매도/익절 패킷을 생성하기 전, 현재 수량과 계산된 분할 수량을 비교하여 분할 수량(또는 남게 될 잔여 수량)이 0.0001 BTC 미만일 경우, 시스템이 자동으로 '전량 청산(100%)'으로 주문 파라미터를 강제 치환합니다.

2. 지능형 가드레일 (본전 가드 & 트레일링)

Why: 수익을 확보한 상태에서 갑작스러운 빔(Beam)을 맞아 손실로 전환되는 것을 완벽히 차단하고, 추세를 끝까지 발라먹기 위함.

How:
▹ 본전 가드: 수익률이 N% 도달 시 가동. 이후 가격이 진입가(ROE 0%) 근처로 돌아오면 시장가 전량 탈출.
▹ 가드레일(트레일링): 수익률이 M% 도달 시 가동. 최고 도달 수익률(Peak) 대비 지정한 퍼센트(%)만큼 하락하면 즉시 시장가 전량 익절.

3. 눌림목 불타기 (Pyramiding)

Why: 확실한 추세가 터졌을 때, 1차 익절 후 남은 물량에 수익금을 엎어서 비중을 다시 늘려 극대화된 수익을 창출하기 위함.

How: 1차 분할 익절이 나간 상태에서(수량 감소), 기존 진입 방향과 동일한 깃발(방향)의 강한 신호가 다시 발생하면, 초기 진입 수량의 30%를 시장가로 추가 진입(불타기)하고 평균단가를 재조정합니다.

4. 초고밀도 CSV 딥다이브 레코더

Why: 향후 AI 머신러닝 훈련 및 완벽한 사후 복기 백테스팅을 위한 고품질 로우(Raw) 데이터를 수집하기 위함.

How: 향후 완벽한 사후 복기 및 훈련 데이터 축적을 위해, 어떠한 조건이나 임계치에도 구애받지 않고 무조건 1초 간격 상시 초고밀도 로깅 모드(Deep Dive)로 24시간 내내 실시간 틱 데이터를 쏟아냅니다.

05 클라이언트 대시보드 (관제 모니터) 제어 패널

🔄 실전 계좌 잔고 동기화

Why: 거래소 앱을 켜지 않고도 봇의 현재 시드 머니 상태를 직관적으로 파악하기 위함.

How: 원클릭으로 비트겟 REST API를 호출하여 최신 총 자산 및 가용 USDT를 대시보드에 즉시 렌더링합니다.

📡 실시간 오더플로우 레이더

Why: 봇이 바이낸스 세력의 움직임을 제대로 스캐닝하고 있는지 1초 단위로 시각화하여 확인하기 위함.

How: 청산액과 OI 속도를 게이지바로 표시하며, 목표 임계치에 도달하거나 돌파할 경우 직각적인 시각적 알람(색상 변화 등)을 제공합니다.

🕹️ 봇 상태 및 가드레일 제어

Why: 장세가 극도로 혼탁할 때 봇의 신규 진입을 수동으로 즉시 차단하거나, 트레일링 스탑 등 생존 기믹을 ON/OFF 하기 위함.

How: 대시보드의 직관적인 토글 스위치를 통해 봇 가동/정지, 본전가드, 트레일링 스탑 기능을 클릭 한 번으로 제어합니다.

🚨 비상 마스터 탈출

Why: 붓다빔, 머스크빔 등 예상치 못한 초거대 악재 발생 시, 고민할 시간 없이 즉시 봇을 멈추고 시드를 보호하기 위한 최후의 보루.

How: 버튼 클릭 즉시 진행 중인 모든 프로세스를 중단하고 0.5초 만에 현재 포지션을 전량 시장가로 던진 뒤 봇 가동을 정지합니다.

🔪 50% 시장가 분할 청산

Why: 심리적으로 불안하거나 수익을 안전하게 확보하고 싶을 때, 수동으로 빠르게 반익절(50%)을 날려 리스크를 축소하기 위함.

How: 버튼 클릭 시 400172 스마트 수량 가드 알고리즘을 거쳐 안전하게 절반의 포지션을 즉시 시장가 청산합니다.

🎯 스마트 스탑 & 목표가 알림

Why: 폐하께서 자리를 비우시거나 주무실 때, 미리 지정해 둔 핵심 지지/저항선이 뚫렸을 경우 시드를 방어하거나 원하는 타점에서 신호를 받기 위한 '절대 방어선'입니다.

How: 대시보드 UI 하단에서 특정 가격(USDT)을 입력하고 기능을 활성화해 두면, 시스템이 백그라운드에서 0.1초 단위의 실시간 틱을 감시합니다.

▹ [목표가 알림 모드]: 시세가 해당 가격에 도달하는 즉시 스마트폰(텔레그램)으로 경고 푸시 알림을 쏘아 차트 확인 타이밍을 알려줍니다.
▹ [스마트 스탑 모드]: 시세가 지정 가격에 닿거나 관통하는 그 즉시 0.5초 이내에 보유 중인 전량 포지션을 시장가로 강제 청산(손절/익절)하고, 텔레그램으로 비상 청산 내역을 즉각 보고하여 치명적인 손실을 원천 차단합니다.

06 환경 설정 (Configuration) 상세

🌍 세션별 설정 (Session Config)

Why: 아시아(ASIA), 런던(LONDON), 뉴욕(NY) 장은 시간대별로 세력의 변동성과 거래 대금이 완전히 다릅니다. 따라서 각 장의 특성에 맞춰 돌파 임계치(청산액, OI속도)의 컷오프 라인을 다르게 적용하여 최적의 변곡점 타점을 잡기 위함입니다.
How: 설정 탭에서 각 세션별로 청산 목표 임계치와 OI 속도 임계치를 개별적으로 입력하고 저장합니다.

⚙️ 트레이딩 핵심 설정 (Core Trading Config)

Why: 레버리지 배율, 1회 투입 비중(USDT), 방향성(롱 전용/숏 전용/양방향) 등 자본금 운용의 가장 중요한 뼈대와 방향을 설정하기 위함입니다.
How: 거래를 원하는 레버리지 수치를 세팅하고, 진입 시 사용할 고정 USDT 금액을 입력합니다. 안전 장세를 위해 롱만 칠 것인지, 숏만 칠 것인지도 선택 가능합니다.

🛡️ 가드레일 설정 (Guardrail Config)

Why: 수익 중인 포지션이 물려버리는 어처구니없는 상황을 방지하고, 수익을 극대화하기 위해 '생존 기믹'의 디테일을 조율하기 위함입니다.
How:
▹ 본전가드: 수익률이 몇 %에 도달했을 때 켤 것인지 (예: 5% 도달 시 가동)
▹ 트레일링 스탑: 수익률이 몇 %에 도달했을 때부터 고점 추적을 시작하고, 고점 대비 몇 % 하락 시 익절을 날릴 것인지 세밀하게 세팅합니다.

📱 알림 설정 (Notification Config)

Why: 폐하께서 어디에 계시든 스마트폰 하나로 봇의 모든 진입/청산 상황과 비상사태를 0.1초 만에 실시간으로 보고받기 위함입니다.
How: 텔레그램 봇 토큰(Token)과 챗 ID(Chat ID)를 입력해두면, 시스템이 1/2/3차 타점, 익절, 손절, 가드레일 발동 내역을 텔레그램으로 직송합니다.

08 🛠️ 유지보수 가이드 (Troubleshooting)

오류 발생 시 개발자가 가장 먼저 확인해야 할 원포인트 점검 가이드입니다.

  • 증상: 비트겟 주문이 안 나가거나 에러가 뜸 (예: 400172)
    해결: shinseon_server.py의 execute_bitget_internal_packet() 함수 내부를 확인하십시오. 잔여 수량(size) 처리 로직과 marginMode 파라미터가 정확히 들어갔는지 점검해야 합니다.
  • 증상: 오더플로우 깃발(LONG/SHORT) 방향이 엉뚱하게 뜰 때
    해결: shinseon_server.py의 process_1m_data_and_trade() 함수 내 Case A, B, C, D 분기문을 확인하십시오. price_slope_1m(EMA 기울기), oi_delta_1m, long_liq vs short_liq 3중 부호 판단이 백서와 일치하는지 대조해야 합니다.
  • 증상: 클라이언트와 AWS 서버 간 로그 동기화가 끊어짐
    해결: shinseon_server.py의 start_socket_server() 및 client_handler() TCP 소켓 유지 로직을 점검하십시오. 또한 클라이언트 측의 QTimer 재연결 로직이 정상 작동하는지 확인합니다.
  • 증상: 평시 또는 50% 돌파 시 CSV 파일이 저장되지 않음
    해결: core_logic.py 내부의 백그라운드 스레드인 check_radar_signal_dynamic() 함수의 _write_csv() 호출부 예외 처리(try-except) 로그를 확인하십시오.
