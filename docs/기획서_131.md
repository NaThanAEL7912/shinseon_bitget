# ShinSeon Bitget 기획서_131 (비트겟 체결 API 3대 팩트 파서 교정 및 일별 통계 100% 복원 완공)

## 📌 개요
AWS 서버 환경 및 비트겟 거래소 API 응답 규격 팩트를 정밀 수색하여 발굴한 **3대 불일치 버그(대문자 API키, `tradeSide: close`, `profit` 손익금 필드)**를 완벽 교정하여, 누적 상세 보고서 팝업창 및 전광판에 비트겟 실제 매매 실적이 100% 선명하게 출력되도록 수술합니다.

---

## 🔍 [3대 팩트 버그 및 정밀 수술안]

### 1. 🔑 대문자 API 키 파라미터 호환 로더 수술
- **원인:** AWS `server_config.json`의 키명이 `BITGET_API_KEY`, `BITGET_SECRET_KEY`, `BITGET_PASSPHRASE` (대문자)로 지정되어 있어 소문자 전용 로더가 API 키 읽기에 실패함.
- **수술:** 대문자/소문자(`BITGET_API_KEY`, `bitget_api_key`, `api_key` 등) 100% 호환 파서로 서버 거래소 인스턴스(`bot_core.bitget_exchange`) 생성을 정공법으로 보증.

### 2. 🎯 비트겟 체결 구분 필터 (`tradeSide == "close"`) 정격 교정
- **원인:** 비트겟 선물 API의 실제 청산 체결 구분값 팩트는 **`tradeSide: "close"`** 임에도 기존 코드가 `close_long`/`close_short`만 대조하여 청산 체결건이 0건으로 필터링 유실되었음.
- **수술:** `tradeSide`가 `"close"`, `"close_long"`, `"close_short"` 이거나 `reduceOnly: True` 인 청산 건을 100% 정격 수집하도록 완공.

### 3. 💵 실제 체결 손익금(`profit`) 및 ROE 정밀 반영
- **원인 및 수술:** 비트겟 API의 실제 체결 손익금 필드인 `t.get("info", {}).get("profit")` (예: `"-0.2204"` USDT) 값을 직접 정밀 파싱하여, 일별 통계 로그 파일(`logs/trade_stats_YYYY-MM-DD.json`)에 승, 패, 손익금, 승률, 평균 ROE를 100% 오차 없이 정확히 저장 및 클라이언트 팝업 표에 렌더링 완공 (V5.30).
