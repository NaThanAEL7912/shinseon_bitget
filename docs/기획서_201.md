# 기획서 201: CSV 헤더 중복(2줄) 제거 및 엑셀 100% 한글 정격(UTF-8 BOM 원천 복원) 완치 수술

## 📌 1. 개요 및 원인 분석
- **현상 (헤더 2줄 중복 및 한글 `?쉽떽(KST)` 뭉개짐 지속):**
  - **폐하의 어명 제보:** *"그리고 한글로 안보인다. 그리고 2줄이 되버렸냐"*
  - **헤더 2줄 중복 팩트 원인:** 기존 소독 스크립트 실행 과정에서 깨진 기존 헤더 행을 완벽히 잘라내지 못하고 상단에 새 헤더를 덧붙여 **Row 1과 Row 2에 헤더가 2줄로 들어간 팩트**이옵니다.
  - **한글 깨짐(`?쉽떽`) 지속 팩트 원인:** 파이썬 `open(path, "a", encoding="utf-8-sig")` 함수는 파일 추가 모드(`"a"`)일 때 파일 맨 앞에 BOM(`\xef\xbb\xbf`)을 주입하지 않습니다. 이로 인해 엑셀이 파일을 열 때 UTF-8을 인식하지 못하고 ANSI(CP949)로 오역하여 한글을 뭉개버린 팩트이옵니다.
- **목적:**  
  1. CSV 파일의 Row 1에 **오직 1줄의 선명한 한글 헤더**만 남기고 중복 및 깨진 헤더를 100% 원천 삭제합니다.
  2. 파이썬 파일 쓰기 시 바이너리 모드(`"wb"`, `"ab"`)로 **첫 3바이트에 `\xef\xbb\xbf` BOM 식별자를 고정 정격 주입**하여 엑셀 오픈 시 100% 깨짐 없는 한글로 완치시킵니다.
