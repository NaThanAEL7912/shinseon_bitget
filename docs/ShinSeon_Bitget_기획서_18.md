# ShinSeon_Bitget 기획서 #18

## 1. 개요 및 목적
- **현상 1**: 세션/트레이딩 핵심 설정 대화상자에서 세션별 1분 누적 청산액(예: 아시아 $100,000, 미국 $300,000 등)이나 수동 임계치를 설정하더라도, 대시보드의 `[雷達] 실시간 오더플로우 레이더` 게이지 표기가 `$2.0M` (2,000,000 달러)로 하드코딩되어 고정되어 있는 버그 발생.
- **현상 2**: 클라이언트 대시보드 설정 창에서 설정값을 변경하고 `[적용 및 저장]`을 눌러도, 변경된 파라미터가 AWS 서버엔진으로 전송되지 않는 현상.
- **현상 3**: 웹소켓 실시간 UI 수신 시 대시보드 오더플로우 레이더 타이틀 영역에 현재 진행 중인 장세 정보(예: `🟡 유럽 장세 (KST 19:40:51)`)가 표기되지 않고 누락되는 현상.
- **목적**: 
  1. 웹소켓 실시간 UI 수신부(`update`, `ui_update`) 및 대시보드 갱신 로직에서 하드코딩된 `$2.0M` 문자열을 제거하고, 폐하께서 설정하신 세션별 임계치 및 수동 임계치 설정값이 실시간 게이지 최대 범위(Range) 및 포맷 텍스트에 연동되도록 정공법으로 수정.
  2. 클라이언트에서 설정 변경 시 웹소켓 신호(`CMD_UPDATE_CONFIG`)를 통해 AWS 서버엔진으로 변경된 세션 임계치/배팅 비율/손절선 등을 실시간으로 동기화 적용.
  3. AWS 서버 및 클라이언트 웹소켓 수신부에 실시간 장세 정보(`current_session`: 예 `🟡 유럽 장세 (KST 19:40:51)`) 전송 및 레이더 타이틀 영역(`lbl_radar_title`) 실시간 표기 연동.

## 2. 세부 개발 및 수정 계획

### [클라이언트 수정: `shinseon_client.pyw`]
1. **웹소켓 메시지 수신부 하드코딩 제거 및 장세 표기 추가 (Lines 1193, 1208-1216)**
   - `update` 및 `ui_update` 이벤트 수신 시 `self.bar_liq.setFormat(...)` 하드코딩 제거.
   - 수동 임계치 체크 여부에 따라:
     - **수동 임계치 체크 시**: `self.edit_target_liq` 입력값 사용
     - **체크 해제 시**: 현재 활성화된 세션의 `session_thresholds[current_session]['liq']` 목표 청산금액 사용
   - `self.bar_liq.setRange(0, int(target_liq))` 및 `self.bar_liq.setFormat(...)` 에 실시간 반영.
   - `ui_update` 수신 시 `session` / `current_session` 파라미터를 파싱하여 `self.lbl_radar_title`에 `● 바이낸스 1분 청산 (🟡 유럽 장세 (KST 19:40:51))` 형태로 실시간 업데이트.

2. **서버 동기화 웹소켓 명령 송신 (`CMD_UPDATE_CONFIG`)**
   - `apply_and_save` 실행 시 `{"cmd": "CMD_UPDATE_CONFIG", "config": ...}` 메시지를 AWS 서버로 전송.

### [서버 수정: `shinseon_server.py`]
1. **웹소켓 브로드캐스트 데이터에 장세 정보 포함**
   - `ui_update` 패킷 송신 시 `session` (`current_session_name`) 문자열 포함하여 클라이언트로 전달.
2. **`CMD_UPDATE_CONFIG` 커맨드 수신 처리 신설**
   - 클라이언트로부터 수신받은 최신 세션 임계치 및 트레이딩 파라미터를 서버 봇 엔진(`v35_engine`) 및 `shinseon_config.json`에 즉시 반영.
