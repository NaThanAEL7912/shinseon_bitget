# ShinSeon Bitget 기획서_119

## 📌 개요
실전 매매 완료 시 누적/금일 트레이딩 실적(승/패/손익/ROE%)이 서버에 기록되지 않거나 클라이언트 전광판 및 상세 보고서 팝업에 실시간 반영되지 않던 문제를 원천 해결합니다. 모든 청산 지점에 실적 동기화 로직을 장착하고 웹소켓 연결 시 서버 자동 통계 수신을 완공합니다.

---

## 🎯 서버/클라이언트 실적 동기화 수술 항목

1. **`shinseon_server.py` 청산 전 루틴 실적 기록 및 브로드캐스트 장착**
   - 1차 분할익절, 반대 신호 쿨타임 시장가 청산, 스탑로스 손절, 가드레일 익절, 추적 익절, 원격 비상 청산 등 모든 청산 발생 지점에서 `record_trade_history_event(...)` 정격 호출 장착.
   - 청산 기록 후 접속된 클라이언트에 `EVT_SYNC_STATS` 패킷 브로드캐스트 송출.
   - 클라이언트 접속 완료 시 (`CMD_REQ_STATS_DETAIL`) 저장된 최신 통계를 즉시 응답 전송.

2. **`shinseon_client.pyw` 초기 접속 및 실시간 통계 수신 연동**
   - 웹소켓 연동 성공 시(`on_open`) 즉시 서버에 `CMD_REQ_STATS_DETAIL` 자동 요청 전송.
   - `EVT_SYNC_STATS` 이벤트 수신 시 상단 `[🏆 누적 실적]` 전광판, `[📅 금일 실적]` 전광판, 및 누적 상세 보고서 팝업 표 데이터 100% 자동 실시간 갱신.

3. **검증, 서버 데몬 재가동 및 클라이언트 푸시 (V5.19)**
   - `py_compile` 검증 후 서버 `ubuntu@13.192.187.244` 업로드 및 데몬 재가동.
   - `python deploy.py V5.19` 실행으로 Git 배포.
