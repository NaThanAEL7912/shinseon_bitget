# ShinSeon Bitget 기획서_130 (서버 직접 거래소 체결 이력 수집 및 일별 실적 저장소 정공법 완공)

## 📌 개요
폐하의 엄격하신 원칙에 따라 **모든 매매 실적 데이터 및 일별 통계 로그 파일(`logs/trade_stats_YYYY-MM-DD.json`)의 수집/저장 주체는 오직 AWS 릴레이 서버**가 담당하며, 클라이언트는 서버에 저장된 실적 정보를 불러와 팝업창에 렌더링만 수행하도록 수술합니다.

---

## 🎯 정공법 수술안 (서버 단독 거래소 스캔 & 실적 저장 완공)

### 1. 🔑 서버 거래소 인스턴스 (`bitget_exchange`) API 키 정격 연동
- 클라이언트 접속 패킷(`CMD_UPDATE_CONFIG` 및 접속 프레임) 수신 시, 클라이언트의 비트겟 API 키 정보(`bitget_api_key`, `bitget_secret_key`, `bitget_passphrase`)를 서버의 `bot_core.bitget_exchange` CCXT 인스턴스에 즉시 정격 할당.
- 서버 독립적으로 비트겟 선물 API(`fetch_my_trades`) 조회가 100% 항상 성공하도록 정공법 세팅.

### 2. ⚡ 서버 직접 비트겟 체결 복원 및 일별 실적 파일 저장
- 팝업창 `[🔄 실시간 새로고침]` 클릭 시 서버가 비트겟 최근 7일치(100건) 체결 내역을 **서버에서 직접 조회**.
- 서버가 일별 통계 로그 파일(`logs/trade_stats_YYYY-MM-DD.json`) 및 요약 파일(`logs/trade_stats_summary.json`)에 **누락된 거래 짝을 100% 직접 복원 및 저장**.

### 3. 🖥️ 클라이언트 순수 불러오기 렌더링
- 서버가 저장을 마치고 전송한 `EVT_SYNC_STATS` 응답 데이터를 받아 클라이언트 팝업 표 **상단 [일자별 매매 실적 요약]** 및 **하단 [선택 날짜 개별 거래 상세 세부 리스트]**에 선명하게 렌더링 완공 (V5.29).
