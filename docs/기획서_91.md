## 2. 세부 수술 내역 (일별 로그 분리 & 대시보드 다운로드 연동)

### 가. AWS 서버 일별 날짜 로그 자동 회전 로깅 엔진 (`shinseon_server.py`)
- 로그 생성 경로: `/home/ubuntu/logs/shinseon_trade_YYYY-MM-DD.log`
- 매일 00:00:00(KST) 날짜가 바뀌는 순간 새로운 날짜의 로그 파일이 자동으로 분리 생성되며 이력이 무기한 보존됩니다.
- 진입 사유, 청산 사유, 체결 내역, 쿨타임(15s/300s/900s), API 예외, 파라미터 변경 이력이 0.001초 단위로 적재됩니다.

### 나. WebSocket 서버 로그 파일 목록 조회 및 다운로드 패킷 연동 (`shinseon_server.py`)
- `CMD_REQ_LOG_LIST`: 서버에 보관된 일자별 로그 파일 목록(예: `["2026-08-06", "2026-08-05"...]`)을 브로드캐스팅 수신.
- `CMD_REQ_LOG_FILE`: 폐하께서 선택하신 특정 날짜 로그 파일 전문을 0.001초 만에 클라이언트로 직송 전송 (`EVT_LOG_FILE_DATA`).

### 다. 클라이언트 대시보드 전용 [📂 서버 일별 로그 다운로드 센터] UI 구축 (`shinseon_client.pyw`)
- 메인 대시보드 상단 패널에 **`[📂 서버 트레이딩 로그 관리]`** 버튼 추가.
- 대화상자(QDialog) 팝업:
  - 📅 **일자별 로그 목록 창**: 클릭 한 번으로 이전 날짜 선택 가능.
  - 📥 **`[내 PC로 다운로드]`** 버튼: 다운로드 폴더 자동 저장 & 즉시 텍스트 뷰어 열람 기능.
