# [기획서 43] 바이낸스 찐청산 금액 실시간 로그 기록 및 AWS KST 세션 수술 (V4.46)

## 1. 개요 및 요구사항 분석
- **폐하의 어명:**
  1. 바이낸스 1분 누적 청산 중 실제로 찐청산(`forceOrder`) 패킷이 수신되면, 얼만큼 청산되어 들어왔는지 로그 창에 실시간 기록을 남길 것.
  2. 현재 한국 시각 새벽 `04:37 KST` (미국 본장 시간)임에도 `유럽 장세`로 잘못 표시되던 AWS 세션 시각 계산 로직을 수술할 것.

---

## 2. 상세 수술 및 원천 복구 계획 (V4.46)

###가. 바이낸스 찐청산 발생 시 실시간 금액 로그 기록 수술 (`shinseon_server.py`, `shinseon_client.pyw`)
1. 바이낸스 `forceOrder` 찐청산 패킷 수신 시, 발생 금액 및 포지션 방향(LONG/SHORT)을 실시간으로 포매팅하여 로그 전송:
   - 포맷 예시: `💥 [바이낸스 찐청산 포착] SHORT 청산 $45,447 발생! (1분 누적: $348,866)`
2. 클라이언트 대시보드 하단 로그 창에 찐청산 포착 내역이 명확히 촥 릴레이 수신되도록 수술.

###나. AWS KST 시각 기준 미국 본장 세션 연동 수술 (`shinseon_server.py`)
1. **원인 팩트:** AWS EC2 인스턴스의 시스템 시각이 UTC로 세팅되어 있어, `now_dt.hour` 연산 시 KST 변환 전의 UTC 시각(19시)을 그대로 가져와 유럽 장세로 오인 표시하던 맹점 발견.
2. **수술 내역:**
   - KST 시각(`kst_dt = datetime.utcnow() + timedelta(hours=9)`)을 기준으로 `kst_hour * 60 + kst_minute`를 완전 재계산.
   - 현재 새벽 `04:37 KST` 시각에 **`🟢 미국 본장 (KST 04:37:09)`**이 100% 정상 표시되도록 원천 수술.

###다. 소신(안티그래비티) 직접 수술 및 배포
1. 버전을 `V4.46`으로 지정.
2. 소신이 직접 소스코드 세션 시각 및 찐청산 로깅 수술 집행.
3. `deploy.py V4.46` 실행하여 Commit & GitHub main push.
4. AWS 서버 및 V4.46 대시보드 구동 후 미국 본장 100% 정상 표시 및 찐청산 금액 실시간 로그 릴레이 최종 검증.
