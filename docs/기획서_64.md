# [기획서 64] 버튼 클릭 시 3단계 실시간 상세 보고 로그 체계 구축 및 수동 제어판 비주얼 통합 완공 수술 (V4.64)

## 1. 개요 및 폐하의 명철하신 어명 분석
- **폐하의 어명:**
  "그리고 버튼을 클릭하면 로그에 50%머 청산을 합니다. 뭐라 말이라도 있어야 햐는거 아니냐?
  그리고 이상이 있으면 이상이 있다. 청산 되고 나면 청산 되었습니다. 보고 이런게 있어야지 아니 뭐 이래
  그리고 이전엔 있었는데 이전꺼 자로 분석해봐"

- **소신의 이전 버전 팩트 분석 및 개편 목표:**
  1. 이전 성공 버전에서는 버튼을 클릭하는 즉시 **[1단계: 개시 알림] $\rightarrow$ [2단계: 진행 중 API 전송 알림] $\rightarrow$ [3단계: 최종 성공/실패 팩트 보고]**의 3단계 단계별 실시간 로그가 실시간 로그창에 생생하게 남았었습니다.
  2. 그러나 최근 파라미터 개편 과정에서 일부 조건문이나 패킷 처리 루프에서 실시간 로그가 누락되는 현상이 적출되었습니다.
  3. 폐하의 어명에 따라, **`🌓 50% 청산` 및 `🛡️ 스마트 스탑 설정` 등 수동 제어판의 모든 버튼 클릭 시 100% 실시간 3단계 단계별 로그(개시 -> 진행 -> 성공/실패 사유)를 로그창에 실시간 보고**하도록 완전 수술합니다.

## 2. 상세 수술 및 배포 계획 (V4.64)

### 가. 50% 청산 3단계 실시간 상세 보고 시스템 구축 (`shinseon_client.pyw` & `shinseon_server.py`)
1. **[1단계: 클릭 즉시 개시 보고]**
   - `🚀 [수동 50% 청산 발동] 비트겟 포지션 50% 분할 시장가 청산 명령을 집행합니다.`
2. **[2단계: 진행 상황 보고]**
   - `📡 [서버 릴레이] AWS 서버로 50% 청산 명령 패킷(CMD_CLOSE_50) 직송 전송 중...`
   - `🎯 [비트겟 v2 API 직송] 50% 청산 발주 준비 완료 (대상 수량: {amount} BTC)`
3. **[3단계: 최종 결과 팩트 보고 (성공/오류 상세 사유)]**
   - **성공 시:** `✅ [50% 청산 완료] 비트겟 {amount} BTC 시장가 청산 성공! (남은 포지션 유지 중)`
   - **오류 시:** `❌ [50% 청산 오류 발생] 사유: {error_code/error_msg}`

### 나. 스마트 스탑 설정 3단계 실시간 상세 보고 시스템 구축 (`shinseon_client.pyw` & `shinseon_server.py`)
1. **[1단계: 클릭 즉시 개시 보고]**
   - `🛡️ [스마트 스탑 설정 개시] ROE 오프셋: {offset:+.2f}%, 청산 비율: {ratio:.0f}% 감시 가드를 설정합니다.`
2. **[2단계: 상태 판정 보고]**
   - `📡 [서버 릴레이] AWS 서버에 스마트 스탑 감시 오프셋({offset:+.2f}% ROE) 동기화 전송 중...`
3. **[3단계: 가동 완공 보고]**
   - `✅ [스마트 스탑 가동 완료] 비트겟 실전 포지션에 {offset:+.2f}% ROE 손절/익절 감시 가드가 작동되었습니다!`

### 다. 수동 제어판 버튼 비주얼 개편
- `🌓 50% 청산`: 선명한 오렌지/앰버 액티브 스타일 (`#D97706` $\rightarrow$ `#B45309`) + `PointingHandCursor` + `pressed` & `clicked` 2중 바인딩
