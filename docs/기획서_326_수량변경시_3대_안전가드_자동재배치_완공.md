## 1. 🎯 [기획 배경 및 폐하의 절대 어명]
- 폐하께서 수동 주문 또는 추가 매수(물타기/불타기)로 인해 **보유 포지션의 수량(`contracts`)이나 평단가(`entry_price`)가 변경**되었을 때:
  1. 기존에 거래소에 걸려있던 구형 TP/SL 플랜 주문들을 **비트겟 REST API(`cancel-plan-order`)로 0.001초 만에 100% 전량 자동 취소(청소)**하고,
  2. **새롭게 갱신된 최종 평단가와 총 보유 수량을 기준으로 3대 안전 가드(1차 TP 50% / 2차 TP 50% / SL 손절방패 100%)**를 거래소에 즉시 자동 재배치한다.
  3. '자동 봇 시작' 버튼의 ON/OFF 여부와 무관하게 24시간 상시 감시 및 자동 호위를 보장한다.

## 2. 🔍 [핵심 동작 로직 및 방어 설계]

1. **상태 변이 감지 인터셉터:**
   - `last_guarded_pos = {"entry_price": X, "contracts": Y, "side": Z}` 상태 메모리 보유.
   - 포지션 동기화(`handle_sync_position` 및 3초 주기 `sync_bitget_real_position_status`) 시:
     - **조건:** 신규 포지션이거나, 기존 대비 **수량(`contracts`)이 변경**되었거나, **평단가(`entry_price`)가 변경**되었을 때 (`abs(prev_contracts - contracts) > 0.00001` or `abs(prev_entry - entry_price) > 0.1`)
2. **2단계 자동 재배치 파이프라인:**
   - **1단계 (기존 플랜 전량 정화):** 비트겟 REST API `/api/v2/mix/order/orders-plan-pending` 조회 후 남아있는 기존 미체결 TP/SL 플랜 주문들을 `/api/v2/mix/order/cancel-plan-order`로 즉시 취소.
   - **2단계 (신규 3대 안전가드 발주):**
     - **1차 TP (50%):** 새 평단가 기준 세션 TP1 가격 (`planType: profit_plan`, `size: contracts * 0.5`)
     - **2차 TP (50%):** 새 평단가 기준 세션 TP2 가격 (`planType: profit_plan`, `size: contracts * 0.5`)
     - **SL 방패 (100%):** 새 평단가 기준 세션 손절선 가격 (`planType: pos_loss`, 전체 포지션 100% 방패)
3. **무포지션/전량 청산 시 자동 정화:**
   - 포지션이 0개(무포지션)로 확인되면 기존에 남아있는 모든 예약 플랜 주문을 즉시 100% 자동 캔슬하여 잔여 오더 방지.
