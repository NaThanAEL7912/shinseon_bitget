신선 (神選) 백서

바이낸스 선물 오더플로우 세력 추적 & 비트겟 자동 저격 시스템 (박호두 레퍼럴 수수료 50% 할인 검증)

01 시스템 개요 (Overview)

🚀 오더플로우 저격 봇 '신선'의 정의

신선(神選)은 전 세계 최대 유동성을 보유한 바이낸스(Binance) USDT-M 선물 시장의 초단위 오더플로우(청산 물량 + 미결제약정 OI)를 실시간 감시하여, 대형 세력의 시장가 돌파 폭격을 감지하고 비트겟(Bitget) 선물 시장에서 초고속으로 동시 저격 포지션을 진입/청산하는 완벽한 무감정 기계 매매 시스템입니다.

순수 +OI 기관 자금 추적
Strict +OI Filtering

음수(-OI) 잔파도를 100% 걸러내고 세력의 신규 자금 폭발 시점에만 정밀 타격.

2단계 계단식 공격 가드
Dual Multi-Stage TP

1차 50% 익절 락인 ➔ 2차 50% 피크 올킬로 수익 극대화 및 리스크 제로화.

수수료 50% 할인 실질 순수익 검증
BakHodu 0.030% Net Profit

박호두 레퍼럴 50% 할인을 반영하여 수수료 차감 후 순수 현금 수익 극대화.

02 하이브리드 인프라 아키텍처

🏛️ AWS 서버 데몬 & 로컬 PC 관제 센터 2-Tier 구조

AWS 초고속 서버가 24시간 365일 무중단으로 바이낸스 웹소켓을 감시하고 즉각 비트겟 API로 발주하며, 로컬 PC에서는 GUI 클라이언트를 통해 실시간 텔레메트리 관제 및 원격 제어를 수행합니다.

[AWS Cloud Server] 백엔드 엔진
  • 바이낸스 웹소켓: BTCUSDT 1초 단위 실시간 체결, 청산, OI 수신
  • 세션별 독립 판단 엔진: 아시아, 유럽, 미국, 주말 4대 세션별 독립 임계치 자동 판정
  • 비트겟 REST API 발주: 시장가 초고속 저격 및 TP/SL 가드레일 제어
  • 초고밀도 CSV 딥다이브: 1초 단위 전수 데이터 24시간 로컬 영구 로깅
[Local PC] 관제 대시보드 (PySide6)
  • 실시간 텔레메트리 렌더링: 1초 간격 청산액, OI속도, EMA 기울기, 포지션 PnL 동기화
  • 세션별 독립 파라미터 제어: 레버리지, 1차/2차 배팅 비중, 쿨타임 동적 수정 및 영구 저장
  • 실전 계좌 원클릭 동기화: 비트겟 잔고 및 현재 포지션 상태 실시간 갱신
  • 비상 탈출 (Emergency): 0.5초 즉시 전량 시장가 청산 및 봇 정지 지원

03 핵심 판단 대헌법 (오더플로우 매트릭스)

📌 절대 진입 대헌법: 1분 누적 청산액이 세션 목표치 이상 AND 1분 OI 속도가 반드시 순수 양수(+OI)인 순간에만 진입합니다.
oi_delta_1m > 0 AND oi_delta_1m >= target_oi

📊 1단계: 순수 +OI 2대 정통 돌파 저격 매트릭스

Case 1분 EMA 추세 기울기 (price_slope_1m) 1분 OI 속도 (oi_delta_1m) 롱/숏 청산 주도 비율 2차 검증 오더플로우 팩트 (세력의 의도) 신선 포지션
Case C 지속 상승 ( > 0 ) 증가 ( > 0 ) short_liq ≥ long_liq (숏 청산 돌파) 세력이 숏 청산 먹으며 신규 매수 폭발. 상승 추세 돌파. LONG (매수) 🟢
Case D 지속 하락 ( < 0 ) 증가 ( > 0 ) long_liq ≥ short_liq (롱 청산 돌파) 세력이 롱 청산 먹으며 신규 숏 폭발. 하강 추세 돌파. SHORT (매도) 🔴
기각 -OI(음수) 잔파도, 임계치 미달, 청산 주도 세력 불일치 시 위험 휩쏘 및 개미 손절 잔파도 100% 원천 차단. NONE (휴식) ⚪️

⚔️ 2단계: 2단계 계단식 공격 가드 (Dual Offensive TP Guard)

  • 1단계 공격 가드 (1차 50% 익절 락인): 1차 목표 수익률 도달 시 보유 수량의 50%를 시장가로 즉시 익절하여 확정 수익을 챙깁니다.
  • 무손실 방어선 전진: 1차 익절 직후 잔여 50% 수량의 손절선을 본전가(0.00%) 또는 수익 버퍼로 상향하여 '절대 1원도 잃지 않는 무위험 상태'로 전환합니다.
  • 2단계 공격 가드 (2차 50% 피크 올킬): 2차 목표 수익률 도달 시 잔여 수량 전량 시장가 올킬 청산으로 대추세를 100% 싹쓸이합니다.
  • 초고속 쿨타임 (Fast Rotation): 익절 쿨타임 10초 / 손절 쿨타임 30초로 설정하여, 익절 후 10초 만에 다음 황금 파도에 초고속 재탑승합니다.
