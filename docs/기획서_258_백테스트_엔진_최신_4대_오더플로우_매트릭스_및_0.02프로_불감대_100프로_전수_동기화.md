# 기획서 258: 백테스트 코어 엔진, 최신 [4대 완성형 오더플로우 매트릭스 & 0.02% 동적 불감대] 100% 전수 동기화 수술

## 1. 개요 및 배경
폐하의 지극히 날카로우신 어명(**"이 백테스터에 지금까지 개발된 최신 로직이 모두 정확하게 적용된 것이 맞느냐?"**)을 받들어 엔진 코드를 정밀 감사한 결과, 초기 백테스터 엔진에 과거 단순 판정(`oi > 0`)이 잔존해 있어, **최근 완공된 [4대 오더플로우 매트릭스: 음수 OI V자 반등 롱 / 역V자 덤핑 숏] 및 [0.02% 5초 동적 불감대 필터]**가 완벽하게 반영되지 않았던 차이를 발견하였습니다. 이에 실전 운영 서버(`core_logic.py`, 백서 V7.03)와 1원/1틱의 오차도 없이 100% 동일하게 전수 동기화 수술을 단행합니다.

## 2. 실전 서버 100% 동기화 4대 오더플로우 매트릭스 명세

```mermaid
graph TD
    A[1초 틱 데이터: 청산액, 1분 OI속도, 5초 가격변동 delta_5s, 1분 기울기] --> B{1. 필수 하드 게이트 검사}
    B -->|1분 청산 >= target_liq AND abs(1분OI) >= target_oi AND abs(delta_5s) >= 0.02%| C{2. 4대 완성형 매트릭스 판정}
    B -->|미달| X[진입 기각 / 대기]
    
    C -->|1. 숏청산 + (+OI) + delta_5s >= +0.02% + 기울기 >= 0| D[🟢 1️⃣ 추세 돌파 롱]
    C -->|2. 롱청산 + (+OI) + delta_5s <= -0.02% + 기울기 <= 0| E[🔴 2️⃣ 추세 돌파 숏]
    C -->|3. 롱청산 + (-OI) + delta_5s >= +0.02% (반등턴)| F[🟢 3️⃣ V자 바닥 반등 롱 🏹]
    C -->|4. 숏청산 + (-OI) + delta_5s <= -0.02% (꺾임턴)| G[🔴 4️⃣ 역V자 천장 덤핑 숏 🏹]
    
    D --> H[비트겟 실전과 100% 동일한 2단계 분할익절 & 본전가드 & 손절 시뮬레이션]
    E --> H
    F --> H
    G --> H
```

### 1) [진입 3대 하드 게이트 100% 동기화]
1. `1m_Rolling_Liq >= target_liq` (세션별 청산액 기준치)
2. `abs(1m_OI_Speed) >= target_oi` (양수/음수 상관없이 절대 속도 기준치)
3. `abs(delta_5s) >= 0.02%` (최근 5초간 가격 변동폭이 최소 0.02% 이상인 명확한 추세/반등만 진입)

### 2) [4대 완성형 오더플로우 매트릭스 100% 동기화]
| 번호 | 전략 유형 | 청산 조건 | OI 속도 | 5초 가격 변동 (delta_5s) | 1분 기울기 | 최종 진입 방향 |
|:---:|:---|:---:|:---:|:---:|:---:|:---:|
| **1️⃣** | **추세 돌파 롱** | 숏 청산 >= target_liq | `+OI (양수)` | `>= +0.02%` | `>= 0` | 🟢 **LONG** |
| **2️⃣** | **추세 돌파 숏** | 롱 청산 >= target_liq | `+OI (양수)` | `<= -0.02%` | `<= 0` | 🔴 **SHORT** |
| **3️⃣** | **V자 바닥 반등 롱** | 롱 청산 >= target_liq | `-OI (음수)` | `>= +0.02% (반등)` | 무관 | 🟢 **LONG 🏹** |
| **4️⃣** | **역V자 천장 덤핑 숏**| 숏 청산 >= target_liq | `-OI (음수)` | `<= -0.02% (하락)` | 무관 | 🔴 **SHORT 🏹** |

### 3) [청산 및 가드레일 실전 서버 1:1 동기화]
- **1차 50% 분할 익절**: 목표 수익률 도달 시 50% 물량 시장가 확정
- **무위험 본전/보존 가드**: 1차 익절 완료 즉시 손절선을 `본전/버퍼가드`로 상향 이동
- **2차 올킬 전량 청산**: 2차 목표치 도달 시 잔여 50% 전량 청산
- **최초 손절선**: 진입 후 세션별 손절폭(-0.6% ~ -1.3%) 도달 시 100% 즉시 시장가 손절
- **반대신호 전환 청산**: 60초 쿨다운 경과 후 반대방향 4대 신호 발생 시 즉시 탈출
