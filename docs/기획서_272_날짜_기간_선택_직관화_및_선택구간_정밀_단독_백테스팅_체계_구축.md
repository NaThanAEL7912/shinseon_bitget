# 기획서 272: 날짜 기간 선택 직관화 및 선택 구간 정밀 단독 백테스팅 체계 구축

## 1. 개요 및 배경
- 폐하의 지엄하신 지적: "선택한 기간 것만 백테스팅되어야 하는데 전부 다 된다."
- 현황 및 원인 분석:
  1. 현재 `QDateTimeEdit` 위젯이 초단위(`06:15:05`, `20:43:51`)까지 복잡하게 얽혀 있어, 달력에서 날짜를 고를 때 직관적이지 않고 원치 않는 과거 날짜(8/10 등)가 남아 광범위한 기간(11일치 전체 57회 거래)이 시뮬레이션됨.
  2. 사용자가 원하는 직관적인 날짜 선택: 달력에서 시작일(예: 8/17)과 종료일(예: 8/21)을 콕 찍으면 해당 일자의 `00:00:00`부터 `23:59:59`까지 오직 그 기간만의 데이터로 정밀 단독 백테스팅이 수행되어야 함.

---

## 2. 세부 개발 계획

### 1) 📅 날짜 선택 UI 혁신적 직관화 (달력 원클릭 선택)
- 시작 일시 / 종료 일시 선택창을 초단위 번잡함을 없애고, **달력에서 날짜를 마우스로 찍으면 시작일 `00:00:00` ~ 종료일 `23:59:59`로 자동 정밀 바인딩**.
- 날짜를 변경하는 즉시 우측에 **`[📌 선택 기간: N일간 (MM/DD ~ MM/DD, 데이터 약 M만건)]`** 실시간 안내 라벨 표출.

### 2) 🚀 직관적인 빠른 날짜 선택 프리셋 버튼 재배치
- `[전체 기간 (8/7~8/24)]` / `[최근 3일]` / `[최근 1주일]` / `[지난 주 평일 (8/17~8/21)]` / `[주말 (8/22~8/23)]` 등 명확한 일자 버튼 제공.

### 3) 🎯 선택 구간 100% 엄격 필터링 보장
- 백테스트 실행 시 폐하께서 선택하신 시작일 00:00:00 ~ 종료일 23:59:59 범위 밖의 틱과 거래는 단 1건도 침범하지 못하도록 엄격 차단.
- 거래 상세 일지 상단에 `최초 거래 일시`와 `최종 거래 일시`를 명시하여 선택 구간만 정밀 연산되었음을 시각적으로 검증.
