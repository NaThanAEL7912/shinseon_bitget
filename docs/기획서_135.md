# ShinSeon Bitget 기획서_135 (CSV 엑셀 한글 BOM 인코딩 교정 및 초(:SS) 타임스탬프 일괄 완치 완공)

## 📌 개요
엑셀(Excel)에서 CSV 파일을 열었을 때 한글 헤더 깨짐 현상과 타임스탬프에 초(`:SS`)가 누락되던 버그를 정밀 수술하여, **`utf-8-sig` (BOM 포함) 인코딩 정공법 교정 및 타임스탬프 `YYYY-MM-DD HH:MM:SS` (초 단위 포함)** 으로 기존/신규 CSV 데이터를 100% 완치 완공합니다.

---

## 🎯 2대 정밀 수술안

### 1. 🌐 엑셀 100% 한글 호환 `utf-8-sig` (BOM) 강제 지정
- **원인 팩트:** 엑셀은 BOM이 없는 UTF-8 CSV 파일을 열 때 한글 글자를 깨뜨려 표현함 (`?십떆(KST)` 등).
- **수술 팩트:** 모든 CSV 쓰기/수정 엔진의 파일 저장 인코딩을 **`utf-8-sig` (BOM 포함 UTF-8)** 로 100% 픽스하여 엑셀에서 한글 헤더가 선명하고 완벽하게 노출되도록 보증.

### 2. ⏱️ 타임스탬프 초(`:SS`) 단위 자동 보정 및 정격 출력
- **원인 팩트:** 기존 기록 데이터 일부에 초(`:SS`)가 누락된 `2026-08-07 6:14` 형식으로 작성되어 엑셀에 초 단위가 빠져 노출되었음.
- **수술 팩트:**
  - 신규 기록 시 `YYYY-MM-DD HH:MM:SS` (초 단위 포함)으로 100% 정격 생성.
  - 기존 파일 로딩 시 초가 누락된 행(`2026-08-07 06:14`)을 자동 감지하여 **`2026-08-07 06:14:00` (초 `:00` 추가)**으로 일괄 변환 덮어쓰기 완공 (V5.34).
