# [기획서 73] 포지션 유무 동적 버튼 연동 가드 & AWS 서버 정격 응답 로그 직송 마스터 기획서 (V4.73)

## 1. 개요 및 폐하의 어명 분석
- **폐하의 어명:**
  1. "내가 현재 포지션이 없는데 50% 시장가 분할 청산 클릭을 했어... 아무런 답변이 없어"
  2. "그리고 포지션이 없는데 왜 저게 클릭이 되는것도 오류지?"
  3. "스마트 스탑 설정은 여전히 클릭이 안돼 클릭해도 아무런 반응이 없어"

- **소신의 수술 목표:**
  1. **포지션 유무 동적 버튼 가드 (`has_position` 연동):**
     - 포지션이 없을 때(`100% 현금 대기 중`)는 `🌓 50% 시장가 분할 청산` 및 `🛡️ 스마트 스탑 설정` 버튼을 **자동 비활성화(`setEnabled(False)`)** 처리하고, 만약 누르더라도 **`⚠️ [청산 불가] 현재 비트겟 포지션이 없어 50% 분할 청산을 집행할 수 없습니다.`** 명확한 경고 로그를 출률합니다.
     - 포지션이 진입되면 즉시 버튼을 **자동 활성화(`setEnabled(True)`)**하여 클릭 가능하게 전환합니다.
  2. **AWS 서버 응답 전용 패킷(`EVT_RESPONSE_LOG`) 이식:**
     - 기존 `ui_cb`로 전송되어 `레이더 피드 ➡️`로 찌그러져 출력되던 포맷을 전면 개조하여, 서버의 정격 처리 결과를 **`📡 [서버 응답] ...` 0.001초 직송 로그로 대시보드에 선명하게 출력**합니다.

## 2. 세부 작동 아키텍처 및 구현 계획

### 가. 클라이언트 포지션 상태 연동 (`shinseon_client.pyw`)
- `EVT_SYNC_POSITION` 수신 시 `has_position` 값에 따라 버튼 동적 제어:
  - `has_position == False` 인 경우:
    - `btn_close_50.setEnabled(False)` / 툴팁: `현재 활성화된 포지션이 없습니다.`
    - `btn_stoploss.setEnabled(False)` / 툴팁: `현재 활성화된 포지션이 없습니다.`
  - `has_position == True` 인 경우:
    - `btn_close_50.setEnabled(True)`
    - `btn_stoploss.setEnabled(True)`

### 나. 50% 청산 & 스마트 스탑 클릭 핸들러 예외 가드
- 포지션 미보유 시 클릭 시도 시 즉시 경고 로그 반환:
  - `⚠️ [청산 불가] 현재 보유 중인 포지션이 없어 50% 분할 청산을 집행할 수 없습니다. (100% 현금 대기 중)`
  - `⚠️ [스마트 스탑 불가] 현재 보유 중인 포지션이 없어 스마트 스탑을 가동할 수 없습니다. (100% 현금 대기 중)`

### 다. AWS 서버 응답 패킷 전송 구조화 (`shinseon_server.py`)
- `CMD_CLOSE_50` 수신 시 서버에서 클라이언트로 즉시 `EVT_RESPONSE_LOG` 송신:
  - 포지션 없음: `📡 [서버 응답] ⚠️ 현재 비트겟에 활성화된 포지션이 없어 50% 청산 명령을 스킵합니다.`
  - 소액 전량 청산 완료: `📡 [서버 응답] ℹ️ 수량이 최소 발주 단위(0.001 BTC) 이하이므로 0.0009 BTC 전량 시장가 청산을 완료했습니다.`
  - 50% 분할 청산 완료: `📡 [서버 응답] ✅ 비트겟 50% 시장가 분할 청산 완료`
- `CMD_SET_SMART_STOP` 수신 시:
  - 가동 등록 시: `📡 [서버 응답] 🛡️ AWS 서버 실시간 스마트 스탑 오프셋(+6.00% ROE) 등록 완료`
  - 가동 해제 시: `📡 [서버 응답] 🧹 AWS 서버 스마트 스탑 감시가 해제되었습니다.`
