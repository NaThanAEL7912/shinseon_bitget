# [기획서 45] 신규 순수 청산 발생액 실시간 로그 분리 포매팅 (V4.48)

## 1. 개요 및 요구사항 분석
- **폐하의 어명:**
  1. 기존 로그(`💥 [바이낸스 청산포착] SHORT 1분 누적 청산: $231,592`)는 1분 총 누적액일 뿐이므로, **'지금 방금 새로 발생한 청산 금액'**을 명확히 표시할 것.
  2. 1분 총 누적액과 방금 터진 신규 청산 발생액을 명확히 분리하여 직관적인 로그를 작성할 것.

---

## 2. 상세 수술 및 원천 복구 계획 (V4.48)

###가. 신규 순수 청산 발생액(`delta_liq`) 실시간 연산 및 로그 포매팅 수술 (`shinseon_client.pyw`, `shinseon_server.py`)
1. **신규 청산 발생액(`delta_liq`) 산출:**
   - 1분 누적액 변화분(`현재 누적액 - 이전 누적액`) 또는 실시간 새로 포착된 단일 청산 체결액(`usd_val`)을 '신규 발생 청산액'으로 즉시 연산합니다.
2. **폐하 지시 전용 명확한 로그 포맷 개편:**
   - 포맷 예시:
     `💥 [바이낸스 청산포착] SHORT 신규 청산 $45,200 발생! (1분 누적: $231,592)`
   - 찐청산 시 포맷 예시:
     `💥 [바이낸스 찐청산] SHORT 찐청산 $45,200 발생! (1분 누적: $231,592)`

###나. 소신(안티그래비티) 직접 수술 및 배포
1. 버전을 `V4.48`로 지정.
2. 소신이 직접 소스코드 신규 청산액 연산 및 로깅 수술 집행.
3. `deploy.py V4.48` 실행하여 Commit & GitHub main push.
4. AWS 서버 및 V4.48 대시보드 구동 후 신규 청산 발생액(예: `$45,200`)과 1분 누적액($231,592) 분리 명시 100% 최종 검증.
