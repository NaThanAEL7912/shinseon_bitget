# [기획서_357] 실시간 목표가 가격 알림 GUI 강제 리프레시 및 시각화 배지 개편 기획서 (V7.65)

## 1. 개요 및 원인 분석
- **현상**: 폐하께서 대시보드 우측 하단 `[BITGET] 실시간 목표가 가격 알림`에 `65000.0`을 입력하고 `[ 🔔 알림 등록 ]` 버튼을 클릭하셨으나, 로그에는 등록 메시지가 찍히는데 하단 상태 라벨이 `🔔 감시 중인 알림 없음`으로 그대로 남아있어 등록이 안 눌러진 것처럼 보임.
- **원인 분석**:
  1. `add_price_alert()` 실행 시 Qt 이벤트 루프에서 `self.lbl_active_price_alerts` 라벨의 강제 리페인트(`repaint()`) 및 리프레시 처리가 누락되어 텍스트 갱신이 씹힘.
  2. 등록 후 입력창(`edit_price_alert_target`)이 비워지지 않고, 등록 성공에 대한 시각적 피드백(하이라이트 배지)이 미비하여 폐하께서 등록 여부를 즉각 인지하기 어려움.
  3. 초당 수신되는 `update_live_ui` 틱 갱신 과정에서 알림 텍스트 갱신이 UI 메인 스레드 안전성 보장을 받지 못함.

## 2. 정밀 해결책 및 개발 명세

### 1) [`shinseon_client.pyw`](file:///C:/Working/ShinSeon_Bitget/shinseon_client.pyw) 가격 알림 GUI 전면 개편
1. **강제 리프레시 및 입력창 자동 초기화**:
   - `add_price_alert()` 등록 성공 시 `self.edit_price_alert_target.clear()`로 입력창을 즉시 초기화하고 포커스를 유지.
   - `update_price_alert_ui()` 내에서 `self.lbl_active_price_alerts.repaint()` 및 스타일시트 동적 하이라이트 적용.
2. **시각적 배지(Badge) & 명확한 감시 상태 표출**:
   - 알림이 없을 때: 회색/어두운 금색 `⚪ [알림 대기] 등록된 목표가 알림이 없습니다.`
   - 알림이 있을 때: 에메랄드/네온 그린 투톤 박스 `🔔 [실시간 감시 중 1건] $65,000.0 (▼ 하강 돌파)`로 크고 선명하게 표출.
3. **버튼 클릭 시 즉각적인 시각 피드백**:
   - `[ 🔔 알림 등록 ]` 클릭 시 0.2초간 버튼 텍스트가 `✅ 등록 완료!`로 바뀌었다가 복귀하도록 하여 즉각적인 반응성 체감 제공.
4. **버전 삼위일체 V7.65 갱신**:
   - `shinseon_client.pyw`, `shinseon_server.py`, `shinseon_config.json`, `docs/shinseon_whitepaper.html` 버전을 `V7.65`로 갱신.
