# [기획서 386] 황실 콕핏 스토캐스틱 RSI 및 다이버전스 독립 전용 카드 분리 신설 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 빨간 펜으로 3중 Stoch RSI 뱃지를 감싸시며 **"이 부분만 따로 떼내자. 오더플로우 아래에다가 넣고 새로운 박스를 해줘, 그리고 다이버전스 출력되는 부분도 추가로 넣어줘 어차피 아래 여백이 많으니까"**라는 명확하고 탁월하신 UI 분리 지시를 내리심.
  - 기존에는 오더플로우 레이더 카드 안에 스토캐스틱 신호등과 오더플로우 바가 함께 섞여 있어 다소 복잡했음.

- **목적**:
  1. `[실시간 오더플로우 레이더]` 카드에서 Stoch RSI를 분리하고, 순수한 **3대 AND 오더플로우 힌트 및 청산/OI 수급 전용 카드**로 정돈.
  2. 오더플로우 카드 바로 아래에 **`[ 📊 스토캐스틱 RSI & 다이버전스 관제 ]` 신규 독립 카드(QFrame.card)**를 신설.
  3. 신설된 전용 카드에 **3중 Stoch RSI 신호등 바 + 5m/15m 스마트 다이버전스 전용 상태 뱃지**를 상하로 배치하여 완벽한 시각적 독립성과 최고급 관제탑 뷰 완성.
  4. 콕핏 버전을 **V1.06**으로 순차 상향 및 이력 관리 대장 등재.

---

## 2. 세부 개발 명세

### ① 카드 1: [ 🌊 실시간 오더플로우 레이더 카드 ]
- 구성:
  - 헤더: `🌊 [실시간 오더플로우 레이더] | 세션 정보 | 🔔 사운드 알림`
  - 오더플로우 3대 AND 힌트 뱃지: `[ 🟢 지금은 롱이 유리하다 (3대 AND 동조) ]` / `[ 🔴 지금은 숏이 유리하다 ]` / `[ ⚪ 지금은 관망이 유리하다 ]`
  - 실시간 임계치 직접 수정 바: `⚙️ 임계치: 청산 $ [ 600000 ] | OI [ 0.12 ] % [ 💾 적용 ]`
  - 프로그레스바 1: `1분 누적 청산: $XX / $600,000`
  - 프로그레스바 2: `1분 OI 속도: +0.XXXX% / +0.1200%`

### ② 카드 2 (신설!): [ 📊 스토캐스틱 RSI & 다이버전스 관제탑 ]
- 구성:
  - 헤더: `📊 <b style='color:#C084FC;'>[스토캐스틱 RSI & 다이버전스]</b> <span style='color:#94A3B8; font-size:10px;'>(1m · 5m · 15m)</span>`
  - 1열: `[ 1m Stoch: 8.4% 🟢 ] [ 5m Stoch: 92.6% 🔴 ] [ 15m Stoch: 96.6% 🔴 ]` (3중 신호등 뱃지)
  - 2열: `[ 5m/15m 스마트 다이버전스 전용 뱃지 (self.lbl_div_badge) ]`
    - `[ 🔥 5m+15m 강력 하락 다이버전스! (숏 저격) ]` (불꽃 레드)
    - `[ 🔥 5m+15m 강력 상승 다이버전스! (롱 저격) ]` (불꽃 그린)
    - `[ ⚠️ 15m 하락본세 vs 5m 단기반등 충돌! (관망) ]` (경고 앰버)
    - `[ ⚠️ 15m 상승본세 vs 5m 단기눌림 충돌! (관망) ]` (경고 앰버)
    - `[ 🐻 15m/5m 하락 다이버전스 감지! ]` / `[ 🐂 15m/5m 상승 다이버전스 감지! ]`
    - `[ ⚪ 다이버전스 대기 중 (5m/15m 차트 관측 중) ]`

### ③ 콕핏 전용 버전 V1.06 갱신
