## 📌 개요
폐하의 엄중하신 어명(**"OI값이랑 복합 계산해야지 왜 청산 값으로만 롱숏 또 판단하냐고"**)에 따라, 단편적인 청산액 비교를 완전 폐기하고 **OI 미결제약정 자금 유입/유출 부호(`oi_delta_1m`)와 롱/숏 청산 볼륨(`long_liq`, `short_liq`)을 2차원 복합 계산하는 정공법 방향성 엔진**을 구축하여 완치 수술을 집행합니다.

## 📐 [OI ✕ 청산 복합 판정 정공법 매트릭스]

### 1. 💡 OI 부호 ✕ 청산 볼륨 복합 팩트
- **Case 1: `OI >= 0` (플러스 자금 유입 세션)**
  - `long_liq >= short_liq` (롱 개미 털기 + 자금 유입): 세력 저점 롱 매집 ➡️ **`LONG` (매수)**
  - `short_liq > long_liq` (숏 개미 털기 + 자금 유입): 세력 숏 스퀴즈 ➡️ **`SHORT` (매도)**
- **Case 2: `OI < 0` (마이너스 자금 유출 세션)**
  - `long_liq >= short_liq` (롱 지지선 무너짐 + 자금 이탈): 대형 폭포수 하락 ➡️ **`SHORT` (매도)**
  - `short_liq > long_liq` (숏 쇼트커버링 + 자금 이탈): 반등 숏커버 ➡️ **`LONG` (매수)**

### 2. 🛡️ 수술 코드 팩트 (V5.60)
```python
# [OI + 청산 복합 판정 엔진 (V5.60)]
if oi_delta_1m >= 0:
    direction = "LONG" if long_liq >= short_liq else "SHORT"
else:
    direction = "SHORT" if long_liq >= short_liq else "LONG"
```
