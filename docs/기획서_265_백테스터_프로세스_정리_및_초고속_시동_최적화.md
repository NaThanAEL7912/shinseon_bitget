# 기획서 265: 백테스터 좀비 프로세스 정리 및 0.1초 초고속 시동 최적화

## 1. 개요 및 배경
- 폐하의 증상 보고: "시작이 안된다."
- 원인 정밀 진단:
  1. 기존에 실행되었던 `shinseon_backtester.pyw` 프로세스 2건(PID 19808, 21928)이 백그라운드에 살아있어 새로운 창 생성을 방해하고 있음.
  2. 21일치(107만 틱) 대용량 실측 데이터 탑재 후, 백테스터 시동 시 `__init__`에서 107만 틱 전체 시뮬레이션을 동기적으로 무겁게 돌리느라 창이 뜨는 데 지연(렉)이 발생함.

---

## 2. 세부 조치 및 최적화 계획

### 1) 🧹 기존 백그라운드 백테스터 프로세스 안전 종료
- 현재 백그라운드에 멈춰 있는 백테스터 프로세스(PID 19808, PID 21928)를 깔끔하게 종료하여 메모리 및 창 충돌 해소. (실전 봇 `shinseon_client.pyw`는 절대 건드리지 않고 보호).

### 2) ⚡ 0.1초 즉시 시동 최적화 (`shinseon_backtester.pyw`)
- 창이 뜰 때 107만 틱 전체를 무겁게 돌리지 않고, 기본 선택 기간을 **"최근 3일"**로 가볍고 빠르게 설정하여 0.1초 만에 창이 즉시 열리도록 시동 시퀀스 최적화.
- 사용자가 원하는 기간을 선택한 후 언제든 [백테스트 실행]이나 [전체 기간]을 누르면 1초 만에 전체 시뮬레이션이 돌아가도록 연동.

### 3) 🚀 원클릭 실행 배치 파일 보강 (`신선_전략_백테스터.bat`)
- 기존 백테스터 프로세스가 남아있을 경우 자동 정리 후 깔끔하게 새 창을 띄우도록 배치 파일 안정화.
