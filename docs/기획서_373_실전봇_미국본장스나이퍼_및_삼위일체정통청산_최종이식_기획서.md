# 0단계: 세력 자금 필수 유입 검사

    if (price_delta_5s >= 0.0) and (price_delta_1m >= 0.0) and (price_slope_1m >= 0.0):
        direction = "LONG"
    elif (price_delta_5s <= 0.0) and (price_delta_1m <= 0.0) and (price_slope_1m <= 0.0):

### 3️⃣ 반대 신호 시 100% 전량 정통 청산 (Close to Flat)
- 롱 보유 중 유효 `SHORT` 발생 시 ➔ 롱 100% 즉시 시장가 전량 청산 (현금 100% 복귀).
- 숏 보유 중 유효 `LONG` 발생 시 ➔ 숏 100% 즉시 시장가 전량 청산 (현금 100% 복귀).
