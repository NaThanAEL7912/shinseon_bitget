# 📋 기획서 252: 신선(SHINSEON) 차세대 3대 고도화 전략 로드맵 기획서

---

## 🎯 1. 개요 및 배경
- **현 상태 (V6.50):**  
  현재 신선(SHINSEON) 자동매매 시스템은 **바이낸스 1분 청산액 + 1분 `+OI` 세력 자금 유입 + 15초 반감기 EMA 기울기 + 4대 세션별 독립 매트릭스(비중/레버리지/임계치) + 비트겟 거래소 직송 0초 랙 프리 SL/TP 및 스마트 본전 가드레일**을 완비하여, 시장 미시구조(Orderflow) 기반의 상위 0.1% 최고급 매매 엔진으로 가동 중입니다.
- **문서 목적:**  
  현재의 강력한 공수 밸런스를 유지하면서, 향후 실전 데이터 축적 후 한 단계 더 완전무결한 퀀트 병기로 진화시키기 위한 **차세대 3대 핵심 고도화 아젠다(CVD 공격성 정합, 1분+5분 OI 듀얼 정렬, 3초 WSS 틱 프리징 킬스위치)** 를 영구 문서로 체계화하여 보존합니다.

## 🛠️ 2. 차세대 3대 고도화 상세 전략

---

### ① CVD (Cumulative Volume Delta) 시장가 공격성 정합 필터
- **시장 미시구조 원리:**  
  숏 청산 발생 및 `+OI` 증가 시에도, 대형 마켓메이커(MM)가 상단에 지정가 매도벽을 대놓고 시장가 매도(Taker Sell)를 퍼붓는 **'물량 떠넘기기(Absorption/흡수)'** 구간이 드물게 발생할 수 있음.
- **고도화 방안:**  
  - 바이낸스 실시간 체결 스트림에서 `Taker Buy Volume - Taker Sell Volume`의 실시간 델타인 **CVD가 진입 방향과 동일한 순매수(+) 상태인지 컨펌**.
  - 세력의 물량 떠넘기기(흡수) 함정을 99.9% 원천 회피.

---

### ② 1분 + 5분 OI 듀얼 타임프레임 거시 정합 (원웨이 대추세 포착)
- **시장 미시구조 원리:**  
  1분 단기 `+OI`가 급증하더라도 5분 거시 흐름이 거대한 `-OI`(자금 이탈) 상태라면 단기 반등 후 재하락할 가능성이 존재함.
- **고도화 방안:**  
  - **1분 `+OI` (단기 타점 격발) & 5분 `+OI` (거시 세력 방향 일치)** 가 동시에 충족될 때만 진입하거나 배팅 가중치를 부여.
  - 진입 후 1.5%~2.0% 이상 시원하게 뻗어 나가는 **원웨이 메가 트렌드 파동**만을 선별 타격하여 승률 및 손익비 극대화.

---

### ③ 실시간 웹소켓(WSS) 3초 틱 프리징 하드 킬스위치 (물리적 안전망)
- **시장 미시구조 원리:**  
  거래소 자체의 순간적 API 장애, 네트워크 패킷 드랍으로 틱 데이터가 멈췄을 때 잘못된 시세 기준으로 오발주되는 0.001%의 잠재 위험 차단.
- **고도화 방안:**  
  - 마지막 바이낸스/비트겟 시세 수신 시각이 **3.0초 이상 멈췄을 경우(Data Stale)** 신규 진입 발주를 즉시 자동 락(Freeze).
  - 웹소켓 정상 스트리밍이 재개되는 즉시 자동 락 해제.
