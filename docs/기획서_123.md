# ShinSeon Bitget 기획서_123 (서버-클라이언트 스마트 스탑(Smart Stop) 완전 연동 기획서)

## 📌 개요
`C:\Working\SHINSEON` 원본의 **인메모리 듀얼 방향성 스마트 스탑(Smart Stop) 엔진**을 서버(`shinseon_server.py`)에 정격 이식하여, 실시간 PnL 오프셋 도달 시 **서버가 직접 비트겟 지정 비율(50%/100%) 시장가 청산**을 0.001초 만에 집행하도록 완공하고, 클라이언트(`shinseon_client.pyw`)는 설정 패킷 송신 및 UI 비주얼 가동 역할을 수행하도록 수술합니다.

---

## 🛡️ 스마트 스탑(Smart Stop) 서버-클라이언트 동작 메커니즘

### 1. 📡 클라이언트 (`shinseon_client.pyw`) 역할
- 오프셋(%) (예: 0.3%) 및 청산 비율(%) (예: 50%) 입력값 파싱.
- `[🛡 스마트 스탑 설정]` 버튼 클릭 시:
  - 서버에 `CMD_SET_SMART_STOP` 패킷 송신: `{"active": True, "offset_val": 0.3, "ratio": 50.0}`.
  - 버튼 비주얼을 `[🟢 스마트 스탑 해제]`로 전환.
- `[🟢 스마트 스탑 해제]` 버튼 클릭 시:
  - 서버에 `CMD_SET_SMART_STOP` 해제 패킷 송신: `{"active": False}`.
  - 버튼 비주얼을 `[🛡 스마트 스탑 설정]`으로 원복.

### 2. ⚡ 서버 (`shinseon_server.py`) 역할 및 실시간 감시 엔진
- **`CMD_SET_SMART_STOP` 패킷 수신 시:**
  - 서버 봇 엔진에 `custom_stop_active = True`, `custom_stop_offset_pct = offset_val`, `custom_stop_close_ratio = ratio`, `custom_stop_set_pnl = current_pnl` 인메모리 세팅.
- **실시간 포지션 감시 루프 (매 1초 실시간 감시):**
  - **하방 손절/보존 모드 (`offset_val < custom_stop_set_pnl`):**
    - 실시간 ROE PnL이 설정 오프셋 이하로 떨어질 때 (`live_pnl <= offset_val`) ➡️ 지정 비율(50% 또는 100%) 비트겟 시장가 청산 발주!
  - **상방 반등/익절 모드 (`offset_val >= custom_stop_set_pnl`):**
    - 실시간 ROE PnL이 설정 오프셋 이상으로 상승할 때 (`live_pnl >= offset_val`) ➡️ 지정 비율 비트겟 시장가 청산 발주!
- **발동 완료 후:**
  - `custom_stop_active = False` 자동 해제 및 텔레그램/WSS 결과 로그 통지 송출.
