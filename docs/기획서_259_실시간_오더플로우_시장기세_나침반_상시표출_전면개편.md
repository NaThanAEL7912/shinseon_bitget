# 📋 기획서 259: 실시간 오더플로우 시장 기세/방향성 나침반 상시 표출 전면 개편 기획서

---

## 🎯 1. 개요 및 배경
- **폐하의 어명 및 직관:**  
  > *"이 값이 딱 판정이 났을 때만 표시가 되는데 모든걸 만족 하진 않지만 현재 라면 롱이다 숏이다 표시가 되면 좋겠다."*
- **현상 및 문제점:**  
  1. 기존 UI의 레이더 상태바(`lbl_hint`)는 청산액($650k+)과 OI속도(+0.18%+) 등 모든 필수 임계치가 100% 충족되어 실제 타점이 격발되는 찰나의 순간에만 `[ LONG ]` 또는 `[ SHORT ]`로 표시되었습니다.
  2. 평상시에는 단순히 `[ ⏳ 타점 탐색 대기 중 (조건 미충족) ]` 또는 `[ 🛡️ SHORT 포지션 보유 중 ]`으로만 고정되어 있어, **"지금 이 순간 시장의 수급과 청산, 가격 기울기가 롱 쪽으로 기울고 있는지, 숏 쪽으로 기울고 있는지"** 를 한눈에 직관적으로 파악하기 어려웠습니다.
- **개선 목표:**  
  임계치 100% 충족 여부와 관계없이, 실시간 가격 기울기(Slope), 청산 우세 비율(Long Liq vs Short Liq), OI 부호(+/-)를 매 초마다 실시간 융합 연산하여 **"현재 시장의 실시간 기세/방향성(Market Flow Bias)"** 을 상시 24시간 나침반처럼 선명하게 표출합니다.

## 🛠️ 2. 상세 작업 명세

### ① 실시간 오더플로우 시장 기세(Bias) 4대 엔진 수식 (`shinseon_server.py`, `shinseon_client.pyw`)
1. **🟢 롱(LONG) 우세:**  
   - `가격 기울기 상승(Slope > 0 또는 Delta > 0)` **AND** `숏 청산 우세(Short Liq $\ge$ Long Liq)` **AND** `+OI 유입(OI > 0)`
   - ➔ **`[ 🟢 실시간 기세: 롱(LONG) 우세 ↗ ]`**
2. **🔴 숏(SHORT) 우세:**  
   - `가격 기울기 하강(Slope < 0 또는 Delta < 0)` **AND** `롱 청산 우세(Long Liq $\ge$ Short Liq)` **AND** `+OI 유입(OI > 0)`
   - ➔ **`[ 🔴 실시간 기세: 숏(SHORT) 우세 ↘ ]`**
3. **⚠️ 롱 청산 과열 (상승 중 롱 털림 ➔ 숏 반전/휩쏘 주의):**  
   - `가격 기울기 상승(Slope > 0)` 상태이나 `롱 청산이 더 많이 터짐(Long Liq > Short Liq)`
   - ➔ **`[ ⚠️ 롱 청산 과열 (롱 털림) ➔ 숏 반전 주시 ]`**
4. **⚠️ 숏 청산 과열 (하락 중 숏 털림 ➔ 롱 반전/휩쏘 주의):**  
   - `가격 기울기 하강(Slope < 0)` 상태이나 `숏 청산이 더 많이 터짐(Short Liq > Long Liq)`
   - ➔ **`[ ⚠️ 숏 청산 과열 (숏 털림) ➔ 롱 반전 주시 ]`**
5. **⚪ -OI 청산 이탈 (관망/포지션 정리):**  
   - `OI 속도 음수(OI < 0)`
   - ➔ **`[ ⚪ -OI 포지션 정리 중 (관망) ]`**

### ② 포지션 보유 중 및 현금 대기 중 상황별 스마트 융합 표출
- **포지션 보유 중:**
  - `[ 🛡️ SHORT 보유 | 시장 기세: 숏(SHORT) 우세 📉 ]` (순풍 안심)
  - `[ 🛡️ SHORT 보유 | ⚠️ 반대 롱(LONG) 기세 유입 주의 ↗ ]` (역풍 경고)
  - `[ 🛡️ LONG 보유 | 시장 기세: 롱(LONG) 우세 📈 ]` (순풍 안심)
  - `[ 🛡️ LONG 보유 | ⚠️ 반대 숏(SHORT) 기세 유입 주의 📉 ]` (역풍 경고)
- **현금 대기 중:**
  - `[ 🟢 현재 기세: 롱(LONG) 우세 ↗ (타점 대기) ]`
  - `[ 🔴 현재 기세: 숏(SHORT) 우세 ↘ (타점 대기) ]`
  - `[ 💥 100% 임계치 돌파! 타점 진입: LONG / SHORT ]` (타점 격발 시 네온 발광)
