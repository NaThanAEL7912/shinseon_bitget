# 👑 [기획서_392] 황실 콕핏(shinseon_cockpit.pyw) 50% 분할 청산 및 비상탈출 비트겟 V2 정격 페이로드(marginMode 필수 + tradeSide=close + holdSide 충돌 제거) 완벽 이식 & V1.12 배포 기획서

---

## 1. 개요 및 배경

- **문제 상황:**
  - 콕핏 V1.11에서 `[ ✂️ 50% 시장가 분할 청산 ]` 클릭 시:
    - 1차: `22002 No position to close`
    - 2차: `400172 The margin mode cannot be empty`
- **원인 분석:**
  1. 비트겟 V2 선물 API(`/api/v2/mix/order/place-order`)에서 **`marginMode: "isolated"` (또는 "crossed")는 필수 파라미터**임 (누락 시 400172 에러 발생).
  2. V2 `place-order` 엔드포인트에서 청산 시 **`side: "buy"`(숏 청산) / `side: "sell"`(롱 청산) + `tradeSide: "close"` + `marginMode: margin_mode`**가 정격 규격이며, `holdSide` 키가 포함되면 라우터 충돌로 `22002 No position to close`가 발생함.
- **해결 방안:**
  - `marginMode`를 필수로 포함하고, `tradeSide: "close"` 정격 규격을 준수하며, 3단 다중 폴백(Multi-Fallback) 안전망을 구축하여 100% 무조건 체결 보장!
  - 버전을 **`👑 황실 수동 콕핏 V1.12`**로 갱신 배포.

## 2. 세부 개발 명세

### 1) `CLOSE_50` 로직 3단 정격 발주 엔진 구축
- `shinseon_cockpit.pyw` 내 `BitgetMainDirectWorker._process_action`:
  ```python
  elif action_type == "CLOSE_50":
      pos = self._get_active_position()
      if not pos:
          self.order_result.emit("⚠️ [50% 분할 청산] 본 계정에 보유 중인 포지션이 없습니다.")
          return
      contracts = float(pos.get('total', 0) or 0.0)
      hold_side = str(pos.get('holdSide', 'long')).lower()
      margin_mode = str(pos.get('marginMode', 'isolated')).lower()
      side_str = "LONG" if hold_side == "long" else "SHORT"
      close_side = "sell" if hold_side == "long" else "buy"
      half_qty = max(0.0001, round(contracts * 0.5, 4))
      
      success = False
      last_err = ""
      
      # 1단계: 비트겟 V2 정격 place-order (marginMode + tradeSide: close)
      try:
          res = self.exchange.private_mix_post_v2_mix_order_place_order({
              "symbol": "BTCUSDT",
              "productType": "USDT-FUTURES",
              "marginMode": margin_mode,
              "marginCoin": "USDT",
              "size": str(half_qty),
              "side": close_side,
              "orderType": "market",
              "tradeSide": "close"
          })
          if res.get("code") == "00000":
              self.order_result.emit(f"✂️ [본 계정 50% 분할 청산 성공] {side_str} {half_qty} BTC 시장가 분할 청산 체결 완료!")
              success = True
          else:
              last_err = f"{res.get('msg')} ({res.get('code')})"
      except Exception as e:
          last_err = str(e)
          
      # 2단계: reduceOnly = true 폴백
      if not success:
          try:
              res = self.exchange.private_mix_post_v2_mix_order_place_order({
                  "symbol": "BTCUSDT",
                  "productType": "USDT-FUTURES",
                  "marginMode": margin_mode,
                  "marginCoin": "USDT",
                  "size": str(half_qty),
                  "side": close_side,
                  "orderType": "market",
                  "tradeSide": "close",
                  "reduceOnly": "YES"
              })
              if res.get("code") == "00000":
                  self.order_result.emit(f"✂️ [본 계정 50% 분할 청산 성공] {side_str} {half_qty} BTC 체결 완료 (폴백)!")
                  success = True
              else:
                  last_err += f" / {res.get('msg')} ({res.get('code')})"
          except Exception as e:
              last_err += f" / {e}"

      # 3단계: CCXT create_order 폴백
      if not success:
          try:
              self.exchange.create_order(
                  'BTC/USDT:USDT',
                  'market',
                  close_side,
                  half_qty,
                  params={'tradeSide': 'close', 'holdSide': hold_side, 'marginMode': margin_mode, 'marginCoin': 'USDT'}
              )
              self.order_result.emit(f"✂️ [본 계정 50% 분할 청산 성공] {side_str} {half_qty} BTC 체결 완료 (CCXT)!")
              success = True
          except Exception as e:
              last_err += f" / {e}"

      if not success:
          self.order_result.emit(f"❌ [50% 분할 청산 실패] {last_err}")
  ```
