# 👑 [기획서_393] 황실 콕핏(shinseon_cockpit.pyw) 2단 안전방패 & 본전가드 클릭 시 기존 미체결 TP/SL 플랜 주문 100% 자동 전수 취소 후 신규 재배치 정화 엔진 탑재 & V1.13 배포 기획서

## 1. 개요 및 배경

- **문제 상황:**
  - 콕핏에서 `[ 🛡️ 2단 안전방패 (TP/SL) ]` 또는 `[ 🛡️ 무위험 본전가드 (BE Shield) ]` 클릭 시, 기존에 등록되어 있던 구형 TP/SL 플랜 주문(예: 1.0 BTC 기준 스탑로스)이 취소되지 않고 그대로 남아있어, 신규 수량(2.0 BTC) 기반 주문과 중복되거나 꼬이는 현상 발생.
- **원인 분석:**
  - `BE_SHIELD` 및 `AUTO_GUARD` 실행 시 비트겟 거래소에 걸려있는 기존 TP/SL 플랜 주문(`orders-plan-pending`) 목록을 조회하여 전수 취소(`cancel-plan-order`)하는 사전 정화(Purge) 루틴이 누락되어 있었음.
- **해결 방안:**
  - `_cancel_all_tpsl_plan_orders()` 전용 헬퍼 함수를 신설.
  - `BE_SHIELD` 및 `AUTO_GUARD` 클릭 시 **1) 기존 대기 중인 모든 TP/SL 플랜 주문 전수 취소 ➔ 2) 현재 최신 보유 수량 및 평단가 기반 신규 TP/SL 정밀 재배치** 2단계 파이프라인 완비.
  - 버전을 **`👑 황실 수동 콕핏 V1.13`**으로 갱신 배포.

## 2. 세부 개발 명세

### 1) 미체결 TP/SL 플랜 주문 전수 취소 헬퍼 함수 신설
- `BitgetMainDirectWorker` 클래스 내:
  ```python
  def _cancel_all_tpsl_plan_orders(self):
      """비트겟 본 계정에 대기 중인 모든 미체결 TP/SL 플랜 주문 전수 취소"""
      try:
          res = self.exchange.private_mix_get_v2_mix_order_orders_plan_pending({
              'symbol': 'BTCUSDT',
              'productType': 'USDT-FUTURES',
              'planType': 'profit_loss'
          })
          entrusted = (res.get('data') or {}).get('entrustedList') or []
          for o in entrusted:
              oid = o.get('orderId')
              plan_type_val = o.get('planType') or 'profit_plan'
              if oid:
                  try:
                      self.exchange.private_mix_post_v2_mix_order_cancel_plan_order({
                          'symbol': 'BTCUSDT',
                          'productType': 'USDT-FUTURES',
                          'marginCoin': 'USDT',
                          'orderId': str(oid),
                          'planType': plan_type_val
                      })
                  except Exception:
                      pass
      except Exception:
          pass
  ```

### 2) `AUTO_GUARD` 및 `BE_SHIELD` 실행 시 사전 취소 연동
- `AUTO_GUARD` 및 `BE_SHIELD` 발주 직전에 `self._cancel_all_tpsl_plan_orders()`를 먼저 호출하여 기존 잔여 플랜 주문을 100% 깨끗이 삭제한 후 신규 주문 전송!
