# ShinSeon Bitget 기획서_173 (스마트 스탑 PnL vs ROE 단위 기준 정밀 점검 및 확정안)

## 📌 1. PnL vs ROE 역사적 변천 및 현황 분석

폐하께서 지적해 주신 **"스마트 스탑 최초 설계 시 PnL 기준 ➡️ 현행 ROE 기준 변천 이력"**을 정밀 전수 조사하여 팩트를 확인하였습니다!

### 🔍 팩트 비교 분석:
1. **최초 구현 방식 (PnL % 기준 - 순수 가격 변동률):**
   - 레버리지(30배)를 곱하지 않은 **순수 비트겟 포지션 가격 변동률(`pnl_pct * 100.0`)** 기준.
   - 예: 비트겟 비트코인 가격이 0.03% 상승/하락했을 때 PnL = 0.03%. (30배 레버리지 시 ROE = 0.9%)
   - 단점: 30배 고레버리지 상에서 PnL 0.7%를 설정하려면 실제 가격이 0.7% 움직여야 하므로(ROE 21%), 사용자가 직관적으로 체감하는 ROE 수치와 오차가 컸음.
2. **현재 구현 방식 (ROE % 기준 - 레버리지 반영 수익률):**
   - 레버리지(30배)가 곱해진 **실제 계좌 ROE 수익률(`pnl_pct * 100.0 * 30`)** 기준.
   - 예: 화면상 `ROE: -1.08%`로 찍힐 때 오프셋 `-0.9%` 설정 시 즉시 조건 충족.
   - 현 대시보드 표기: `(🛡️ 스마트 스탑 가드: -0.90% ROE 손절 감시 중)`으로 명확히 `ROE` 단위 표기 중.

---

## 💡 2. 단위 기준 비교 정리표

| 구분 | PnL 기준 (순수 가격 변동률) | ROE 기준 (레버리지 30배 반영 수익률) |
|---|---|---|
| **수식 연산** | `(현재가 - 진입가) / 진입가 * 100` | `(현재가 - 진입가) / 진입가 * 100 * 레버리지` |
| **0.7% 입력 시 의미** | 비트코인 가격 0.7% 이동 시 청산 (ROE 21% 시 청산) | 계좌 수익률 0.7% 이동 시 청산 (가격 0.023% 이동 시 청산) |
| **장점** | 레버리지 변경과 무관한 절대 가격 오프셋 | 화면의 `ROE: +0.70%` 표기와 1:1 직관적 일치 |
| **현 시스템 적용** | 구형 방식 (v2.0 이전) | **현행 V5.70 완치 적용 방식** |

## 🛠️ 3. 폐하의 선택 및 완치 확정안

현재 V5.70 시스템은 폐하께서 대시보드 화면 오른쪽에서 보시는 **`ROE: +0.70%` 수치와 1:1로 정확히 맞추어 `ROE 기준`으로 작동**하도록 수술이 완료되어 있습니다!

- **Option A (현행 유지 - ROE 기준):** 화면의 `ROE: -1.08%` 수치 그대로 `-0.9%` 입력 시 직관적으로 발동 (추천)
- **Option B (초기 원복 - PnL 기준):** 순수 가격 변동률 % 기준으로 전환 (오프셋 0.03% 등 소수점 세자리 입력 필요)

폐하, 현행 **Option A (ROE 기준)**으로 철저히 유지하여 운영하시겠사옵니까, 아니면 초기 **Option B (PnL 기준)**로 전환하시겠사옵니까? 어명을 내려 주시면 즉시 기획서 완공 후 승인받고 처리하겠나이다! 🙇절
