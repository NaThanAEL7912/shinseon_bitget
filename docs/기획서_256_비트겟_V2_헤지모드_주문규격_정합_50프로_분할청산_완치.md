## 🎯 1. 개요 및 배경
- **현상 및 문제점:**  
  폐하께서 대시보드의 **`[ 🌓 50% 시장가 분할 청산 ]`** 버튼을 클릭하셨으나, 서버 로그에서 비트겟 API로부터 `❌ [50% 청산 예외]: bitget {"code":"22002","msg":"No position to close"}` 에러가 반환되며 분할 청산이 실패하는 현상이 지속되었습니다.
- **원인 정밀 규명 (AWS 실전 API 패킷 테스트로 100% 입증):**  
  1. 일반적인 현물/타 거래소 규격에서는 "롱 포지션 청산 = 시장가 매도(`side: sell`)"로 작동합니다.
  2. 그러나 **비트겟 V2 선물 헤지 모드(`USDT-FUTURES / hedge_mode`)** 규격에서는:
     - **`side`는 포지션의 방향 자체를 의미**합니다 (`buy` = Long 포지션, `sell` = Short 포지션).
     - **`tradeSide`가 진입/청산 액션을 결정**합니다 (`open` = 신규 진입, `close` = 청산).
     - **`holdSide`가 보유 방향을 명시**합니다 (`long` 또는 `short`).
  3. 따라서 **롱(LONG) 포지션을 분할 청산할 때** 비트겟 API에 `side: "sell"`을 전달하면, 비트겟은 "숏 포지션(`sell`)을 청산(`close`)하려는데 보유한 숏 포지션이 없다(`holdSide: long`과 불일치)"로 판정하여 `22002 No position to close` 에러를 뿜었던 것입니다.
  4. **실제 테스트 검증 완료:**
     - 롱 분할 청산: `side: "buy", tradeSide: "close", holdSide: "long"` ➔ `00000 success` 즉각 체결!
     - 숏 분할 청산: `side: "sell", tradeSide: "close", holdSide: "short"` ➔ `00000 success` 즉각 체결!
