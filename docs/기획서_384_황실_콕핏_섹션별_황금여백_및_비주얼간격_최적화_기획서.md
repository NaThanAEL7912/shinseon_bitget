# [기획서 384] 황실 콕핏 6개 화살표 섹션별 황금 여백 및 비주얼 간격 최적화 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 스크린샷에 6개의 빨간 화살표를 직접 표시해 주시며 **"내가 표시한 곳들의 여백을 좀 줘라"**는 비주얼 밸런스 개선 어명을 내리심.
  - 진단 결과: 상단 공백을 제거하는 과정에서 각 카드 사이의 간격(`setSpacing(6)`)이 너무 좁아져 카드들이 다닥다닥 붙어 답답해 보이는 현상이 발생함.

- **목적**:
  1. `main_layout.setSpacing(12)` 및 여백 조율을 통해 폐하께서 화살표로 지정하신 **6개 구간의 간격을 기존의 2배(12px~14px)로 시원하게 확장**.
  2. 답답함을 완전히 해소하고 시각적 독립성을 확보한 최고급 럭셔리 대시보드 레이아웃 구축.
  3. 콕핏 버전을 **V1.04**로 순차 상향 및 이력 관리 대장 등재.

---

## 2. 세부 개발 명세

### ① 6개 지정 섹션 간격 12px 황금 여백 적용
```python
main_layout = QVBoxLayout(central_widget)
main_layout.setAlignment(Qt.AlignTop)
main_layout.setContentsMargins(12, 12, 12, 12) # 상하좌우 쾌적한 12px 마진
main_layout.setSpacing(12)                      # 6개 카드 사이 12px 황금 여백!
```
- 적용되는 6대 황금 간격:
  1. 👑 상단 헤더 ↔ 🌊 레이더 카드 사이 간격: `12px`
  2. 🌊 레이더 카드 ↔ 🚀 빠른 주문 카드 사이 간격: `12px`
  3. 🚀 빠른 주문 카드 ↔ 📊 본 계정 HUD 카드 사이 간격: `12px`
  4. 📊 본 계정 HUD 카드 ↔ 🛡️ 안전 방패 카드 사이 간격: `12px`
  5. 🛡️ 안전 방패 카드 ↔ 📉 스마트 스탑 카드 사이 간격: `12px`
  6. 📉 스마트 스탑 카드 ↔ 📜 하단 미니 로그창 사이 간격: `12px`

### ② 기본 윈도우 크기 최적화
- `self.resize(500, 840)` 설정으로 6개 여백이 모두 적용된 상태에서 스크롤 없이 완벽 렌더링.

### ③ 콕핏 전용 버전 V1.04 갱신
- `self.COCKPIT_VERSION = "V1.04"` 및 `VERSION = "V1.04"`
- 윈도우 타이틀: `[SHINSEON] 황실 수동 콕핏 V1.04 (가로 500px 초슬림 · 비트겟 직통)`
