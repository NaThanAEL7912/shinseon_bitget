## 2. 상세 수술 및 원천 복구 계획 (V4.60)

###가. `🌓 50% 청산` WSS 원격 전송 통로 신설 (`shinseon_client.pyw`, `shinseon_server.py`)
1. **클라이언트 송신 (`shinseon_client.pyw`):**
   - `trigger_close_50()` 클릭 시 `cmd: "CMD_CLOSE_50"` WSS 패킷을 AWS 서버로 즉시 전송합니다.
2. **서버 수신 및 50% 시장가 청산 집행 (`shinseon_server.py`):**
   - AWS 서버 WebSocket 루프에 `elif cmd == "CMD_CLOSE_50":` 핸들러를 신설하고, 비트겟 API 50% 분할 시장가 청산(`execute_bitget_internal_packet(side="CLEAR", order_type="50_PERCENT_CLOSE")`)을 0.001초 만에 발주합니다.

###나. 소신(안티그래비티) 직접 수술 및 배포
1. 버전을 `V4.60`으로 지정.
2. 소신이 직접 50% 청산 원격 WSS 패킷 전송 수술 집행.
3. `deploy.py V4.60` 실행하여 Commit & GitHub main push.
4. AWS 서버 및 V4.60 대시보드 구동 후 4개 기능 100% 완벽 작동 전수 검증 마감.
