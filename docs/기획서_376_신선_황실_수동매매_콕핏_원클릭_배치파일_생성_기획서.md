## 2. 배치 파일 (`신선_수동매매_콕핏.bat`) 설계 명세

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"
echo ====================================================
echo  [SHINSEON] Starting Shinseon Cockpit Widget (500px)...
echo ====================================================
echo.
echo  1. Checking for latest version updates...
python shinseon_updater.py --no-start
if %errorlevel% neq 0 (
    echo.
    echo ====================================================
    echo  [ERROR] Updater execution failed!
    echo ====================================================
    echo.
    pause
) else (
    start "" pythonw shinseon_cockpit.pyw
)
exit
```
