# 기획서 262: 신선 백테스팅 봇 3차 최종 QA - 모든 경우의 수(진입/청산/방어) 소스코드 1:1 정밀 교차 검증

## 1. 개요 및 배경
폐하의 지엄하신 세 번째 어명("신선 봇의 모든 경우의 진입, 청산 로직을 확인하고 백테스트 봇이 제대로 개발되어 있는지 꼼꼼하게 검증하라")을 받들어, 실전 운영 서버(`core_logic.py`)의 모든 엣지 케이스(총 14개 시나리오)가 백테스트 엔진(`backtest_engine.py`)의 소스코드에 1:1로 단 하나의 누락도 없이 완벽하게 이식되었는지 코드 레벨에서 정밀 교차 감사(Code Audit)를 수행합니다.

---

## 2. 14대 엣지 케이스 검증 시나리오 및 체크리스트 (검증 결과)

### 🟢 [A. 진입 (Entry) 로직]
1. **[Case 1, 2] 진입 방향 결정**: `청산액 >= 기준치` & `OI >= 기준치` 달성 시 `숏 청산 >= 롱 청산` 여부로 롱/숏 판정
   - **결과**: ❌ 불일치 발견 (과거 4대 매트릭스인 5초 델타/OI 부호 잔재 발견) ➔ 🛠️ **수정 완료** (실전 `core_logic.py`와 100% 동일하게 `short_liq >= long_liq` 판정으로 수술 완치)
2. **[Case 3] 데이터 결측치 방어**: 바이낸스 통신 오류 등으로 가격이 0으로 들어오는 경우(`price <= 1000`) 필터링
   - **결과**: ✅ 정상 구현 확인 완료 (`if cp <= 1000.0: continue`)

### 🔄 [B. 2차 매집 (DCA) 로직]
3. **[Case 4] DCA 발동 조건 3박자**: 1차 평단 대비 설정 하락폭, 최소 15분 대기, 동일 방향 신호
   - **결과**: ✅ 정상 구현 확인 완료 (`pnl1 <= dca_drop` and `sig_dir == direction` and `cts - last_entry >= dca_time_limit`)
4. **[Case 5] 가중평균 평단가 산출**: `(ep1 * 1차비중 + ep2 * 2차비중) / (1차비중 + 2차비중)`
   - **결과**: ✅ 정상 구현 확인 완료 (수학적 가중평균 수식 100% 일치)

### 💰 [C. 분할 익절 (Take Profit) 로직]
5. **[Case 6] 1차 분할 익절**: 최고 PnL `1차 목표` 도달 시 50% 확정
   - **결과**: ✅ 정상 구현 확인 완료 (`is_tp1` 플래그 및 수익 정산 분리 로직 완벽 적용)
6. **[Case 7] 2차 올킬 청산**: 1차 익절 후 최고 PnL `2차 목표` 도달 시 전량 청산
   - **결과**: ✅ 정상 구현 확인 완료 (`pnl_cur >= tp2_ratio`)

### 🛡️ [D. 방어 및 손절 (Guard & Stop Loss) 로직]
7. **[Case 8] 본전/보존가드 발동**: 1차 익절 후 가격 하락 시 보존 청산
   - **결과**: ✅ 정상 구현 확인 완료 (`pnl_cur <= be_guard_ratio`)
8. **[Case 9] 최초 100% 스탑로스**: 1차 익절 전 최저 PnL `손절선` 도달 시 전량 손절
   - **결과**: ✅ 정상 구현 확인 완료 (`pnl1 <= -sl_ratio`)

### ⏳ [E. 시간 제한 및 쿨타임 (Time & Cooldown) 로직]
9. **[Case 10] 진입 직후 60초 락다운**: 진입 후 60초 이내 반대신호 무시
   - **결과**: ✅ 정상 구현 확인 완료 (`cts - last_entry_time >= 60.0` 조건 AND 묶음 처리)
10. **[Case 11] 반대신호 긴급 탈출**: 60초 경과 후 반대 신호 발생 시 즉각 탈출
    - **결과**: ✅ 정상 구현 확인 완료 (`sig_dir != direction` 스위칭 발동)
11. **[Case 12, 13] 수익/손절 쿨타임**: 청산 후 10초/30초 진입 차단
    - **결과**: ✅ 정상 구현 확인 완료 (`cooldown` 타이머 갱신 완벽)
12. **[Case 14] 세션 마감 강제 청산**: 세션 시간 끝날 때 시장가 정리
    - **결과**: ✅ 정상 구현 확인 완료 (루프 종료 후 마지막 강제 PnL 정산 로직 구비)
