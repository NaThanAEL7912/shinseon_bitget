## 1. 🎯 [기획 배경 및 폐하의 절대 어명]
- 폐하께서 비트겟 모바일 앱 또는 웹에서 수동으로 임의 포지션을 진입하셨을 때, **'자동 봇 시작' 버튼이 눌려있지 않은 대기/정지 상태이더라도**, 신선 시스템이 포지션을 감지하는 즉시 **3대 안전 가드(1차 TP 50% / 2차 TP 50% / SL 손절방패 100%)**를 비트겟 거래소에 0.001초 만에 자동 선주문으로 박아넣어 국고를 24시간 철통 수호하도록 개편한다.

## 2. 🔍 [핵심 동작 로직 및 방어 설계]

1. **실시간 포지션 감지 인터셉터:**
   - 클라이언트 및 서버의 포지션 동기화(`CMD_SYNC_POSITION` 및 3초 주기 `sync_bitget_real_position_status`)에서 비트겟 거래소의 실시간 포지션이 감지될 때:
   - **기존에 미배치 상태이거나 신규 진입된 포지션(`entry_price`, `contracts`, `side`)**인 경우, 봇의 가동 상태(`RUNNING` 또는 `STOPPED`)와 무관하게 **`place_bitget_tpsl_plan_orders`를 0.001초 즉시 격발**.
2. **3대 안전 가드 자동 배치 규격:**
   - **1차 TP (50% 부분 익절):** 세션 가드레일 설정(기본 +0.40% ~ +0.90%) 도달 시 시장가 분할 익절 (`planType: profit_plan`, `size: 50%`)
   - **2차 TP (50% 최종 익절):** 세션 가드레일 설정(기본 +0.60% ~ +1.50%) 도달 시 시장가 전량 익절 (`planType: profit_plan`, `size: 50%`)
   - **SL 손절 방패 (100% 전체 보호):** 세션 손절선(기본 -0.60% ~ -1.30%) 도달 시 포지션 100% 시장가 손절 방패 (`planType: pos_loss`)
3. **중복 발주 방지 락(Lock) 완비:**
   - 이미 해당 평단가 및 수량으로 TP/SL이 배치된 경우 재발주를 방지하여 API 쿼터 및 중복 주문을 100% 완벽 차단.
