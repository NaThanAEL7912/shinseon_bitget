## 1. 개요 및 배경

- **목적:**
  - 1분봉, 5분봉, 15분봉의 3중 스토캐스틱 RSI가 모두 극바닥(올그린 🟢, <=20%) 또는 모두 극천장(올레드 🔴, >=80%)으로 **동일한 색상의 불이 3개 동시에 점등될 때**, 국왕 폐하께서 지정하신 전용 사운드 파일 [`C:\Working\AI_Trading\sound\position.mp3`](file:///C:/Working/AI_Trading/sound/position.mp3)를 백그라운드에서 부드럽게 재생하여 즉각적인 골든 타임을 청각적으로 알리고자 함.
- **적용 대상:** [`shinseon_cockpit.pyw`](file:///C:/Working/ShinSeon_Bitget/shinseon_cockpit.pyw)

## 2. 세부 개발 명세

### 1) Windows MCI 기반 무간섭 백그라운드 MP3 사운드 플레이어 탑재
- **전용 사운드 파일 경로:** `C:\Working\AI_Trading\sound\position.mp3` (로컬 `sound/position.mp3` 복사본 상호 연동)
- **무간섭 백그라운드 재생 스레드:**
  - GUI 렉이나 멈춤(Freezing)이 절대 발생하지 않도록, `threading.Thread` 백그라운드에서 Windows 네이티브 `mciSendStringW` API를 호출하여 재생.
  - 사운드 파일 미존재 시 `winsound.Beep`로 안전하게 백업.

### 2) 3중 동일 색상 사운드 감지 및 재생 로직 (`on_rsi_updated`)
- **① 3중 올그린 🟢 극바닥 동조 (`k_1m <= 20.0 and k_5m <= 20.0 and k_15m <= 20.0`):**
  - **사운드:** `position.mp3` 백그라운드 즉시 재생!
  - **로그 출력:** `[HH:MM:SS] 🔔🟢 [3중 극바닥 동조 알림] 1m·5m·15m Stoch RSI 3중 초록불(<=20%) 동시 점등! (롱 골든 타임) ➔ position.mp3 재생!`
- **② 3중 올레드 🔴 극천장 동조 (`k_1m >= 80.0 and k_5m >= 80.0 and k_15m >= 80.0`):**
  - **사운드:** `position.mp3` 백그라운드 즉시 재생!
  - **로그 출력:** `[HH:MM:SS] 🔔🔴 [3중 극천장 동조 알림] 1m·5m·15m Stoch RSI 3중 빨간불(>=80%) 동시 점등! (숏 골든 타임) ➔ position.mp3 재생!`
- **③ 폭주 방지 쿨타임:**
  - 60초 쿨타임(`self._last_stoch_sound_time`, 60초)을 적용하여 연속 발동 시 소리 중복 방지.
- **④ 상단 사운드 체크박스 연동:**
  - `self.sound_enabled`가 활성화되어 있을 때만 재생.
