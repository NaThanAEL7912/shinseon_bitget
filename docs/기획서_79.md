# [기획서 79] 비트겟 증거금 초과 진입 기각 방지 및 설정값 동적 레버리지 연동 산출 수술 기획서 (V4.79)

## 1. 개요 및 폐하의 어명 팩트 분석
- **폐하의 어명:** "30배 항상 고정이 아니고 설정값대로 변경 되어야지"
- **소신의 수술 지침 반영:**
  - 30배 고정이 아닌, 폐하께서 `세션 / 트레이딩 핵심 설정` 대화상자에서 설정하신 레버리지 배수(`leverage_level`, 예: 1~150배)를 **동적으로 실시간 수신하여 100% 적용**하도록 수술합니다.

---

## 2. 세부 수술 내역

### 가. 동적 레버리지(`leverage_level`) 연동 92% 안전 가드 수량 공식 (`shinseon_server.py`)
- 폐하께서 설정창에 입력하신 레버리지 값(`lev = dashboard.leverage_level`)을 동적으로 읽어옵니다.
- 개조 공식:
  - `lev = float(getattr(dashboard, "leverage_level", 30.0))`
  - `max_affordable_usd = bitget_bal * lev * 0.92` (동적 레버리지 반영)
  - `calculated_target = bitget_bal * (ratio / 100.0) * lev * 0.92`
  - `p_target = min(calculated_target, max_affordable_usd)`
  - `amount = max(0.001, round(p_target / current_price, 3))`
  - 설정값에 따라 레버리지와 주문 수량이 100% 정밀하게 연동되며, 증거금 부족(40019) 거부가 전면 원천 박멸됩니다!

### 나. 발주 직전 동적 레버리지(`set_leverage(lev)`) 동기화 보장
- 주문 발주 직전, 폐하께서 설정하신 레버리지 값(`lev`)으로 비트겟 API `set_leverage(lev)`를 보장 호출하여 거래소 레버리지가 설정값과 100% 일치하도록 정격 조정합니다.
