# 📋 기획서 254: 스마트 스탑 가드 감시 기준의 PNL(순수 코인 가격 변동률 %) 전면 개편 및 신선 헌법 100% 일원화 기획서

---

## 🎯 1. 개요 및 배경
- **현상 및 문제점:**  
  폐하께서 대시보드의 `(PNL: +0.64%)`를 확인하시고, PNL이 `+0.50%`로 내려올 때 수익을 보존(50% 분할 익절)하기 위해 `오프셋: 0.5`를 입력하셨으나, 기존 코드가 이를 레버리지 30배가 곱해진 `ROE +0.50%` (PNL 환산 시 고작 +0.016% = 사실상 본전)로 해석하고 라벨에도 `+0.50% ROE`로 오표기하는 괴리가 발생하고 있었습니다.
- **신선 헌법 체계와의 정합성:**  
  - 1번 탭: 최초 손절선 `-1.3%` (순수 PNL %)
  - 4번 탭: 가드레일 분할 익절 `+1.5%` (순수 PNL %)
  - 2번 탭: 2차 진입 하락폭 `-0.30%` (순수 PNL %)
  - 신선의 모든 백서와 파라미터는 **100% 순수 비트코인 가격 변동률(PNL %)** 을 기준으로 작동하므로, 스마트 스탑 가드 역시 PNL % 기준으로 완벽히 일원화되어야 합니다.
- **목적:**  
  스마트 스탑 가드의 모든 계산 수식, 실시간 감시 엔진, 텔레메트리 이중 안전망, UI 라벨 및 로그 표기를 **`PNL % (순수 가격 변동률)` 기준으로 100% 전면 개편**하여, 폐하께서 의도하신 대로 PNL `+0.50%` 도달/이탈 시 50% 분할 익절이 정밀하게 집행되도록 수술합니다.

---

## 🛠️ 2. 상세 작업 명세

### ① 서버 감시 엔진 및 텔레메트리 PNL 기준 전면 수술 (`shinseon_server.py`)
1. **`CMD_SET_SMART_STOP` 패킷 처리:**  
   - 현재 진입가 대비 실시간 코인 가격 변동률 `live_pnl` 산출 및 `custom_stop_set_pnl`에 보존.
   - `custom_stop_offset_pnl = offset_val` 설정.
2. **`manage_v35_exit_guardrail` 실시간 감시 루프:**  
   - `live_pnl = pnl_pct * 100.0` (순수 가격 변동률)을 오프셋(`offset_val`)과 직접 비교:
     - `offset_val < pnl_at_set` ➔ `live_pnl <= offset_val` (하향 이탈 시 수익보존/손절)
     - `offset_val > pnl_at_set` ➔ `live_pnl >= offset_val` (상향 도달 시 목표익절)
   - 발동 시 지정 비율(`ratio`) 분할 청산 집행.
3. **텔레메트리 콜백 및 UI 표출 텍스트:**  
   - `(🛡 스마트 스탑 가드: +0.50% PNL 수익보존 감시 중)` 으로 정직하고 명확하게 표출.

---

### ② 클라이언트 UI 및 로그 표기 정상화 (`shinseon_client.pyw`)
1. UI 라벨을 `오프셋(PNL %):` 으로 명확히 안내.
2. 설정 시 로그를 `🛡️ [스마트 스탑 설정] 비트겟 PNL {offset:+.2f}% 도달 시 {ratio:.0f}% 청산 가드를 가동합니다.` 로 표출.
