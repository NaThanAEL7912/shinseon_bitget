# 신선 비트겟 (ShinSeon_Bitget) 프로젝트 기획서 1

## 1. 프로젝트 개요
* **목표**: 기존 비트겟(BBITGET) 거래소 기반 코인 자동 매매 시스템인 "신선(ShinSeon)"을 비트겟(Bitget) 거래소 환경으로 마이그레이션(재개발) 합니다.
* **주요 기능**: 바이낸스(Binance)에서 트레이딩 신호를 받아 비트겟(Bitget) 거래소 API를 통해 실제 매매(주문, 취소, 포지션 관리 등)를 수행합니다.

## 2. 개발 및 협업(검증) 파이프라인 구축 기획
본 프로젝트는 **안티그래비티(기획/개발) ↔ 오픈클로(검수/테스트)** 형태로 상호 협력하여 진행됩니다.

1. **기획 및 설계 (안티그래비티)**: 소신(안티그래비티)이 폐하와 함께 아키텍처 및 세부 로직을 설계하고 기획서로 정리합니다.
2. **코드 구현 (쫄다구 코더 Subagent)**: 설계된 내용을 바탕으로 안티그래비티의 쫄다구 코더 에이전트(Subagent)가 비트겟 API 연동 코드 및 트레이딩 로직을 작성합니다.
3. **코드 검수 및 테스트 (OpenClaw)**: 작성이 완료되면, 현재 백그라운드에 구동 중인 오픈클로(OpenClaw) 봇에게 검수 및 테스트를 요청합니다. 
   - 텔레그램이나 터미널을 통해 오픈클로에게 테스트 스크립트 실행을 명령하여 런타임 에러 확인, API 통신 정상 여부(모의 투자 등)를 검증받습니다.
4. **수정 및 피드백**: 오픈클로의 테스트 결과를 바탕으로 안티그래비티가 코드를 수정하고 안정성을 확보합니다.
