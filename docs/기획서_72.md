# [기획서 72] 대시보드 팝업창 완전 제거 및 AWS 서버 실시간 응답 로그 직송 이식 기획서 (V4.72)

## 1. 개요 및 폐하의 어명 분석
- **폐하의 어명:**
  1. "이거 팝업 뜨는건 삭제 해주고"
  2. "지금 주문이 없을 때는 어떤 답변이 오는지 모르겠는데 서버에서 답변 오는걸 로그에 출력해야 되지 않을까?.?"

- **소신의 수술 목표:**
  1. **모든 팝업 모달창(`QMessageBox`) 전면 완전 삭제:**
     - 50% 청산, 스마트 스탑 설정/해제 등 버튼 클릭 시 화면 중앙을 가리던 팝업 창(`QMessageBox.information`)을 100% 완전 제거하여 거래 흐름을 차단하지 않도록 정화합니다.
  2. **AWS 서버 실시간 처리 결과 및 응답 메시지의 대시보드 로그(`txt_log`) 100% 직송 출력:**
     - 포지션이 없을 때, 청산이 체결되었을 때, 오류가 발생했을 때 등 AWS 서버에서 반환되는 **모든 처리 결과 패킷(`EVT_RESPONSE_LOG`)을 대시보드 좌측 하단 로그창에 실시간으로 즉시 출력**합니다.

---

## 2. 서버 응답 로그 직송 아키텍처 및 세부 설계

```
[클라이언트 버튼 클릭]
          │
[AWS 릴레이 서버 패킷 전송 (CMD_CLOSE_50 / CMD_SET_SMART_STOP)]
          │
[AWS 서버 비트겟 API 처리 & 조건 판정]
  ├── 포지션 미존재 시 ➔ EVT_RESPONSE_LOG: "⚠️ [서버 응답] 현재 활성화된 비트겟 포지션이 없어 50% 청산 명령을 스킵합니다."
  ├── 체결 완료 시    ➔ EVT_RESPONSE_LOG: "✅ [서버 응답] 비트겟 0.0009 BTC 시장가 청산 완료 (체결 코드: 00000)"
  └── 스마트 스탑 설정 ➔ EVT_RESPONSE_LOG: "🛡️ [서버 응답] 비트겟 포지션에 +6.00% ROE 스마트 스탑 감시 가드가 등록되었습니다."
          │
[클라이언트 WSS 수신 ➔ 대시보드 로그(txt_log) 0.001초 직송 출력!] (팝업창 0%)
```

### 가. 팝업창 전면 거두기 (`shinseon_client.pyw`)
- `execute_50_percent_close` 메서드 내부 `QMessageBox.information` 삭제
- `trigger_stoploss_setting` 및 `reset_stoploss_ui` 메서드 내부 `QMessageBox.information` 삭제
- 기타 모든 버튼의 알림 팝업창 전면 제거

### 나. AWS 서버 실시간 응답 패킷 구조화 (`shinseon_server.py`)
- 서버에서 모든 명령 처리 후 클라이언트로 `EVT_RESPONSE_LOG` 전송:
  - 포지션 미보유 시: `📡 [서버 응답] 현재 보유 중인 포지션이 없습니다. (100% 현금 대기)`
  - 수량 최소 단위 미달 및 스마트 전량 청산 시: `ℹ️ [서버 응답] 수량(0.0009 BTC)이 최소 발주 단위 이하이므로 전량 시장가 청산을 완료했습니다.`
  - 50% 분할 청산 체결 성공 시: `✅ [서버 응답] 50% 분할 청산(0.001 BTC) 체결 완료!`
  - 스마트 스탑 설정 시: `🛡️ [서버 응답] 스마트 스탑 감시 가드(+6.00% ROE) 가동 개시!`
  - 스마트 스탑 해제 시: `🧹 [서버 응답] 스마트 스탑 감시 가드가 정상 해제되었습니다.`
