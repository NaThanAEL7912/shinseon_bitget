## 2. 🔍 [백테스터 현재 로직 100% 정밀 분석]

### 1️⃣ 데이터 구조 및 8대 세션 체계
- **입력 데이터:** `docs/historical_data/` 및 `downloads/` 폴더에 24시간 1초 단위로 기록된 실측 오더플로우 CSV 데이터 전수 사용.
- **8대 세션 분기 (KST 기준):**
  1. 평일/주말 아시아 (09:00 ~ 16:30)
  2. 평일/주말 유럽 (16:30 ~ 22:30)
  3. 평일/주말 미국 본장 (22:30 ~ 05:00)
  4. 평일/주말 태평양 (05:00 ~ 09:00)

### 2️⃣ 진입 시그널 판정 로직 (현재 백테스터 상태)
- **현재 적용 헌법 (V7.27 청산 주도권 엔진):**
  ```python
  if rolling_1m_liq >= target_liq and abs(oi_delta_1m) >= target_oi:
      if short_liq >= long_liq:
          sig_dir = "LONG"   # 숏 청산 압도 시 롱
      else:
          sig_dir = "SHORT"  # 롱 청산 압도 시 숏
  ```
- **현재 로직의 특징:**
  - `abs(oi_delta_1m)` (절댓값)을 사용하므로, 아까 엑셀에서 보신 것처럼 **OI가 음수(`-0.18%`)인 휩소/청산 구간에서도 진입 신호가 발생**하고 있음.

### 3️⃣ 포지션 분할 매수 및 물타기/불타기 (DCA & Pyramiding)
1. **1차 진입:** 세션별 설정된 1차 비중(예: 300%)으로 진입.
2. **2차 추매 (DCA):** 진입 후 평단 대비 `-0.30%` 하락 시 동일 신호 발생 시 즉시 2차 비중(150%) 투입 ➡️ 평단가 하향 조정.
3. **3차 추매 (DCA):** 2차 추매 후 900초 쿨타임 경과 & `-0.60%` 하락 시 3차 비중(150%) 투입.
4. **눌림목 불타기 (Pyramiding):** 1차 익절(TP1) 성공 후 시세가 되돌림(-0.3%)을 줄 때 +30% 비중 추가 탑승.

### 4️⃣ 5단계 방탄 청산 알고리즘
1. **1차 TP (50% 분할 익절):** 수익률 `+0.40% ~ +0.90%` 도달 시 보유 수량의 50% 즉시 익절.
2. **2차 TP (100% 올킬 익절):** 잔여 50% 물량이 최종 목표가(`+0.80% ~ +1.50%`) 도달 시 전량 청산.
3. **본전 스탑 가드 (Breakeven Guard):** 1차 익절 완료 후, 시세가 꺾여 진입가 본전(`+0.00% ~ +0.10%`) 도달 시 잔여 물량 무위험 탈출.
4. **손절 방패 (Hard Stop Loss):** 1차 익절 전 세션별 손절선(`-0.60% ~ -1.30%`) 터치 시 전량 즉시 손절.
5. **60초 후 반대 신호 탈출:** 진입 후 60초가 지난 시점에서 강력한 반대 세력 신호 발생 시 스위칭 청산.

## 3. 🚀 [백테스터 고도화 및 테스트 계획]

### 💡 폐하의 `+OI` (양수 자금유입) 필터 백테스팅 옵션 추가
1. **기존 방식 (A안 - 절댓값 OI):**  
   - `abs(oi) >= target_oi` (양수/음수 모두 진입 - 휩소 포함)
2. **폐하의 제안 (B안 - 순수 자금 유입 `+OI`만 진입):**  
   - `oi > 0 and oi >= target_oi` (음수 청산 휩소 원천 차단)
