# [기획서 10] 잔고 동기화 (CCXT 비동기 호출 및 선물 계좌) 버그 수정

폐하, 클라이언트와 서버가 드디어 연결(연결 성공!)되었으나 버튼을 눌러도 반응이 없던 이유를 찾아내었습니다! 
이는 서버 내부에서 비트겟 거래소에 잔고를 요청하는 부분에 숨어있던 두 가지 작은 버그 때문이었습니다.

## 1. 버그 원인
1. **비동기 함수 호출 오류:** CCXT 라이브러리 교체(V4.14) 과정에서, 비트겟 잔고 조회 함수(etch_balance)가 동기 방식에서 비동기(Async) 방식으로 바뀌었는데, 기존 동기식 호출 껍데기(syncio.to_thread)를 씌워놔서 내부적으로 에러를 뿜으며 조회가 차단되고 있었습니다. (이 에러 메시지가 다른 로그들에 밀려 순식간에 지나가는 바람에 발견이 늦었습니다.)
2. **현물/선물 계좌 지정 누락:** 비트겟에 "내 돈 얼마 있어?"라고 물어볼 때, 기본적으로 현물(Spot) 계좌를 뒤져서 0원을 가져오고 있었습니다. 선물(Futures/Swap) 계좌를 조회하도록 명시해 주어야 합니다.

## 2. 해결 방안 (Proposed Changes)
- **수정 대상 파일:** shinseon_server.py, shinseon_client.pyw
- **작업 내용:** 
  1. (서버) CCXT 초기화 옵션에 {'options': {'defaultType': 'swap'}} (선물 계좌 기본값) 추가.
  2. (서버) 잔고 조회 코드에서 syncio.to_thread를 벗겨내고 순수 비동기 호출(wait self.bot_core.bitget_exchange.fetch_balance())로 변경.
  3. (클라이언트) 폐하의 어명에 따라, 클라이언트 최초 실행 시 표시되던 가짜 2만불($20,000.00) 텍스트를 삭제하고, $0.00 (실시간 동기화 대기)로 표시되도록 수정. 0원이면 정직하게 0원으로 즉각 반영되도록 조치.


이 수정이 완료되면 버튼 클릭 시 서버가 비트겟 선물 계좌에 정상적으로 통신하여 폐하의 실전 USDT 자본금을 화면에 띄워줄 것입니다!
