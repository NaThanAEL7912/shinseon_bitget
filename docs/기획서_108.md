# ShinSeon Bitget 기획서_108

## 📌 개요
마스터 대시보드 상단 헤더 영역에 **[전체 누적 매매 결과 전광판(좌측/빨간 영역)]**과 **[오늘의 당일 매매 결과 위젯(우측/파란 영역)]**을 배치하고, 날짜별 매매 실적 데이터를 축적하여 **[📊 누적 상세 보고서 팝업(QDialog)]**을 통해 일별 승률, 익절/손절액, 순손익(USDT), 세부 거래 내역을 일목요연하게 조회할 수 있도록 대시보드 통계 시스템을 전면 고도화합니다.

---

## 🎯 개발 및 기획 상세 항목

### 1. **대시보드 상단 듀얼 통계 전광판 배치 (UI 개편)**
- **좌측 영역 [전체 누적 매매 결과] (캡처 화면 빨간색 상자 위치):**
  - 표시 정보: `전체 누적 손익($)` | `전체 승률(%)` | `총 거래 횟수 (승/패)` | `[📊 누적 상세 보고서]` 팝업 버튼
  - 디자인: 다크 테마 기반 Gold / Cyber Blue 그라데이션 포인트 적용
- **우측 영역 [오늘의 당일 매매 결과] (캡처 화면 파란색 상자 위치):**
  - 표시 정보: `금일 손익($)` | `금일 승률(%)` | `금일 거래 횟수 (승/패)` | `구동 상태 및 핑`

### 2. **일별/날짜별 매매 데이터 자동 적재 (Data Persistence)**
- 매 거래 청산(익절/손절/가드레일/스위칭) 발생 시 `daily_trade_stats.json` 및 서버 DB에 일별 누적 데이터 자동 갱신:
  - 축적 칼럼: `날짜(YYYY-MM-DD)` | `총 거래 횟수` | `승리 횟수` | `패배 횟수` | `당일 승률(%)` | `총 익절액($)` | `총 손절액($)` | `당일 순손익($)` | `평균 ROE(%)`

### 3. **[📊 누적 상세 보고서] 팝업 창 (QDialog) 신설**
- **상단 요약 카드 메트릭:**
  - `전체 누적 손익($)` | `전체 누적 승률(%)` | `총 거래 횟수` | `최대 손실폭(MDD)` | `평균 손익비`
- **중앙 일별/날짜별 실적 상세 테이블 (`QTableWidget`):**
  - 날짜별 행 구성 (최신 날짜순 정렬)
  - 특정 날짜 클릭/선택 시 하단에 **[해당 날짜 개별 거래 세부 리스트]** (진입시간, 청산시간, 방향, 진입가, 청산가, PnL, ROE%, 청산 사유) 즉시 표시!
- **하단 제어 버튼:**
  - `[🔄 실시간 새로고침]` | `[📥 일별 통계 CSV 다운로드]` | `[닫기]`

### 4. **AWS 서버-클라이언트 실시간 동기화 (EVT_SYNC_STATS)**
- 서버에서 청산 발생 시 통계 자동 계산 후 `EVT_SYNC_STATS` 패킷 브로드캐스트하여 클라이언트 상단 전광판 및 팝업 창 즉시 갱신.
