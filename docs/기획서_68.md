# [기획서 68] 비동기 루프 예외 박멸(ensure_future) 및 QMessageBox 팝업 100% 보장 완공 수술 (V4.68)

## 1. 개요 및 팩트 원인 적출 (100% 실측 결과)
- **폐하의 지적:**
  "아니 이거 머 버튼을 처리를 못하냐 미치것네"
- **소신의 100% 팩트 원인 적출 결과:**
  1. Qt 동기 이벤트 루프에서 `asyncio.create_task()`를 직접 호출할 때 `RuntimeError: no running event loop` 예외가 발생하여 핸들러 내부에서 무반응처럼 중단되는 맹점을 발견하였습니다.
  2. 성공적으로 작동하던 `btn_emergency`(비상 탈출 버튼)와 동일하게 **`asyncio.ensure_future()` 안전 바인딩**으로 수술하여 비동기 루프 예외를 100% 박멸합니다.
  3. 클릭 즉시 화면 중앙에 **`QMessageBox.information` 안내 팝업창**이 무조건 떠오르도록 탑재하여 100% 시각적 실행 팩트를 보장합니다.
