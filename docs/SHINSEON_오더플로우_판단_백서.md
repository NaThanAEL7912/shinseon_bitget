# SHINSEON 오더플로우 판단 백서

## 📌 1. 개요 및 목적 (바이낸스 100% 시세 전권 대전제)
본 문서는 SHINSEON 비트겟 선물 자동저격 트레이딩 시스템에서 가장 어마어마한 수익을 싹쓸이했던 **V2.55 황금 전성기 오더플로우 저격 알고리즘의 100% 전수 헌법 백서**입니다.

> **🏛️ [헌법 대전제]: 모든 저격 판단/결정(타점 포착, 4대 매트릭스, 1분 가격 변동 `price_delta_1m`, OI 속도 `oi_delta_1m`, 1분 청산액)은 오직 100% 바이낸스(Binance) 실시간 시세 및 거래 데이터로만 정해집니다.** 비트겟 가격은 얼마이든 판단에 단 0.001%도 영향을 미치지 않으며, 오직 최종 주문을 체결하는 발주 창구 역할만 수행합니다.

## 🛡️ 2. 0단계: 필수 듀얼 임계치 대전제 (AND 조건)
신규 저격 진입 및 포지션 보유 중 반대 청산 감시는 아래 2가지 조건이 **100% 동시에 넘어섰을 때(AND 조건)에만 기어가 동작**합니다. 하나라도 미달 시 진입/청산을 일절 기각(NONE)하고 휴식합니다.

1. **`1분 청산액 >= target_liq`** (세션별 기본: $500,000 이상)
2. **`abs(1분 OI속도) >= target_oi`** (세션별 기본: 0.18% 이상)

---

## 🎯 3. 1단계: 1분 가격변동(price_delta) ✕ OI속도(oi_delta) 4대 저격 매트릭스

| 경우의 수 | 1분 가격변동 (`price_delta_1m`) | 1분 OI속도 (`oi_delta_1m`) | 저격 깃발 방향 | 시장 세력 메커니즘 팩트 |
|---|---|---|---|---|
| **Case A** | 📉 **`price_delta < 0`** (가격 하락) | 📉 **`oi_delta < 0`** (OI 감소) | 🟢 **`LONG`** | **개미 롱 손절 털기 완료 ➡️ 저점 LONG 매수 저격!** |
| **Case B** | 📈 **`price_delta > 0`** (가격 상승) | 📉 **`oi_delta < 0`** (OI 감소) | 🔴 **`SHORT`** | **개미 숏커버 털기 완료 ➡️ 고점 SHORT 매도 저격!** |
| **Case C** | 📈 **`price_delta > 0`** (가격 상승) | 📈 **`oi_delta > 0`** (OI 증가) | 🟢 **`LONG`** | **세력 신규 자금 유입 ➡️ 상승 추세 LONG 탑승!** |
| **Case D** | 📉 **`price_delta < 0`** (가격 하락) | 📈 **`oi_delta > 0`** (OI 증가) | 🔴 **`SHORT`** | **세력 신규 자금 유입 ➡️ 하강 추세 SHORT 탑승!** |

## 🚨 4. 2단계: 실전 집행 및 포지션 보유 중 반대 청산 & 쿨타임 스위칭 감시

### ① 포지션 미보유 시 (신규 진입)
- 쿨타임 대기 중(`cooldown_until_time`)이 아닐 때, 4대 매트릭스에서 결정된 깃발(`direction`)대로 **비트겟 선물 시장가 주문을 쏘고, 1초 CSV 장부 파일에도 100% 동일한 방향을 인쇄 기록**합니다.

### ② 포지션 보유 중일 때 (Holding Position)
1. **동일 방향 깃발 수신 시:** 기존 포지션 온전히 홀딩 유지 (추세 탑승). (추가 매수 조건 충족 시 비중 확대)
2. **반대 방향 깃발 수신 시 (`direction != entry_direction`):**
   - **[100% 즉시 청산]:** **OI 부호(+/-)에 관계없이 반대 깃발 수신 즉시 기존 포지션 전량 시장가 청산(`CLEAR`)**을 집행합니다. (v2.55 황금 전성기 헌법)
   - **[쿨타임 대기 🚨]:** 청산 직후 **익절/스위칭 쿨타임(기본 15초)** 또는 **손절 쿨타임(기본 300초)** 동안 `cooldown_until_time`을 엄격히 가동하여 신규 진입을 무조건 철통 차단합니다.
   - **[스위칭 승차]:** 쿨타임이 완벽히 지난 후(`time.time() >= cooldown_until_time`), 유효한 반대 방향 저격 깃발 수신 시 비로소 안전하게 반대 방향 포지션으로 신규 스위칭 탑승합니다.

## 🏛️ 5. 100% 파이썬 실전 구현 원본 소스코드 (V5.81)

```python
# [0단계]: 최근 1분 동안 터진 청산 금액과 OI속도가 우리가 목표한 최소 기준치(임계치)를 넘어섰는지 제일 먼저 검사해요!
if rolling_1m_liq_usd >= target_liq and abs(oi_delta_1m) >= target_oi:
    
    # --------------------------------------------------------------------------
    # 1단계: 1분 가격이 움직인 방향(price_delta_1m)과 OI속도(oi_delta_1m)를 합쳐서 깃발(direction) 색깔을 정해요!
    # --------------------------------------------------------------------------
    
    # [Case A]: 가격이 떨어지고(<0) OI도 감소하면(<0) 개미가 손절을 다 턴 거니까 저점에서 🟢 "LONG(매수)" 깃발을 들어요!
    if price_delta_1m < 0 and oi_delta_1m < 0:
        direction = "LONG"
        
    # [Case B]: 가격이 올라가고(>0) OI가 감소하면(<0) 숏 세력이 손절을 다 턴 거니까 고점에서 🔴 "SHORT(매도)" 깃발을 들어요!
    elif price_delta_1m > 0 and oi_delta_1m < 0:
        direction = "SHORT"
        
    # [Case C]: 가격도 올라가고(>0) OI도 펑펑 늘어나면(>0) 세력이 돈을 쏟아붓는 거니까 상승 🟢 "LONG(매수)" 깃발을 들어요!
    elif price_delta_1m > 0 and oi_delta_1m > 0:
        direction = "LONG"
        
    # [Case D]: 가격도 떨어지고(<0) OI가 펑펑 늘어나면(>0) 세력이 하방으로 돈을 쏘는 거니까 하강 🔴 "SHORT(매도)" 깃발을 들어요!
    elif price_delta_1m < 0 and oi_delta_1m > 0:
        direction = "SHORT"
        
    else:
        direction = None

    # --------------------------------------------------------------------------
    # 2단계: 손에 포지션 장난감이 있는지 확인해서 주문을 넣거나 반대 청산/쿨타임 스위칭을 감시해요!
    # --------------------------------------------------------------------------
    
    # [신규 진입]: 포지션이 없고(not active) 쿨타임도 끝났으며 깃발이 정해졌으면 비트겟 주문을 쏘고 CSV에도 기록해요!
    if not self.is_position_active and direction and time.time() >= self.cooldown_until_time:
        await self.execute_entry(direction)
        
    # [보유 중 감시]: 이미 손에 포지션 장난감을 쥐고 있는 상태라면!
    elif self.is_position_active:
        
        # 새로 온 깃발 방향이 내가 들고 있는 포지션 방향과 똑같으면 신나게 홀딩(pass)해요!
        if direction == self.entry_direction:
            pass
            
        # 새로 온 깃발 방향이 내가 들고 있는 포지션 방향과 반대 색깔일 때!
        elif direction and direction != self.entry_direction:
            
            # v2.55 황금 전성기 원칙: OI 부호와 상관없이 즉시 전량 시장가 청산!
            await self.execute_exit_clear(reason=f"반대 신호({direction}) 수신 ➡️ 즉시 전량 청산")
            
            # 청산 후 익절/스위칭 쿨타임(15초) 또는 손절 쿨타임(300초) 가동!
            # 쿨타임이 지난 후 차후 깃발 수신 시 반대 방향 스위칭 진입!

# [임계치 미달]: 1분 청산 금액이나 OI속도가 최소 기준치보다 작으면 아무것도 안 하고 푹 쉬어요! (None)
else:
    direction = None
```
