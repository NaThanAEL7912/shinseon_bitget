### 2) 실전 물리 연산 공식 (정공법 100%)
1. **실제 진입/청산가**: 2026-03-01 ~ 2026-08-31 매일 21:30 ~ 01:00 KST 바이낸스 실제 1분봉의 시가/고가/저가/종가 범위 내 실제 가격.
2. **진입 수량 (Qty)**: 잔고 및 레버리지(20x~30x) 기준 소수점 4자리 BTC (예: 0.1542 BTC, 0.4285 BTC, 1.2541 BTC).
3. **실현 손익 (Gross PnL)**: 
   $$\text{Gross PnL} = (\text{청산가} - \text{진입가}) \times \text{수량} \times (1 \text{ if LONG else } -1)$$
4. **거래 수수료 (Fee)**: 
   $$\text{Fee} = (\text{진입가} + \text{청산가}) \times \text{수량} \times 0.00030$$
5. **순손익 (Net PnL)**: 
   $$\text{Net PnL} = \text{Gross PnL} - \text{Fee}$$
6. **누적 잔고 (Balance)**: 
   $$\text{새 잔고} = \text{이전 잔고} + \text{Net PnL}$$
