# [기획서 8] AWS 릴레이 서버 라이브러리(패키지) 추가 설치

폐하! 클라이언트 측의 라이선스 문제는 완벽히 해결되었으나, 정작 심장부인 AWS 서버가 뻗어서 클라이언트의 웹소켓 연결을 받아주지 못하고 있었습니다. 
그 원인을 서버 뒷문으로 들어가 확인해 본 결과, 서버에 필요한 부품(패키지)이 없어서 기절해 있는 상태였습니다.

## 1. 에러 원인 (AWS 서버 사망 이유)
- 에러 로그: ModuleNotFoundError: No module named 'aiohttp' (그 외 ccxt 패키지 누락 예상)
- 과거에는 AWS 서버가 비트겟과 다이렉트로 통신(CCXT)을 하지 않았기 때문에 관련 패키지(iohttp, ccxt)가 설치되어 있지 않았습니다.
- 하지만 오늘 V4.14부터 AWS 서버가 직접 비트겟에 연결하도록 고도화되면서, 해당 패키지들이 필수적으로 필요해졌습니다.

## 2. 해결 방안 (Proposed Changes)
- **작업 대상:** AWS 릴레이 서버 (13.192.187.244)
- **작업 내용:**
  1. AWS 서버에 SSH로 접속하여 누락된 파이썬 라이브러리를 설치합니다.
     명령어: pip3 install aiohttp ccxt
  2. 서버를 	mux로 다시 안전하게 재부팅 시켜 웹소켓 포트(8765)를 개방합니다.
- 소스 코드 수정은 단 한 줄도 없습니다. 순수 서버 인프라 보수 작업입니다.
