# 기획서 190: 비트겟 포지션 API 실제 평단가/수량 100% 직송 동기화 완치 수술

## 📌 1. 개요 및 원인 분석
- **현상 (비트겟 실제 포지션 화면 vs 텔레그램/손절 엔진 괴리 발생):**
  - **비트겟 거래소 실제 포지션 팩트:** 숏 진입 평단가 **`$63,852.1`**, 체결 수량 **`0.0010 BTC`**, 현재가 `$63,854.2` (ROE `-0.10%`로 소액 손실 안정 유지 중).
  - **텔레그램 및 내부 연존 오보 현상:** 진입가 `$63,902.4`, 가짜 청산가 `$64,541.4`, 수량 `0.007 BTC`, 가짜 ROE `-30.00%` 오보 송출.
- **소스코드 팩트 원인 검증 (`shinseon_server.py` L2594 / L3028):**
  - 진입 시 비트겟 API의 실제 포지션 체결 평단가(`$63,852.1`)를 가져오지 않고, 바이낸스 호가창 추정 시세(`$63,902.4`)를 서버 메모리에 집어넣어 연산했습니다.
  - 이로 인해 실제 비트겟 계좌는 ROE -0.10%로 멀쩡히 가동 중임에도, 서버 내부 엔진이 가짜 추정 시세($64,541.4)로 손절률(-1.00%)을 오인하여 가짜 손절 알림을 날렸던 팩트이옵니다.
- **목적:** 포지션 진입 및 동기화 시 **비트겟 공식 포지션 API REST 패킷(`entryPrice`, `total`)을 100% 직접 수신하여 서버 메모리에 주입**, 비트겟 거래소 포지션 화면과 텔레그램/내부 엔진을 0.0001% 오차도 없이 100% 일치시킵니다.
