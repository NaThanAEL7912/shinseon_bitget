# 기획서 270: 수동 날짜 선택 시 포커스 미커밋 결함 원천 해결 및 직관적 기간 선택 체계 완공

## 1. 개요 및 배경
- 폐하의 엄중하신 지적: "프리셋 버튼 말고, 내가 직접 시작일시와 종료일시를 선택(수동 지정)한 것만 백테스트에 반영이 안 된다."
- 원인 정밀 진단:
  - Qt의 `QDateTimeEdit` 위젯 특성상, 사용자가 키보드로 날짜/시간을 입력하거나 수정한 후 포커스가 빠져나가지 않은 상태에서 바로 [백테스트 실행]을 누르면, **입력한 텍스트가 내부 `dateTime()` 객체로 커밋(확정)되지 않고 이전 날짜로 롤백되어 연산되는 고질적인 포커스 미커밋 버그** 발생.
  - 또한 문자열 파싱 시 텍스트 상자의 표시 텍스트를 직접 읽지 않아 화면에 보이는 날짜와 실제 계산 날짜 간에 엇박자가 발생함.

---

## 2. 세부 개발 계획

### 1) 🎯 `interpretText()` 강제 커밋 & 텍스트 직접 파싱 이중 안전망 구축
- [백테스트 실행] 클릭 시:
  1. `self.dt_start.interpretText()` 및 `self.dt_end.interpretText()`를 강제 호출하여 입력 중인 모든 글자를 즉시 확정.
  2. `self.dt_start.text()` 및 `self.dt_end.text()` 문자열을 `datetime.strptime`으로 정밀 파싱하여 **폐하께서 화면에서 눈으로 보고 계신 날짜/시간 텍스트 그대로 100% 완벽하게 시뮬레이션에 전달**.

### 2) 📅 날짜 선택 UX 편의성 극대화
- 캘린더 팝업(`setCalendarPopup(True)`) 및 키보드 입력 시 실시간 날짜 유효성 검사 강화.
- 시작 일시가 종료 일시보다 늦을 경우 자동 보정 및 친절한 안내.
- 대시보드 타이틀에 폐하께서 선택하신 시작~종료 일시를 정확히 표기하여 적용 여부를 즉시 시각 확인 가능하도록 보강.
