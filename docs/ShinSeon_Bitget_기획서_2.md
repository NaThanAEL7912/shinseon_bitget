# 신선 비트겟 (ShinSeon_Bitget) 프로젝트 기획서 2

## 안티그래비티 ↔ 오픈클로(OpenClaw) 자동화 검수 파이프라인 방안

폐하의 질문인 "오픈클로는 어떻게 안티그래비티의 작업 완료를 알고 검수하는가?"에 대한 해결 방안 기획입니다. 현재 로컬 환경에 오픈클로(OpenClaw) CLI 및 게이트웨이가 완벽하게 구축되어 있으므로, 다음과 같은 3가지 방안이 가능합니다.

### 1안: 안티그래비티의 직접 호출 (추천 ⭐)
* **방식**: 소신(안티그래비티)이 개발을 완료하면, 터미널 명령어를 통해 직접 오픈클로 에이전트를 깨워서 검수를 지시합니다.
* **실행 예시**: 안티그래비티가 백그라운드에서 `openclaw agent --message "ShinSeon_Bitget 코드를 검수하고 모의 테스트를 돌린 후 폐하의 텔레그램으로 보고하라" --deliver` 명령어를 실행합니다.
* **장점**: 폐하께서 중간에 개입하실 필요 없이, 개발(안티그래비티) -> 검수(오픈클로) -> 보고(텔레그램)가 하나의 흐름으로 자동화됩니다.

### 2안: 감시(Watch) 파일을 통한 트리거
* **방식**: 특정 파일(예: `TEST_REQUEST.md`)의 상태 변화를 오픈클로가 주기적으로 감시(`openclaw cron` 활용)하게 합니다.
* **실행 예시**: 안티그래비티가 개발을 마치고 `TEST_REQUEST.md` 파일에 "검수 요망"이라고 적으면, 오픈클로가 이를 감지하고 스스로 테스트를 시작합니다.
* **장점**: 에이전트 간의 독립성이 완벽하게 보장됩니다.

### 3안: 폐하의 어명을 통한 수동 릴레이 (안전 최우선)
* **방식**: 소신이 "폐하, 개발이 완료되었습니다" 라고 보고를 올립니다.
* **실행 예시**: 폐하께서 직접 텔레그램으로 오픈클로 봇에게 "안티그래비티가 짠 신선 비트겟 코드 테스트해서 결과 알려줘" 라고 명령을 내리십니다.
* **장점**: 모든 테스트 시점을 폐하께서 100% 통제하실 수 있습니다.
