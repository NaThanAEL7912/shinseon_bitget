# 기획서 269: 백테스트 실행 시 실시간 "계산 중" 로딩 상태 시각화 피드백 엔진 구축

## 1. 개요 및 배경
- 폐하의 지엄하신 어명: "백테스트 실행을 클릭하면 실행 중인지 알 방법이 없다. '계산 중'이라는 상태가 시각적으로 표시되어야 한다."
- 현황 분석:
  - 21일치(107만 틱) 대규모 실측 데이터를 시뮬레이션할 때 약 1~2초간 연산이 수행되나, 버튼 텍스트나 화면에 "계산 중" 표시가 즉시 나타나지 않아 사용자가 실행 여부를 직관적으로 인지하기 어려움.
- 이에 [백테스트 실행] 클릭 즉시 버튼과 화면 전체에 **"⏳ 정밀 계산 중..."** 시각 피드백을 표출하고 연산 완료 시 즉각 복원하도록 구축합니다.

---

## 2. 세부 개발 계획

### 1) ⚡ [백테스트 실행] 버튼 실시간 동적 상태 변환
- **클릭 즉시 (0.001초)**:
  - 버튼 텍스트: **`⏳ 107만 틱 초단위 오더플로우 정밀 계산 중...`** 으로 즉각 전환.
  - 버튼 스타일: 강렬한 네온 오렌지/레드 로딩 컬러로 점등 및 중복 클릭 방지(`setEnabled(False)`).
  - 마우스 커서: 대기 커서(`Qt.WaitCursor`)로 전환.
  - `QApplication.processEvents()`를 즉시 강제 호출하여 화면 멈춤 없이 1프레임 만에 로딩 상태 표출.

### 2) 📊 하단 대시보드 상태 레이블 동적 피드백
- 대시보드 상단 레이블에 **`⚡ 선택 기간(YYYY-MM-DD ~ YYYY-MM-DD) 초단위 시뮬레이션 연산 중...`** 안내 메시지 표출.

### 3) 🏁 연산 완료 후 즉각 자동 복원
- 계산이 끝나면 0.01초 만에:
  - 버튼 텍스트: **`🚀 백테스트 실행 (Run Backtest)`** 및 골드 컬러로 복원.
  - 버튼 활성화(`setEnabled(True)`) 및 마우스 커서 정상화.
  - 성과 대시보드 및 거래 상세 일지 즉시 렌더링.
