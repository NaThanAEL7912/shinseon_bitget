# 기획서 264: 백테스터 UI 원클릭 "데이터 정렬" 자동 동기화 엔진 및 버튼 구축

## 1. 개요 및 배경
- 폐하의 지엄하신 어명: "매번 pkl을 만들 필요 없이, 시작일시/종료일시 옆 맨 오른쪽에 **'데이터 정렬'** 버튼을 만들어 원클릭으로 최신 실측 데이터를 자동 파싱·정렬할 수 있도록 구축하라."
- `downloads/` 폴더에 신규 일자 데이터(예: 8/24, 8/25 등)가 추가되더라도, 백테스터 UI에서 **"데이터 정렬"** 버튼을 한 번만 누르면 모든 CSV를 자동으로 스캔하여 최신 캐시를 자동 구축하고 날짜 범위를 동기화하도록 시스템을 완성합니다.

---

## 2. 세부 개발 계획

### 1) 🔄 UI 상단 "데이터 정렬 (Sync & Sort Data)" 버튼 신설
- 위치: 백테스터 GUI 상단 날짜 필터링 바 맨 오른쪽 (기본값 복원 옆 또는 프리셋 우측).
- 스타일: 네온 시안/골드 컬러의 고시인성 액션 버튼 (`QPushButton#btn_sync_data`).

### 2) ⚡ 스마트 원클릭 전수 데이터 정렬 엔진 (`sync_and_build_dataset`)
- 버튼 클릭 시 동작 파이프라인:
  1. `downloads/` 폴더 내 모든 날짜 하위 폴더(`2026-08-03` ~ `2026-08-23` ...) 및 `docs/historical_data/` 폴더 내 `orderflow_history_*.csv` 파일을 전수 자동 탐색.
  2. 1초 틱 단위로 청산액, OI속도, 가격, 결측치 필터링을 거쳐 24시간 연속 시계열 및 8대 세션별로 자동 분류·정렬.
  3. `scratch/parsed_session_data.pkl`로 압축 저장 (약 100만 틱을 2~3초 내에 고속 파싱).
  4. 데이터셋의 최소 날짜(예: 2026-08-03 00:00:00)와 최대 날짜(예: 2026-08-23 23:59:59)를 자동 계산하여 UI의 시작일시/종료일시 및 프리셋을 최신 범위로 자동 확장.
  5. "총 21일간 N만 틱의 데이터가 성공적으로 정렬되었습니다!" 완료 알림 팝업 출력 및 즉시 1회 백테스트 자동 갱신.

### 3) 독립 백그라운드 스레드 또는 고속 파서 적용
- 수십 MB의 CSV를 파싱하는 동안 UI가 멈추지 않도록 깔끔하게 처리.
