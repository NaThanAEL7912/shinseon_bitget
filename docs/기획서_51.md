# [기획서 51] 레버리지 ROE 수익률 및 USDT 실손익금액 동기화 표기 수술 (V4.53)

## 1. 개요 및 트레이스 백 정밀 팩트 원인 분석
- **폐하의 지적 사항:**
  "그러니까 내말은 +0.07%기 아닌데 그렇게 떠 있었어 지금 왼쪽 비트겟 포지션과 비교 해봐" (비트겟 웹 UI의 ROE 수치와 신선 터미널 표기 수치 불일치 지적 및 스크린샷 제출)
- **소신의 정밀 트레이스 백 100% 팩트 원인 밝혀냄:**
  1. **수익률 오차 원인:** 비트겟 웹 UI는 **레버리지(30배)가 반영된 ROE 수익률(예: `-2.17%`)**을 표시하는 반면, 기존 신선 서버 코드는 단순 1배수 가격 변동률(`-0.07%`)을 덤덤히 표시하고 있었던 표기 기준 불일치 맹점을 발견하였습니다.
  2. **USDT 손익금액(`+0.0 USDT`) 계산 오차 원인:** `CMD_SYNC_POSITION` 동기화 시 수량 단위 해석 오차(`/ 1000`)로 인해 실손익 금액이 0.0 USDT로 고정되어 표기되던 소수점 오차 맹점을 찾아내었습니다!

## 2. 상세 수술 및 원천 복구 계획 (V4.53)

###가. 비트겟 ROE(레버리지 반영 수익률) 및 정확한 USDT 손익금액 동시 표기 개편 (`shinseon_server.py`, `shinseon_client.pyw`)
1. **레버리지 반영 ROE 계산식 연동:**
   - $\text{ROE \%} = \text{가격 변동률 (\%)} \times \text{레버리지 (30배)}$
   - 예: 비트코인 가격이 -0.07% 변동 시 30배 레버리지 ROE는 **`-2.17%`**로 비트겟 화면과 100% 동일하게 표기됩니다.
2. **USDT 손익금액 소수점 정밀 표기 수술:**
   - 수량 계산식을 소수점 4자리까지 정밀 동기화하여 `(-0.06 USDT)`와 같이 비트겟 웹 화면의 실손익 금액과 100% 일치시킵니다.
3. **표기 포맷 개편:**
   - `[LONG 진입 @ 64,896.3] ROE: -2.17% (-0.06 USDT) (가격변동: -0.07%)`

###나. 소신(안티그래비티) 직접 수술 및 배포
1. 버전을 `V4.53`으로 지정.
2. 소신이 직접 소스코드 ROE 및 USDT 손익 수술 집행.
3. `deploy.py V4.53` 실행하여 Commit & GitHub main push.
4. AWS 서버 및 V4.53 대시보드 구동 후 비트겟 웹 UI와 ROE 수치/USDT 손익 100% 일치 최종 검증.
