# 기획서 221: 앱/웹 수동 진입 포지션 자동 케어 듀얼 TP/SL 선주문 호위 엔진 완공 (V6.19)

## 📌 1. 개요 및 팩트 분석
- **현상 및 필요성:**  
  폐하께서 봇 가동 중 비트겟 모바일 앱이나 웹사이트에서 수동으로 포지션을 잡으셨을 경우, 기존 봇은 1초 만에 포지션을 동기화하여 감시는 시작하지만 **비트겟 거래소 서버사이드 TP/SL 예약 선주문(Plan Order)**은 자동으로 전송되지 않는 2% 틈새가 존재하였습니다.

- **조치:**  
  실시간 계좌 동기화 루프(`sync_bitget_real_position_status`)에서 **"무포지션 상태 ➡️ 수동 신규 진입 감지 시(`was_inactive -> active`)"**를 포착하는 순간, 봇이 1초 만에 감지함과 동시에 **해당 수동 포지션의 평단가/수량/방향 팩트 수치를 기반으로 비트겟 거래소 TP (익절) 및 SL (손절) 선주문을 0.001초 만에 자동 전송 박아주는 수동 케어 호위 기능 완공**.
