# [기획서 71] 비트겟 v2 API 직송 스마트 스탑(손절/트레일링 익절 가드) 시스템 완전 신규 재설계 마스터 기획서 (V4.71)

## 1. 개요 및 폐하의 엄명 분석
- **폐하의 어명:**
  "오케이 그러면 이제 아까 스마트 스탑 설정 기능 기획안 작성해줘"
- **소신의 신규 기획 목표:**
  - `🌓 50% 시장가 분할 청산` 시스템 완공에 이어, **실시간 ROE 손절 및 트레일링 익절 가드 파수꾼인 [스마트 스탑 설정] 시스템을 완전 신규 설계**합니다.
  - 폐하께서 원하시는 ROE 오프셋(예: +6.0%)과 청산 비율(예: 100%)을 대시보드에서 설정하면, **AWS 릴레이 서버가 200ms 주기로 비트겟 포지션 ROE를 실시간 감시하다가 가드 범위를 이탈할 경우 비트겟 v2 API로 자동으로 칼청산**을 집행합니다.

## 2. 스마트 스탑 가드 시스템 UI 및 작동 아키텍처

```
[설정 값 입력 (오프셋 6.0%, 비율 100%)]
              │
[🛡️ 스마트 스탑 설정 버튼 클릭 (0.001s 비프음)]
              │
[AWS 릴레이 서버로 CMD_SET_SMART_STOP 패킷 전송]
              │
[AWS 서버 200ms 실시간 ROE 감시 루프 가동] ──(가드 이탈 시)──> [비트겟 v2 API 자동 청산]
              │                                                     │
[버튼 상태 🧹 해제 붉은색 전환] <──────(포지션 자동 동기화 0.1s)────────┘
```

### 가. UI 대시보드 제어판 디자인 (`shinseon_client.pyw`)
1. **위치:** 우측 제어판 `■ [BITGET] 스마트 스탑 가드 제어판` 전용 독립 구역
2. **입력 요소:**
   - `오프셋(%):` [ `6.0` ] % 입력 박스 (`edit_stoploss_offset`, 폭 45px, Consolas 폰트, `#00FFCC` 글자색)
   - `비율(%):` [ `100` ] % 입력 박스 (`edit_stoploss_ratio`, 폭 45px, Consolas 폰트, `#00FFCC` 글자색)
3. **버튼 토글 상태 및 비주얼 테마:**
   - **감시 OFF (기본 상태):**
     - 버튼 명칭: `🛡️ 스마트 스탑 설정`
     - 스타일: 세종 다크 브라운 골드 입체 그라디언트 (`stop:0 #4E4944, stop:1 #35312E`)
     - 입력 박스: 수정 가능 (`setEnabled(True)`)
   - **감시 ON (가동 중 상태):**
     - 버튼 명칭: `🧹 스마트 스탑 해제`
     - 스타일: 버건디 레드 경보 그라디언트 (`stop:0 #8C3838, stop:1 #5E2626`)
     - 입력 박스: 수정 차단 (`setEnabled(False)`)

### 나. 스마트 스탑 4단계 정밀 처리 프로세스

#### [1단계: 마우스 클릭 0.001초 비프음 & 입력값 검증]
- 마우스 클릭 0.001초 즉시 **윈도우 비프음(`QApplication.beep()`)** 발송
- 오프셋 값(기본 6.0%) 및 청산 비율(기본 100%) 추출 및 유효성 검증
- 포지션 미보유 시 팝업 안내: `⚠️ 현재 활성화된 포지션이 없어 스마트 스탑을 설정할 수 없습니다.`

#### [2단계: AWS 릴레이 서버 감시 패킷 동기화 전송]
- AWS 릴레이 서버로 `CMD_SET_SMART_STOP` WSS 패킷 전송:
  `packet = {'cmd': 'CMD_SET_SMART_STOP', 'active': True, 'offset_roe': offset_val, 'ratio': ratio_val}`
- 대시보드 로그 출력:  
  `🛡️ [스마트 스탑 설정 개시] ROE 오프셋: {offset_val:+.2f}%, 청산 비율: {ratio_val:.0f}% 감시 가드를 가동합니다.`
- UI 버튼을 `🧹 스마트 스탑 해제` 붉은색 경보 스타일로 전환

#### [3단계: AWS 서버 200ms 실시간 ROE 감시 & 자동 청산 집행 (`shinseon_server.py`)]
- AWS 서버가 200ms 시세 스트림 주기로 현재 포지션 ROE를 실시간 감시
- **가드 트리거 조건:**  
  `현재 ROE <= (진입/고점 ROE - offset_val)` 충족 시 즉시 자동 발동!
- **소액 포지션 가드 적용:**  
  `포지션 수량 <= 0.001 BTC` 시 전량 청산, `> 0.001 BTC` 시 `ratio_val` % 청산
- 비트겟 v2 REST API `place-order` 시장가 청산 직송!

#### [4단계: 체결 완료 텔레메트리 + 팝업 알림 + UI 자동 원복 (0.1초)]
- 자동 청산 완료 즉시 서버와 대시보드가 **`do_position_sync()` 포지션 자동 동기화를 실행**
- 대시보드 로그 출력: `✅ [스마트 스탑 작동 완료] 비트겟 시장가 청산 성공! (감시 자동 종료)`
- 화면 중앙 안내 팝업창(`QMessageBox.information`):  
  `🛡️ 비트겟 포지션에 {offset_val:+.2f}% ROE 스마트 스탑 감시가 설정되었습니다!\n(서버 실시간 감시 엔진 연동 완료)`
- 청산 체결 후 UI 버튼을 `🛡️ 스마트 스탑 설정` 기본 상태로 자동 원복
