# ShinSeon Bitget 기획서_104

## 📌 개요
엑셀(Excel)에서 CSV 파일 오픈 시 한글 헤더 깨짐 현상을 원천 방지(한국어 윈도우 MS Excel 100% 직송 지원 인코딩 적용)하고, 타임스탬프 표기 시 '초'(`:SS`) 단위가 엑셀 셀 서식 자동 축약 없이 100% 한눈에 선명하게 표기되도록 CSV 로깅 엔진을 수정합니다.

---

## 🎯 개발 항목
- [x] 1. **한글 헤더 깨짐 원천 박멸 (인코딩 CP949/EUC-KR & UTF-8-SIG 호환 고도화)** (개발 완료)
  - 한국어 윈도우 MS 엑셀에서 더블클릭 오픈 시 한글 헤더(`일시(KST)`, `비트코인 시세($)` 등 10개 칼럼)가 깨지지 않고 100% 정상 표시되도록 CSV 저장 및 다운로드 파일 인코딩 보강.
- [x] 2. **시간 표기 '초'(:SS) 단위 100% 시각화 보장** (개발 완료)
  - 타임스탬프 포맷을 `YYYY-MM-DD HH:MM:SS`로 명확히 작성하고, 엑셀 열림 시 초 단위 생략 없이 표기되도록 텍스트 보장 서식 연동.
- [x] 3. **기존 CSV 파일 자동 일괄 재정화 (Migration & Encoding Conversion)** (개발 완료)
  - 이미 생성된 `orderflow_history_YYYY-MM-DD.csv` 파일의 헤더 깨짐과 구 포맷 데이터를 100% 한글 CP949/UTF-8-SIG 정격 포맷으로 일괄 변환 정화.
- [x] 4. **구문 검증 및 AWS 서버 배포 (V5.04)** (개발 완료)
  - `py_compile` 검증 후 `python deploy.py V5.04` 배포 및 AWS 서버 재시작.

---

## 🛠 상세 구현 내용
1. `shinseon_server.py` 내 `_write_csv` 및 `CMD_REQ_FILE_DOWNLOAD` 핸들러의 CSV 기록 인코딩을 한국어 윈도우 Excel 직통 호환(`cp949` 및 `utf-8-sig`)으로 안전 처리.
2. 타임스탬프 포맷을 `YYYY-MM-DD HH:MM:SS` 초 단위까지 명확한 문자열로 기록.
3. 기존 CSV 파일 헤더를 신규 한글 CP949/UTF-8-SIG 헤더로 깔끔하게 교정하는 마이그레이션 실행.
