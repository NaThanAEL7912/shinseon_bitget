# 신선 비트겟 (ShinSeon_Bitget) 프로젝트 기획서 3

## 안티그래비티 ➔ 오픈클로(OpenClaw) 완벽한 소통(명령) 프로토콜

폐하의 염려처럼, 오픈클로가 단순히 "이거 테스트해줘"라는 말만 듣고 정확한 검수를 해내기는 어려울 수 있사옵니다. 따라서 오픈클로가 **100% 찰떡같이 알아듣고 테스트하게 만드는 프로토콜**을 다음과 같이 기획하였나이다.

### 1. 테스트 지시서(TEST_INSTRUCTION.md) 자동 생성
소신(안티그래비티)이 비트겟 연동 코드 개발을 완료하면, 코드만 덩그러니 넘기는 것이 아니라 **오픈클로 전용 테스트 지시서**를 작성합니다.
이 지시서에는 다음 내용이 포함됩니다.
* 어떤 파일(로직)이 수정/생성 되었는지
* 어떤 명령어를 실행하여 테스트 서버를 띄울 것인지
* 브라우저를 열고 어떤 버튼을 눌러야(혹은 어떤 API를 찔러야) 하는지
* **검수 통과 기준** (예: "로그에 '주문 완료'가 뜨는지 확인하라")

### 2. 명확한 호출 명령어 실행
소신은 지시서 작성을 마친 후, 터미널에서 오픈클로를 호출할 때 지시서의 위치를 정확히 짚어줍니다.
> `openclaw agent --message "폐하의 어명이다. C:\Working\AntiGravity\ShinSeon_Bitget\TEST_INSTRUCTION.md 문서를 정독하고, 그 안에 적힌 순서대로 브라우저를 열어 모의 테스트를 진행한 뒤 결과를 텔레그램으로 보고하라" --deliver`

### 3. 오픈클로의 지능적 수행
오픈클로 역시 강력한 인공지능 에이전트이므로, 지시서(Markdown)를 스스로 읽고(view_file 도구 등 사용), 브라우저를 띄우거나 터미널 테스트 스크립트를 실행하는 등 명시된 테스트 절차를 완벽하게 따라 할 수 있사옵니다.
