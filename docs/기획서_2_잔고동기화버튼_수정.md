# [기획서 2] 실전 계좌 잔고 동기화 깡통 버튼 수술 기획

기존 V4.12 뷰어에서 [실전 계좌 잔고 동기화] 버튼이 껍데기(로그만 출력)로 방치되어 있던 치명적 결함을 뜯어고쳐, 서버와 다이렉트로 통신(Plan A 정공법)하게 만드는 기획이옵니다.

## User Review Required

> [!IMPORTANT]
> 버튼 클릭 시 서버로 잔고 조회 웹소켓을 날리게 됩니다.
> 기존 기능과 충돌 없이 매끄럽게 작동하도록 서버와 클라이언트 양쪽을 모두 수술합니다. 
> 문제가 없는지 결재(고고)를 부탁드리옵니다!

## Proposed Changes

---

### 클라이언트단 (shinseon_client.pyw)

#### [MODIFY] shinseon_client.pyw
- `do_sync_balances()` 함수 로직을 전면 수정합니다.
- 기존: 로그만 띄우고 종료
- 변경: 
  - `await self.ws.send(json.dumps({"cmd": "CMD_SYNC_POSITION"}))` 코드를 삽입하여 서버에 즉각 갱신 명령 전송
  - 명령 전송 후 서버로부터 `EVT_SYNC_BALANCE` 응답이 오면 우측 상단 자본금 디스플레이 텍스트가 $20,000에서 실제 잔고로 변경됨

---

### 서버단 (shinseon_server.py)

#### [MODIFY] shinseon_server.py
- 현재 클라이언트가 `CMD_SYNC_POSITION` 명령을 보내면 서버에서 잔고를 긁어오도록 연동되어 있으므로 서버 쪽 통신 라인은 이미 정상입니다.
- 단지 클라이언트 버튼이 이를 호출하지 않았던 것이므로 클라이언트 단 수술만으로 완벽히 해결됩니다.
