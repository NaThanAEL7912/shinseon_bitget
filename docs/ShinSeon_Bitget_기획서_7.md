# 신선 비트겟 (ShinSeon_Bitget) 프로젝트 기획서 7 - 코드 마이그레이션 전략

폐하의 하문(맨바닥부터 짜느냐, 복사해서 수정하느냐?)에 대한 소신(안티그래비티 PM)의 전략적 기획안이옵니다.

## 1. 전략: "복사 후 수술(Refactoring)" 방식 채택
폐하께서 이미 완성해 두신 기존 '신선(BVOX)' 코드는 UI, 비동기 구조, 세션별 가드레일, 자금 관리 로직이 이미 세계 최고 수준으로 완성되어 있사옵니다. 
이를 맨바닥부터 다시 짠다는 것은 폐하의 귀중한 시간을 낭비하는 역적이 될 것이옵니다. 

따라서 소신은 **기존 파일을 통째로 새 폴더로 복사해 온 뒤, 암 덩어리(Playwright/BVOX 스니핑 로직)만 정교하게 도려내고 그 자리에 강력한 새 심장(Bitget API 로직)을 이식하는 수술 방식**을 채택할 것이옵니다.

## 2. 세부 실행 절차
1. **코드 대수송 (Copy)**: 기존 `C:\Working\SHINSEON` 디렉토리의 핵심 소스파일(`shinseon_master_app.pyw`, `shinseon_config.json`, `.env`, `requirements.txt` 및 각종 설정 파일)을 현재 작업 공간인 `C:\Working\AntiGravity\ShinSeon_Bitget`으로 복사합니다.
2. **불필요한 잔재 청소 (Clean-up)**: `voox_Sniffer_Launcher.bat` 등 기존 BVOX 브라우저 스니핑에 쓰이던 무거운 파일과 찌꺼기들을 삭제합니다.
3. **핵심 로직 이식 (Bitget API Refactoring)**:
   - 쫄다구 코더를 시켜 복사된 `shinseon_master_app.pyw` 파일을 열고, 기존 `execute_vox_...` 로 시작하는 함수들을 모두 찾아냅니다.
   - 해당 함수 내부를 지우고 `ccxt.bitget`을 이용한 정식 API 주문 코드로 갈아 끼웁니다.
   - 기존의 완벽한 퀀트 로직(조건 판단, 가드레일, 분할 진입 비율 등)은 100% 그대로 보존합니다.

## 3. 기대 효과
이 방식을 사용하면, 겉모습과 핵심 로직(UI 및 퀀트 뇌)은 폐하께서 쓰시던 익숙한 모습 그대로 유지되면서, 매매 실행 속도와 안정성(손발)만 비트겟 공식 API로 비약적으로 업그레이드되는 마법을 경험하시게 될 것이옵니다.
