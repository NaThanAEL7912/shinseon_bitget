# [기획서 363] 대시보드 실시간 오더플로우 레이더 초단순 롱/숏 유리 뱃지 개편 및 V7.66 배포 기획서

## 1. 개요 및 목적
- **목적**: 대시보드 우측 실시간 오더플로우 레이더 뱃지의 복잡하고 장황한 문구들을 완전히 제거하고, 국왕 폐하의 직관적인 시장 상황 파악을 위해 초단순 3색 뱃지(`[ 🟢 지금은 롱이 유리하다 ]`, `[ 🔴 지금은 숏이 유리하다 ]`, `[ ⚪ 지금은 관망이 유리하다 ]`)로 전면 개편.
- **텔레메트리 연동**: 실전 서버(`shinseon_server.py`)의 `telemetry_loop`에서 백서 V2.55 황금 4대 매트릭스 및 0.035% 동적 불감대를 엄격히 연동하여 오더플로우 기세를 실시간으로 정확하게 클라이언트에 전달.
- **버전 삼위일체**: V7.66으로 전체 시스템 버전 동기화 및 AWS 실전 서버 원격 배포.

## 2. 세부 개발 명세

### 2.1 클라이언트 레이더 힌트 뱃지 개편 (`shinseon_client.pyw`)
- `_apply_radar_hint(self, expected_dir)` 메서드 신설 및 캐싱 가드 연동:
  - 롱 유리 (`LONG` 또는 `BULLISH` 포함 시): `[ 🟢 지금은 롱이 유리하다 ]` (에메랄드 그린 배경/테두리/네온 텍스트)
  - 숏 유리 (`SHORT` 또는 `BEARISH` 포함 시): `[ 🔴 지금은 숏이 유리하다 ]` (강렬한 레드 배경/테두리/밝은 레드 텍스트)
  - 관망/중립 (그 외): `[ ⚪ 지금은 관망이 유리하다 ]` (차분한 그레이 배경/테두리/회색 텍스트)
- `self.CURRENT_VERSION`: `"V7.66"` 갱신.

### 2.2 서버 텔레메트리 기세(Flow Bias) 연산 정밀화 (`shinseon_server.py`)
- 백서 V2.55 4대 매트릭스 + 0.035% 불감대 공식 적용:
  ```python
  binance_mid = self.current_price
  deadband_5s = binance_mid * 0.00035
  is_up = (price_delta_5s >= deadband_5s) or (price_delta_1m > 0 and price_slope_1m >= 0.30)
  is_down = (price_delta_5s <= -deadband_5s) or (price_delta_1m < 0 and price_slope_1m <= -0.30)

  if is_down and oi_delta_1m < 0:
      flow_bias = "LONG_FAVORED"
  elif is_up and oi_delta_1m < 0:
      flow_bias = "SHORT_FAVORED"
  elif oi_delta_1m > 0:
      if is_up:
          flow_bias = "LONG_FAVORED"
      elif is_down:
          flow_bias = "SHORT_FAVORED"
      else:
          flow_bias = "NEUTRAL"
  else:
      flow_bias = "NEUTRAL"

  if direction in ["LONG", "SHORT"]:
      hint_val = f"SNIPE_{direction}"
  else:
      hint_val = f"BIAS_{flow_bias}"
  ```
- `self.CURRENT_VERSION`: `"V7.66"` 갱신.
