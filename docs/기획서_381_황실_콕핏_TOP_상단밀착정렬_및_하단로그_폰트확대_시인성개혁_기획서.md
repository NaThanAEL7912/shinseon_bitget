# [기획서 381] 황실 콕핏 TOP 상단 밀착 정렬 및 하단 로그 폰트 확대 시인성 개혁 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 황실 콕핏 V1.00 구동 화면을 검토하시며 **"중간 정렬 때문인지 상단에 공간이 너무 붕 떠 버린다. TOP 상단으로 밀착 정렬해 달라"**는 레이아웃 개선 어명을 내리심.
  - 또한 **"하단 로그 부분 글자가 너무 작아서 읽을 수가 없다. 시원하게 키워 달라"**는 가독성 개혁을 하사하심.

- **목적**:
  1. `shinseon_cockpit.pyw` 메인 레이아웃에 **[ TOP 상단 밀착 정렬 (`Qt.AlignTop`) ]**을 적용하여, 창 높이가 늘어나도 모든 카드가 위에서부터 정갈하고 컴팩트하게 밀착되도록 개편.
  2. 하단 로그창(`self.txt_log`)의 폰트 크기를 기존 10px에서 **[ 13px 굵은 고대비 폰트 ]**로 대폭 확대하고 창 높이를 120px로 확장하여 최상의 시인성 제공.
  3. 콕핏 버전을 **V1.01**로 순차 상향 및 이력 관리 대장 등재.

## 2. 세부 개발 명세

### ① 메인 레이아웃 TOP 상단 밀착 정렬 (`Qt.AlignTop`)
- `main_layout = QVBoxLayout(central_widget)`
- `main_layout.setAlignment(Qt.AlignTop)` 설정 적용.
- `main_layout.setSpacing(6)` 및 각 카드 마진 최적화로 상단 붕 뜨는 빈 공간을 100% 완전 박멸.

### ② 하단 로그창(`QPlainTextEdit`) 폰트 확대 및 가독성 개혁
- 폰트 크기: `10px` ➔ **`13px (Bold)`** 확대.
- 스타일시트:
  ```css
  QPlainTextEdit {
      background-color: #06080b;
      border: 1px solid #1e2638;
      border-radius: 6px;
      color: #F1F5F9;
      font-family: 'Consolas', 'Pretendard', 'Malgun Gothic', monospace;
      font-size: 13px;
      font-weight: bold;
      line-height: 1.4;
      padding: 4px;
  }
  ```
- 로그창 높이: 기존 80px ➔ **120px**로 시원하게 확장.

### ③ 콕핏 전용 버전 V1.01 갱신
- `self.COCKPIT_VERSION = "V1.01"`
- 윈도우 타이틀: `[SHINSEON] 황실 수동 콕핏 V1.01 (가로 500px 초슬림 · 비트겟 직통)`
- 상단 헤더: `👑 황실 수동 콕핏 V1.01`
