# 기획서 188: 평일 및 주말 8대 세션 전용 최적 임계치 전수조사 방안

## 1. 개요 및 배경
폐하께서 제시해 주신 **"세션별 설정 UI 폼"**의 구조와 1:1로 완벽히 부합하도록, 보유 중인 8월 8일~8월 13일(총 6일치: 주말 2일 + 평일 4일) CSV 오더플로우 전수 데이터를 **평일 4개 세션 및 주말 4개 세션 (총 8대 세션)**으로 정밀 분리하여, UI 설정 입력폼에 들어갈 **단 하나의 최적 수치 세팅표**를 정공법으로 도출하는 방안을 수립합니다.

---

## 2. 데이터 분류 및 8대 세션 시간 구분 명세

### A. 평일 세션 데이터 (2026-08-10 07:00 ~ 2026-08-13 24:00)
1. **평일 아시아**: KST 09:00 ~ 16:00
2. **평일 유럽**: KST 16:00 ~ 22:30
3. **평일 미국 본장**: KST 22:30 ~ 05:00
4. **평일 태평양 횡보**: KST 05:00 ~ 09:00

### B. 주말 세션 데이터 (2026-08-08 06:00 ~ 2026-08-10 07:00)
5. **주말 아시아**: 주말 중 KST 09:00 ~ 16:00
6. **주말 유럽**: 주말 중 KST 16:00 ~ 22:30
7. **주말 미국 본장**: 주말 중 KST 22:30 ~ 05:00
8. **주말 태평양 횡보**: 주말 중 KST 05:00 ~ 09:00

## 3. 백테스팅 파라미터 탐색 범위
- **1분 누적 청산액 ($)**: $100,000 ~ $2,000,000 (10만 단위 스텝)
- **1분 OI 속도 (%)**: 0.05% ~ 0.35% (0.01%~0.02% 단위 스텝)
