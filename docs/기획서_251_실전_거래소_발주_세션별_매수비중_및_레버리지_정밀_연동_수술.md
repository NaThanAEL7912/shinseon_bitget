# 📋 기획서 251: 실전 비트겟 REST API 발주부 세션별 독립 매수 비중 및 레버리지 100% 정밀 연동 수술 기획서

---

## 🎯 1. 개요 및 배경
- **현상 및 문제점:**  
  폐하의 날카로운 혜안으로 코드 전수 조사를 진행한 결과, 시뮬레이션 및 DCA 추가매수 트리거 영역은 세션별 설정(`s_tr.get(...)`)을 정상 참조하고 있었으나, **실제 비트겟 거래소로 REST API 주문을 직송하는 핵심 발주 블록(라인 2298~2307)**에서 레거시 단일 전역 변수(`dashboard.split_entry_1_ratio`, `dashboard.leverage_level`)를 여전히 직접 읽고 있는 잔재가 발견되었습니다.
- **영향:**  
  이로 인해 태평양 장(1차 100%, 레버리지 30배)이나 미국 본장(1차 500%) 등 세션별로 비중을 다르게 설정하더라도, 실제 거래소 발주 수량 계산 시에는 아시아 기본 단일값(1차 300%)으로 계산되어 나갈 위험이 있었습니다.
- **목적:**  
  실제 비트겟 거래소 발주 함수(`_execute_bitget_internal_packet_impl`)의 진입 주문 수량 및 레버리지 계산 블록에 **현재 KST 시각 기준 8대 세션 매트릭스(`s_tr = tr_configs.get(s_thresh_key)`)를 100% 정공법으로 완벽 결합**하여, 폐하께서 설정하신 세션별 1/2/3차 매수 비중과 레버리지가 실제 비트겟 주문에 0.001%의 오차도 없이 정확히 반영되도록 수술합니다.

## 🛠️ 2. 상세 작업 명세

### ① 비트겟 실전 발주 수량 및 레버리지 계산부 수술 (`shinseon_server.py` 라인 2290~2325)
1. **실시간 세션 키 산출 및 딕셔너리 로딩:**
   ```python
   now_dt = get_kst_now()
   is_weekend = check_is_weekend_kst(now_dt)
   hour_val = now_dt.hour
   minute_val = now_dt.minute
   if 9 <= hour_val < 16:
       s_thresh_key = "weekend_asia" if is_weekend else "asia"
   elif 16 <= hour_val < 22 or (hour_val == 22 and minute_val < 30):
       s_thresh_key = "weekend_europe" if is_weekend else "europe"
   elif (hour_val == 22 and minute_val >= 30) or hour_val >= 23 or hour_val < 5:
       s_thresh_key = "weekend_us" if is_weekend else "us"
   else:
       s_thresh_key = "weekend_pacific" if is_weekend else "pacific"
       
   tr_configs = getattr(self, "session_trading_configs", None) or getattr(dashboard, "session_trading_configs", {}) or {}
   s_tr = tr_configs.get(s_thresh_key, {})
   ```
2. **세션별 독립 매수 비중(`ratio`) 및 레버리지(`lev`) 정밀 추출:**
   - 1차 진입: `ratio = float(s_tr.get("split_entry_1_ratio", getattr(dashboard, "split_entry_1_ratio", 300.0)))`
   - 2차 추가매수: `ratio = float(s_tr.get("split_entry_2_ratio", getattr(dashboard, "split_entry_2_ratio", 150.0)))`
   - 3차 추가매수: `ratio = float(s_tr.get("split_entry_3_ratio", getattr(dashboard, "split_entry_3_ratio", 0.0)))`
   - 레버리지: `lev = float(s_tr.get("leverage", getattr(dashboard, "leverage_level", getattr(self, "leverage_level", 30.0)))) or 30.0`
3. **정확한 BTC 주문 수량(`amount`) 산출 후 비트겟 v2 API 직송 발주.**
