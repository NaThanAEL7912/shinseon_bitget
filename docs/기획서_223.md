# 기획서 223: 대시보드 UI 설정값 연동 익절 선주문 수량 50% 정률 쪼개기 엔진 완공 (V6.22)

## 📌 1. 개요 및 팩트 목적
- **목적:**  
  폐하의 신선 대시보드 UI 설정 창의 **`분할 익절 청산 비율 (%): 50.0`** 설정과 1:1 완벽 연동하여, 비트겟 거래소에 미리 박아두는 서버사이드 익절(TP) 선주문의 수량을 100%가 아닌 **딱 50% 정률 수량으로 쪼개서 선주문 배치**함.

- **원칙:**  
  1. **TP (익절 지정가 선주문):** 전체 포지션 수량의 **`50%`** (`qty_btc * 0.50`) 수량만 TP 지정가 선주문으로 박음.
  2. **SL (손절 조건가 선주문):** 시드 보호를 위해 **`100%`** (`qty_btc`) 전량 수량으로 손절 방화벽 박음.

## 🛠️ 2. 작업 상세 내역
1. **`shinseon_server.py` L1800 `place_bitget_tpsl_plan_orders` 연산 수정:**
   - `split_ratio = float(getattr(dashboard, "split_close_ratio", 50.0)) / 100.0`
   - `tp_qty = round(qty_btc * split_ratio, 4)`
   - `tp_body` 에 `size: str(tp_qty)` 및 `planType: "pos_profit"` 파라미터 전송.
2. **결과:**  
   비트겟 차트 상에 **익절 라인은 50% 수량만 1차 익절 예약**으로 깔끔하게 그려짐!
