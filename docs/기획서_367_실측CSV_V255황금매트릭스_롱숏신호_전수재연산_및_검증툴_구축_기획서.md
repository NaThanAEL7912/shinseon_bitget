## 2. 핵심 알고리즘 명세 (V2.55 황금 매트릭스 & 0.035% 동적 불감대)
1. **동적 불감대 산출**:
   - `deadband_val = price * 0.00035` (0.035%)
2. **가격 모멘텀 판정**:
   - `is_price_up = (price_delta_5s >= deadband_val) or (price_delta_1m > 0 and price_slope_1m >= 0.30)`
   - `is_price_down = (price_delta_5s <= -deadband_val) or (price_delta_1m < 0 and price_slope_1m <= -0.30)`
3. **4-case 롱/숏 신호 판정**:
   - 트리거 조건: `rolling_1m_liq >= target_liq` and `abs(oi_speed) >= target_oi`
   - Case 1 (롱 청산/스퀴즈 해소 + 급락): `is_price_down` and `oi_speed < 0` $\rightarrow$ **`LONG`** (과매도 역추세 반등 저격)
   - Case 2 (숏 청산/스퀴즈 해소 + 급등): `is_price_up` and `oi_speed < 0` $\rightarrow$ **`SHORT`** (과매수 역추세 하락 저격)
   - Case 3 (신규 롱 진입 + 급등): `oi_speed > 0` and `is_price_up` $\rightarrow$ **`LONG`** (추세 추종 돌파 저격)
   - Case 4 (신규 숏 진입 + 급락): `oi_speed > 0` and `is_price_down` $\rightarrow$ **`SHORT`** (추세 추종 하방 돌파 저격)
   - 그 외: `NONE`
