# [기획서 379] 황실 콕핏 본 계정 API 직접 연동 실시간 포지션 HUD 및 원클릭 주문 완벽 복구 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 수동매매 콕핏(`shinseon_cockpit.pyw`)을 실행하여 비트겟 실시간 포지션 동기화(`🔄 동기화`)를 시도하셨으나, **[본 계정 실시간 포지션 HUD]가 `NO POSITION`으로 멈춰 있고 현재 보유 중이신 `2.0 BTC SHORT @ $78,066.71` 포지션이 표시되지 않는 현상**이 발생함.
  - 정밀 진단 결과: 콕핏이 AWS 실전 릴레이 서버 소켓에만 의존하고 있었는데, AWS 서버가 봇 자동매매 계정을 바라보고 있어 폐하의 **본 계정 실전 수동매매 포지션**을 읽어오지 못하는 구조적 한계가 존재했음.

- **목적**:
  1. `shinseon_cockpit.pyw` 내부에 **[비트겟 본 계정 직접 통신 엔진(ccxt/REST Worker)]**을 신설하여, AWS 서버를 거치지 않고 로컬에서 본 계정 API(`bg_670c796...`)를 직접 호출.
  2. 1초 주기로 본 계정의 포지션(`2.0 BTC SHORT @ $78,066.71`), 미실현 손익, 강제 청산가를 HUD에 즉시 실시간 렌더링.
  3. 콕핏의 `원클릭 빠른 시장가 진입`, `무위험 본전가드`, `2단 안전방패(TP/SL)`, `50% 분할청산`, `비상 탈출` 버튼들이 본 계정에 직접 광속으로 작동하도록 100% 직결.
  4. 시스템 전체 버전을 **V7.81**로 순차 상향 및 삼위일체 동기화.

---

## 2. 세부 개발 명세

### ① 비트겟 본 계정 직통 워커 (`BitgetMainDirectWorker(QThread)`) 장착
- `shinseon_cockpit.pyw` 내부에 본 계정 전용 비동기 스레드 구축:
  - 폐하의 본 계정 API 키(`bg_670c7963afe129099346583180ce606b`) 직접 로드.
  - 1초 주기로 `fetch_positions(['BTC/USDT:USDT'])` 및 `fetch_balance()` 직접 호출.
  - 포지션 변동 시 시그널(`position_updated = Signal(dict)`) 방출하여 HUD를 0.1초 만에 갱신.
  - 네트워크 단절 시에도 부드러운 재시도로 0 Crash 보장.

### ② HUD 실시간 렌더링 및 동기화 버튼 즉시 반응
- `🔄 동기화` 버튼 클릭 시 비동기 스레드가 0.05초 만에 REST를 즉시 강제 갱신하여 딜레이 없이 최신 상태 반영.
- 포지션 보유 시:
  ```text
  포지션: 🔴 SHORT (60x)     보유수량: 2.0000 BTC
  진입평단: $78,066.71       현재가격: $78,065.00
  미실현손익: +$3.42 USDT (+0.07%)
  청산가/안전: $78,950.0 (안전거리: +$885.0 달러 🟢)
  ```

### ③ 5대 황실 원클릭 버튼 본 계정 직결 발주
- `원클릭 시장가 롱/숏 진입`: 본 계정에 직접 시장가 주문 전송.
- `무위험 본전가드 (BE Shield)`: 본 계정 평단가에 손절선 자동 드래그 장착.
- `2단 안전방패 (TP/SL)`: 본 계정에 지정가 TP 및 SL 즉각 발주.
- `50% 시장가 분할 청산`: 본 계정 포지션의 50% 즉시 시장가 익절/탈출.
- `비상 탈출 (EMERGENCY)`: 100% 전량 시장가 청산 및 대기 주문 전량 취소.

### ④ 버전 삼위일체 V7.81 갱신
1. `shinseon_cockpit.pyw` : `self.CURRENT_VERSION = "V7.81"`
2. `shinseon_server.py` : `self.CURRENT_VERSION = "V7.81"`
3. `shinseon_client.pyw` : `self.CURRENT_VERSION = "V7.81"`
4. `shinseon_config.json` : `"CURRENT_VERSION": "V7.81"`
5. `docs/shinseon_whitepaper.html` : 마스터 백서 버전 `V7.81 (20260830)` 갱신
6. `docs/프로젝트_버전_관리.md` : V7.81 이력 등재
