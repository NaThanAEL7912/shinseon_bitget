# [기획서 42] 로그 폰트 1pt 가독성 확대 및 바이낸스 찐청산 화이트/그린 상태등 개편 (V4.45)

## 1. 개요 및 요구사항 분석
- **폐하의 어명:**
  1. 하단 실시간 로그 창 폰트 크기가 작아 가독성이 떨어지므로 1포인트 키워줄 것 (`11px` ➔ `12px`).
  2. 바이낸스 1분 누적 청산 표시 상태등(컬러/아이콘) 로직 개편:
     - 1분 이내에 실제로 바이낸스 찐청산 패킷(`forceOrder`, `has_real_force == True`) 신호가 감지되었을 때만 **그린 연두색(`🟢`, `#00FFCC`)** 불이 들어올 것.
     - 단순 체결량 추정치일 때는 **화이트 흰색(`⚪`, `#FFFFFF`)**으로 명확히 구분 표시할 것.

## 2. 상세 수술 및 원천 복구 계획 (V4.45)

###가. 로그 폰트 가독성 1pt 확대 수술 (`shinseon_client.pyw`)
- `self.txt_log` QSS 스타일시트 내 `font-size: 11px;`를 `font-size: 12px;`로 1포인트 상향 조정하여 눈이 시원하고 또렷하게 읽히도록 수술.

###나. 바이낸스 1분 누적 청산 화이트/그린 상태등 로직 전면 개편 (`shinseon_client.pyw`)
1. **`has_real_force == True` (1분 이내 찐청산 포착 시):**
   - 아이콘: `🟢` (그린 연두색 불)
   - 텍스트 색상: `#00FFCC` (네온 그린)
   - 문구: `바이낸스 1분 누적 청산 (실시간 찐청산 감지)`
2. **`has_real_force == False` (단순 체결량 추정 시):**
   - 아이콘: `⚪` (화이트 흰색)
   - 텍스트 색상: `#FFFFFF` (순백색)
   - 문구: `바이낸스 1분 누적 청산 (체결량 추정)`
3. **`liq_wss_connected == False` (소켓 끊김 시):**
   - 아이콘: `🚨` (레드 경고)
   - 텍스트 색상: `#FF4D4D` (레드)
   - 문구: `바이낸스 끊김 (재접속 중)`
