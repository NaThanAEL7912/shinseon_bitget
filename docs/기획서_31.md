# [기획서 31] Python 3.14 qasync 태스크 재진입 충돌 수술 및 부팅 접속 성공률 100% 완전 복구 (V4.36)

## 1. 개요 및 정밀 실측 팩트 분석
- **폐하의 지적 사항:**
  "[03:35:58] ⚠️ [웹소켓] 웹소켓 연결이 닫혔거나 재연결 중입니다. 5번 재실행 햇는데도 안된다."
- **정밀 트레이스 백 팩트 원인 분석:**
  1. 소신이 직접 터미널에서 `qasync` 이벤트 루프 예외를 추적한 결과, 아래의 핵심 오류가 100% 실측되었습니다.
     `RuntimeError: Cannot enter into task <Task ...> while another task <Task ... coro=<run_startup_sync_sequence>> is being executed.`
  2. **원인:** Python 3.14 환경의 `qasync`(Qt + asyncio 루프 바인딩)에서 부팅 시 `run_startup_sync_sequence` 내의 `asyncio.to_thread`(라이선스 동시 검증)와 `connect_websocket`(웹소켓 접속), `run_manual_latency_test` 등 **여러 비동기 태스크가 동시에 스레드풀 콜백을 칠 때 `qasync` 루프 재진입(Re-entrancy) 충돌이 발생**하던 맹점이 밝혀졌습니다.
  3. 이 충돌이 터지면 `connect_websocket` 태스크가 순간 강제 취소되어 소켓이 닫히고 `웹소켓 연결이 닫혔거나 재연결 중입니다` 알림과 함께 5번 중 4번 부팅에 실패했던 근본 원인이었습니다.
