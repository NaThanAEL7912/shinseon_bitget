## 2. 세부 개편 및 수술 설계 (정공법)

### 가. `server.log` 및 전체 로그 엔진 타임스탬프 정격 적용
- 기존: `INFO:ShinseonBot:[UI] [LONG 진입 @ 64,527.0] ...` (날짜/시각 미표시)
- 개편: **`[2026-08-07 04:10:20.123] [INFO] [ShinseonBot] [UI] [LONG 진입 @ 64,527.0] ...`**
- Python `logging.Formatter` 포맷을 `[%(asctime)s.%(msecs)03d] [%(levelname)s] %(message)s` 로 정격 구성하여 초 단위/밀리초 단위까지 정확한 일시 기록.

### 나. 일별 CSV 오더플로우 임계치 데이터 정격 기록 (`docs/historical_data/orderflow_history_YYYY-MM-DD.csv`)
- 1분 주기(또는 타점 포착 시)로 아래 11개 핵심 칼럼을 누적 기록합니다.

| 칼럼 명칭 | 설명 | 예시 데이터 |
|---|---|---|
| **`timestamp`** | 년-월-일 시:분:초 | `2026-08-07 04:10:20` |
| **`btc_price`** | 비트코인 현재가 ($) | `64885.0` |
| **`liq_1m_total`** | 1분 누적 청산 금액 ($) | `271719` |
| **`liq_1m_long`** | 1분 Long 청산 금액 ($) | `214394` |
| **`liq_1m_short`** | 1분 Short 청산 금액 ($) | `57325` |
| **`liq_threshold`** | 세션 청산 임계치 ($) | `500000` |
| **`oi_1m_pct`** | 1분 Open Interest 변동률 (%) | `-0.0055` |
| **`oi_threshold`** | 세션 OI 속도 임계치 (%) | `+0.2000` |
| **`signal`** | 타점 시그널 | `LONG` / `SHORT` / `NONE` |
| **`session`** | 세션 종류 | `ASIA` / `LONDON` / `NY` / `PACIFIC` / `WEEKEND` |
| **`bot_state`** | 봇 구동 상태 | `RUNNING` / `STOPPED` |

### 다. 일별 트레이딩 및 스캔 로그 정격 기록 (`logs/shinseon_trade_YYYY-MM-DD.log`)
- 초 단위/분 단위 스캔 로그 예시:
  ```text
  [2026-08-07 04:10:20.123] 🔍 [오더플로우 스캔] 비트코인: $64,885.0 | 1분청산: $271,719 / $500,000 (L:$214.3k, S:$57.3k) | OI속도: -0.0055% / +0.2000% | 타점: NONE [세션: NY]
  ```
