• 조건: 숏 청산 폭발 + -OI (매수 고갈) + 5초 하락 꺾임 (delta_5s < -15$)

• 메커니즘: 숏커버링 종료 후 첫 하락 꺾임 포착 ➔ 🔴 최고점 역V자 숏 저격!
