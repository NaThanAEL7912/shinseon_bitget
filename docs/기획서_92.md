## 2. 세부 수술 내역 (날짜별 CSV + LOG 통합 다운로드 파이프라인)

### 가. AWS 서버 일별 날짜 CSV & LOG 이중 저장 엔진 (`shinseon_server.py`)
- 매일 자정(00:00:00 KST) 날짜가 변경될 때 자동으로 새로운 일자 파일 생성:
  - 📊 **일별 오더플로우 CSV**: `/home/ubuntu/logs/shinseon_data_YYYY-MM-DD.csv` (타점 시세, CVD, OI, 1분 청산 물량 등)
  - 📝 **일별 트레이딩 LOG**: `/home/ubuntu/logs/shinseon_trade_YYYY-MM-DD.log` (진입 사유, 청산 사유, 체결 내역, 쿨타임, 파라미터 변경 이력)

### 나. WebSocket 서버 통신 프로토콜 구현 (`shinseon_server.py`)
- `CMD_REQ_FILE_LIST`: 서버에 보관 중인 일자 목록(예: `["2026-08-06", "2026-08-05"...]`)을 클라이언트로 즉시 응답 (`EVT_FILE_LIST`).
- `CMD_REQ_FILE_DOWNLOAD`: 폐하께서 선택하신 날짜의 **CSV 데이터와 LOG 파일 내용 전문**을 클라이언트로 동시 직송 전송 (`EVT_FILE_DATA`).

### 다. 클라이언트 GUI [📥 데이터 다운로드] 팝업 센터 구축 (`shinseon_client.pyw`)
- 버튼 텍스트 변경: 기존 `[📥 CSV 데이터 다운로드]` ➔ **`[📥 데이터 다운로드]`**
- 버튼 클릭 시 **`[📂 날짜별 데이터 & 로그 다운로드 센터]`** 모달 대화상자(QDialog) 팝업:
  - 📅 **날짜 선택 리스트**: 서버에 저장된 날짜 목록 중 원하시는 일자 클릭 선택.
  - 🔘 **다운로드 항목 선택**: `[x] CSV 오더플로우 데이터` / `[x] 트레이딩 상세 로그` (기본값 둘 다 체크).
  - 📥 **`[📥 선택 파일 내 PC 저장]`**: 클릭 시 로컬 폴더로 저장 및 완료 후 저장 폴더 자동 열기!
