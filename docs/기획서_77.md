- **폐하의 지적:**

- **소신의 팩트 분석 (100% 적출):**

  - 이 상태에서 바이낸스 롱/숏 청산 타점 신호가 발생하자, 서버가 "자동 봇 시작 버튼이 눌리지 않은 상태"로 판정하고 진입을 기각시킨 팩트가 적출되었습니다.

## 2. 세부 개조 내역

### 가. WSS 접속 시 자동 봇 시작 (`CMD_START_BOT`) 자동 발동 (`auto_start = True`)
- 대시보드를 켜서 AWS 서버와 연결되는 즉시 **`CMD_START_BOT` 명령을 서버로 자동 송신**하도록 수술합니다.
- `btn_start` 버튼 텍스트를 **`⏸ 자동 봇 정지` (녹색 테마 `#2E6B4E`)**로 즉시 자동 전환합니다.
- 이제 대시보드를 켜신 후 버튼 누르는 것을 잊으시더라도 **100% 즉시 실전 저격 감시가 가동되어 신호 기각 없이 무조건 즉각 진입**됩니다!

### 나. 진입 기각 안내 문구 가독성 쇄신 (`shinseon_server.py`)
- 기존: `⚠️ [진입 기각] 이미 포지션이 가동 중이거나 자동 저격 감시가 비활성화 상태입니다. (is_active: False, is_snipe: False)`
- 쇄신: `⚠️ [진입 기각] 자동 봇 감시가 정지 상태입니다. (우측 [▶ 자동 봇 시작] 버튼을 누르면 실시간 진입 가동)`
