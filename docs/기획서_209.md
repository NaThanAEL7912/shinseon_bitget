# 기획서 209: 지수가중 추세 기울기(EMA Slope 15s Half-Life) 최첨단 0.5초 반응 엔진 구축

## 📌 1. 개요 및 수학적 모델링
- **현상 (기존 단순 선형회귀의 2~4초 지연 현상):**
  - **폐하의 어명 지침:** *"모델 4로 가자 !!"*
  - 기존 단순 선형회귀 기울기는 과거 60초 전 데이터와 현재 시세 데이터에 동일한 가중치(1.0)를 부여하여, 급반전 국면에서 추세선 방향 전환에 약 2~4초의 지연(Lag)이 발생하였습니다.
- **목적 (지수가중 EMA Slope 15s Half-Life 모델 적용):**
  - 최근 시세 데이터일수록 높은 가중치($w_i = e^{-\lambda (t_N - t_i)}$)를 부여하는 **지수가중 선형회귀(Exponentially Weighted Linear Regression)** 모델을 적용하여, **지연시간을 0.5초 이하로 대폭 줄이고 1분 추세를 100% 반영하는 최고 존엄 알고리즘을 완치**합니다.

## 📐 2. 수학적 수식 명세 (`shinseon_server.py`)

### 2.1. 반감기 15초 지수가중치 계산 수식
- 반감기 $h = 15.0\text{초} \Rightarrow \lambda = \frac{\ln(2)}{15.0} \approx 0.04621$
- 각 샘플 $i$의 시간차 $\Delta t_i = t_N - t_i$에 대해:
  $$w_i = \exp(-\lambda \cdot (t_N - t_i))$$
  - 방금 찍힌 현재 시세 ($t_N$): 가중치 $w_N = 1.0$ (100% 반영)
  - 15초 전 시세 ($t_N - 15$): 가중치 $w = 0.5$ (50% 반영)
  - 60초 전 시세 ($t_N - 60$): 가중치 $w \approx 0.06$ (6% 반영, 노이즈 여과)

### 2.2. 지수가중 가중평균 및 기울기 수식 ($\text{EMA Slope}$)
$$\bar{t}_w = \frac{\sum w_i t_i}{\sum w_i}, \quad \bar{P}_w = \frac{\sum w_i P_i}{\sum w_i}$$
$$\text{EMA Slope} = \frac{\sum w_i (t_i - \bar{t}_w)(P_i - \bar{P}_w)}{\sum w_i (t_i - \bar{t}_w)^2}$$
