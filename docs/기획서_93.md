## 2. 세부 수술 내역 (클라이언트 텔레그램 코드 완전 삭제 & 서버 독점 구축)

### 가. 클라이언트 대시보드 (`shinseon_client.pyw`) 텔레그램 이중 코드 완전 삭제
- `shinseon_client.pyw` 내부의 `send_telegram_notification` 및 중복 텔레그램 발송 코드를 **100% 완전 삭제**합니다.
- 대시보드 설정창의 `Bot Token`, `Chat ID` 입력 필드만 유지하여, `CMD_UPDATE_CONFIG`를 통해 서버로 설정값을 전송합니다.

### 나. AWS 서버 (`shinseon_server.py`) 텔레그램 전단(全權) 독점 모듈 탑재
1. **텔레그램 알림 직송 비동기 엔진:**
   - 🎯 **[진입 알림]**: 방향(LONG/SHORT), 비중, 수량(BTC), 진입 사유, 비트겟 잔고
   - ✅ **[체결 알림]**: 비트겟 체결가, 체결 수량, 소모 증거금
   - 🎯 **[청산/스탑 알림]**: 청산 사유(익절 가드레일/손절 스탑), 최종 ROE%, PnL%, 쿨타임(15s/300s/900s) 개시
   - ⚙️ **[설정 변경 알림]**: 파라미터 적용 시 변경된 설정값 텔레그램 보고
2. **텔레그램 양방향 원격 제어 비동기 폴링 리스너:**
   - 🟢 `시작` (/start) ➔ 봇 저격 감시 즉시 가동 (`bot_state = "RUNNING"`)
   - 🛑 `정지` (/stop) ➔ 봇 저격 감시 일시 정지 (`bot_state = "STOPPED"`)
   - 📊 `상태` (/status) ➔ 현재 시세, 비트겟 잔고($33.16), 포지션 보유 상태, ROE%, PnL%, 쿨타임 보고
   - 🚨 `청산` (/close, 비상탈출) ➔ 비트겟 포지션 100% 시장가 즉시 전량 청산 집행 (`execute_emergency`)
