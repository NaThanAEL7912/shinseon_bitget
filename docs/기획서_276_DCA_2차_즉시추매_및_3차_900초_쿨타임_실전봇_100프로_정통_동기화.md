# 기획서 276: DCA 2차 즉시 추매 및 3차 900초 쿨타임 실전 봇 100% 정통 동기화

## 1. 개요 및 배경
- 폐하의 지엄하신 어명: "1차 진입 후 -0.3% 하락 및 동일 신호 시 즉시 2차 추매가 나가도록, 실전 봇과 완벽히 동일하게 다시 교정하라."
- 실전 봇(`core_logic.py`) 대헌법 검증:
  1. **1차 ➔ 2차 추매**: 1차 진입 후 쿨타임 대기 없이, **가격이 -0.30% 이하로 하락하고 동일 방향 신호 발생 시 즉시 2차 추매 체결**. (체결 즉시 `last_split_entry_time = cts` 갱신)
  2. **2차 ➔ 3차 추매**: 2차 체결 후 **900초(15분) 쿨타임이 경과한 후**에만 3차 추매 허용.

---

## 2. 세부 개발 계획

### 1) 🎯 `backtest_engine.py` DCA 로직 실전 봇 1:1 완벽 원상 복원 및 정밀화
- **1차 진입 시**: `last_split_entry_time = 0.0`으로 초기화하여 2차 추매가 쿨타임에 막히지 않도록 조치.
- **2차 추매(DCA) 판정**:
  - `pnl1 <= t_dca_drop and sig_dir == direction` 충족 시 즉시 2차 추매 체결.
  - 체결 즉시 `last_split_entry_time = cts`로 타임스탬프 기록.
- **3차 추매(DCA) 판정**:
  - `pnl1 <= t_dca_drop_3 and sig_dir == direction and (cts - last_split_entry_time >= t_dca_limit)`
  - 2차 체결 후 900초(15분) 쿨타임이 온전히 지난 경우에만 3차 추매 허용.
