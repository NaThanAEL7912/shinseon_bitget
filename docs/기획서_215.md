# 기획서 215: 신호 없음(direction = None) 시 반대 청산 오발조 완치 버그픽스 (V6.13)

## 📌 1. 개요 및 팩트 분석
- **현상:**  
  07:09:22 KST에 보유 중이던 `SHORT` 포지션이 텔레그램 알림 `(보유: SHORT / 신호: None)`과 함께 반대 청산되었습니다.  
  CSV 장부 확인 결과 07:09:23 시점의 신호는 `LONG`이 아니라 **`NONE`**이었습니다.
- **원인:**  
  `shinseon_server.py` L2430의 조건문 `if direction != self.entry_direction:` 에서 `direction`이 `None`(신호 없음)일 때 `None != "SHORT"` 조건이 `True`로 평가되는 중대한 로직 허점이 존재했습니다.  
  신호가 안 터진 일반 틱(`direction = None`) 상황을 반대 신호가 발생한 것으로 잘못 오인하여 포지션을 억울하게 시장가 청산(손절/익절 오발조)했던 팩트가 확인되었습니다.
- **조치:**  
  반대 시그널 감지 조건문을 **`if direction and direction != self.entry_direction:`** (또는 `direction in ["LONG", "SHORT"]`)으로 엄격히 변경하여, 오직 명확한 `LONG` 또는 `SHORT` 반대 신호가 실재할 때만 청산/스위칭이 발동하도록 완벽 완치합니다.
