# 기획서 268: 백테스터 설정값 원클릭 즉시 저장 및 시동 시 최신 설정 100% 자동 복원 체계 구축

## 1. 개요 및 배경
- 폐하의 엄중하신 지적: "설정값을 바꿨는데 하나도 저장이 안 되고 원래 값으로 되돌아간다."
- 결함 원인 분석:
  1. `on_save_config`가 `shinseon_backtest_config.json`에 저장했으나, 앱을 다시 켤 때(`load_config_defaults`)는 여전히 옛날 `shinseon_config.json`만 읽어와서 저장한 값이 리셋되었음.
  2. 저장 시마다 매번 팝업창(QFileDialog)이 떠서 원클릭 저장이 되지 않고 혼선을 초래함.

---

## 2. 세부 개발 계획

### 1) 💾 [설정 저장] 원클릭 즉시 저장 시스템 구축
- [💾 설정 저장] 클릭 시:
  - 파일 선택창 없이 **`shinseon_backtest_config.json`에 1초 만에 원클릭 즉시 저장**.
  - 동시에 실전 `shinseon_config.json`에도 1~4번 탭의 모든 수정 데이터(세션 임계값, 트레이딩 비중, 가드레일, 자금, 수수료율)를 1:1로 정확히 동기화 덮어쓰기.
  - "현재 설정이 안전하게 저장되었습니다!" 알림 출력.

### 2) 🚀 시동 시 최신 저장 설정 100% 우선 복원 (`load_config_defaults`)
- 백테스터를 켤 때:
  1. 1순위: 폐하께서 저장하신 **`shinseon_backtest_config.json`** 이 존재하면 이를 최우선으로 읽어 화면의 모든 위젯(1~4번 탭, 날짜, 불타기, 보존가드, 수수료, 자금 등)을 100% 복원.
  2. 2순위: 파일이 없을 경우 `shinseon_config.json`으로 백업 로드.
- 결과: **폐하께서 변경하신 아시아 400,000 / 유럽 600,000 / 미국 800,000 및 모든 값들이 앱을 재시작해도 1원의 오차도 없이 영구 유지**됨!
