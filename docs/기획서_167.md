# ShinSeon Bitget 기획서_167 (비트겟 진입 주문 격리(Isolated) 모드 100% 완전 강제 적용)

## 📌 1. 전수 조사 및 원인 팩트 분석 (Cross 교차 진입의 원인)
폐하의 어명에 따라 `shinseon_server.py` 및 `core_logic.py` 전체 코드를 샅샅이 다시 전수 조사하였습니다! 
테스트 시 포지션이 **격리(Isolated)**가 아닌 **교차(Cross)**로 열린 원인은 총 3가지 포인트에서 마진 모드 선언이 누락되었기 때문입니다.

1. **`shinseon_server.py` 진입 주문 파라미터 누락:** 
   - `create_order` 호출 시 `params={'tradeSide': 'open'}`만 전달되고, `"marginMode": "isolated"` 및 `"marginCoin": "USDT"` 파라미터가 빠져 있어 거래소 기본값인 '교차'로 주문이 실행됨.
2. **진입 직전 `set_margin_mode` 선언 누락:** 
   - 레버리지 설정(`set_leverage`)만 호출되고, 계좌 마진 모드를 격리로 변경하는 `set_margin_mode('isolated', symbol)` API 호출이 누락됨.
3. **`core_logic.py` 보조 주문부 파라미터 누락:** 
   - 서버 데몬 외 보조 로직 내의 `create_order` 호출부에도 `marginMode` 파라미터가 누락되어 있었음.

## 🛠️ 2. 정공법 수정 상세 내역

### 2.1. `shinseon_server.py` 수정
* 진입 주문 직전 거래소 마진 모드를 격리로 100% 세팅하는 `set_margin_mode('isolated', symbol)` 사전 호출 코드 추가.
* `create_order` 패킷 파라미터(params)에 `"marginMode": "isolated"`, `"marginCoin": "USDT"` 명시적 주입:
  ```python
  # 1. 마진 모드 사전 강제 설정 (Isolated)
  try:
      await exchange.set_margin_mode('isolated', symbol, params={'marginCoin': 'USDT'})
  except Exception:
      pass

  # 2. 레버리지 설정 및 진입 발주
  await exchange.set_leverage(int(round(lev)), symbol)
  order = await exchange.create_order(symbol, 'market', ccxt_side, amount, params={
      'tradeSide': 'open',
      'marginMode': 'isolated',
      'marginCoin': 'USDT'
  })
  ```

### 2.2. `core_logic.py` 수정
* 보조 주문 함수 내 `create_order` 진입 및 청산 호출부 전체에도 동일하게 `marginMode: 'isolated'` 파라미터 철저 주입.
