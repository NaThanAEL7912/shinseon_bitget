## 1. 수술 목적 (Objectives)
- 복잡한 오더플로우 전문 용어(-OI, 숏커버링, 델타 등)를 전면 배제하고, 폐하께서 0.1초 만에 한눈에 보실 수 있도록 **"지금은 롱 유리 / 지금은 숏 유리 / 지금은 관망"** 형태의 세상에서 가장 쉽고 직관적인 UI로 전면 간소화 개편함.

---

## 2. 세부 UI 표기 완료 내역 (Ultra-Simple Design)

### 2.1 현금 대기 중 (포지션 없을 때)

`
• [ 🟢 지금은 롱(LONG)이 유리 ↗ ] (초록색 배경) ➔ 매수 타점
• [ 🔴 지금은 숏(SHORT)이 유리 ↘ ] (빨간색 배경) ➔ 매도 타점
• [ ⚪ 지금은 관망/대기 ⏸ ] (회색 배경) ➔ 휩쏘/소강상태 휴식
`

### 2.2 포지션 보유 중 (포지션 가동 중)

`
• [ 🛡️ 롱(LONG) 보유 중 | 수익 순항 중 ↗ ] (초록색)
• [ 🛡️ 롱(LONG) 보유 중 | ⚠️ 시세 꺾임 주의 ↘ ] (주황색)
• [ 🛡️ 숏(SHORT) 보유 중 | 수익 순항 중 ↘ ] (빨간색)
• [ 🛡️ 숏(SHORT) 보유 중 | ⚠️ 반등 턴 주의 ↗ ] (주황색)
`
