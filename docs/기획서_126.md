# ShinSeon Bitget 기획서_126 (일별 실적 로그 파일 저장소 검증 및 팝업 표 실시간 동기화 완공)

## 📌 개요
폐하의 지시에 따라 **트레이딩 실적 데이터를 일별 파일(`logs/trade_stats_YYYY-MM-DD.json`)로 분리 영구 보관**하고, 비트겟 실제 거래소 체결 이력(`fetch_my_trades`)을 스캔하여 **누락된 과거 거래 실적을 당일/일별 로그 파일에 100% 자동 복원**하며, **누적 상세 보고서 팝업 표에 100% 실시간 갱신**하는 시스템을 완공합니다.

---

## 🔍 [일별 실적 로그 파일 저장 & 팝업 동기화 매커니즘]

### 1. 📂 일별 실적 로그 파일 저장 구조 (`logs/trade_stats_YYYY-MM-DD.json`)
- **저장 위치:** 서버 `/home/ubuntu/logs/trade_stats_YYYY-MM-DD.json`
- **저장 항목:**
  - **일별 요약 (`daily_records`):** 날짜(KST), 총 거래 수, 승, 패, 승률(%), 익절 총액($), 손절 총액($), 당일 순손익($), 평균 ROE(%)
  - **개별 거래 세부 리스트 (`trades_detail`):** 체결 시각, 방향(LONG/SHORT), 수량(BTC), 진입가($), 청산가($), 수익률(ROE%), 손익금($), 청산 사유

### 2. 🔄 비트겟 거래소 체결 내역 서버 자동 복원 엔진 (`sync_past_bitget_trades`)
- 서버 구동 시 및 `CMD_REQ_STATS_DETAIL` 수신 시 비트겟 최근 체결 내역(`fetch_my_trades`) 스캔.
- 오늘/과거 일자의 체결 및 청산 짝(Entry & Exit)을 추적하여, 해당 날짜의 일별 통계 로그 파일(`trade_stats_YYYY-MM-DD.json`) 및 요약 파일(`trade_stats_summary.json`)에 **누락 없이 100% 자동 복원 및 생성 보증**.

### 3. 📊 누적 상세 보고서 팝업창 실시간 동기화
- 팝업창 열기 및 `[🔄 실시간 새로고침]` 클릭 시 서버가 일별 통계 로그 파일들을 읽어 `EVT_SYNC_STATS` 응답을 전송.
- 클라이언트 팝업 표 **상단 [일자별 매매 실적 요약]** 및 **하단 [선택 날짜 개별 거래 상세 세부 리스트]**에 데이터 100% 실시간 갱신 출력.
