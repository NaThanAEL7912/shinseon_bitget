  - **PC 대시보드는 오직 [설정값 전송]과 [실시간 체결 화면 표시]만 담당**하며, 
  - **모든 시세 스캔, 지표 계산, 타점 저격, 비트겟 주문 발주, 손익 청산은 100% AWS 릴레이 서버(`shinseon_server.py`)가 24시간 독자 자율 집행**하고 있습니다!

## 2. 서버 독자 자율 메커니즘 팩트 순서 (AWS Server Architecture)

```
[클라이언트 PC (대시보드)]
   │ 1. 설정값 전송 (CMD_UPDATE_CONFIG) -> (PC 꺼져도 서버에 저장됨)
   │ 4. 체결 완료 알림 수신 (EVT_RESPONSE_LOG, EVT_SYNC_POSITION) <- [대시보드 화면 갱신]
   ▼
[일본 AWS 릴레이 서버 (shinseon_server.py)]
   │ 2. 바이낸스/비트겟 WSS 시세 24시간 독자 스캔 & 0.001ms 타점 포착
   │ 3. 비트겟 거래소로 직접 CCXT API 시장가 주문 직송 집행 (create_order)
   ▼
[비트겟 선물 거래소 (Bitget Exchange)]
```

1. **PC 종료 시에도 24시간 지속 저격:**
   - PC 대시보드를 끄거나 인터넷이 끊겨도 AWS 서버가 최신 설정값을 서버 메모리에 간직하고 있으므로 24시간 단 0.001초의 쉼도 없이 스스로 주문 및 청산을 완료합니다.
2. **초저지연(Latency) 보장:**
   - PC ➔ 서버 ➔ 거래소 루프가 아니라, **AWS 서버 ➔ 비트겟 거래소(핑 1.9ms)** 직송이므로 세계 최고 수준의 속도로 체결됩니다.
