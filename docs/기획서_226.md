## 🛠️ 2. 작업 상세 내역

### 1. `shinseon_server.py` L2420 CSV 로깅 및 L2470 4대 매트릭스 판정 개편
- **0단계 듀얼 임계치 검사:**
  - 기존: `abs(oi_delta_1m) >= target_oi`
  - 수정: **`oi_delta_1m > 0 and oi_delta_1m >= target_oi`** (`+OI` 전용 절대 락다운)
- **신호 판정 매트릭스 (순수 +OI 2대 정통 돌파로 단일화):**
  - 🟢 **`LONG` (Case C)**: `price_slope_1m > 0 and oi_delta_1m >= target_oi and short_liq_usd >= long_liq_usd` (세력 롱 매집 + 숏청산 돌파)
  - 🔴 **`SHORT` (Case D)**: `price_slope_1m < 0 and oi_delta_1m >= target_oi and long_liq_usd >= short_liq_usd` (세력 숏 매집 + 롱청산 돌파)
  - ⚪ **`NONE` (기각)**: `oi_delta_1m <= 0` (-OI) 이거나 임계치 미달 시 **100% NONE 안전 기각 (Case A, Case B 전면 폐지)**

### 2. 포지션 보유 중 반대 청산 & 스위칭 검증 (L2509, L2600)
- 포지션 보유 중 반대 방향 청산은 **오직 세력의 신규 자금이 실린 반대 `+OI` 신호(Case C / Case D) 수신 시에만 스위칭 청산 집행!**
- 단순 개미 청산 노이즈(`-OI`)는 100% 무시하여 롱/숏 포지션을 뺏기지 않고 2시간 대추세 완주.
