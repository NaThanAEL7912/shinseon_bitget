## 🛡️ 2. 0단계: 필수 듀얼 임계치 검사 (순수 +OI 절대 락다운)

신규 저격 진입 및 포지션 보유 중 반대 스위칭 청산 감시는 아래 2가지 조건이 **100% 동시에 충족(AND 조건)**되었을 때에만 기어가 가동됩니다:

1. **`1분 청산액 >= target_liq`** (세션별 기본: $500,000 ~ $650,000 이상)
2. **`1분 OI속도 > 0 (양수) AND 1분 OI속도 >= target_oi`** (세션별 기본: +0.12% ~ +0.28% 이상)

> ⚠️ **[V6.25 헌법 혁신]:**  
> 미결제약정이 감소하는 **`-OI` (음수) 신호는 단순 개미 청산 및 휩쏘 잔파도로 판정하여 100% 영구 폐지(`NONE` 기각)**되었습니다.  
> 오직 세력의 신규 자금이 쏟아져 들어오는 **순수 `+OI` (양수)** 상태에서만 타점이 개방됩니다!

## 🏆 4. 2단계: 1차 / 2차 듀얼 계단식 분할 익절 & 가드레일 엔진 (V6.39)

### ① 1차 분할 익절 (+0.40% 또는 +1.50% 도달 시)
- 보유 수량의 **`1차 분할 익절 비율 (50.0%)`을 시장가로 즉시 익절 청산**하여 확정 수익 확보!
- 남은 50% 수량의 손절선을 **`본전/버퍼 가드 (0.00% ~ +0.10%)`로 자동 상향 배치**하여 완벽한 무위험(Zero-Risk) 상태로 전환!

### ② 2차 최종 익절 (+0.60% 또는 +1.70% 도달 시)
- 남아있는 **`2차 분할 익절 비율 (잔여 50.0%)`을 전량 최종 시장가 익절 청산**하여 2단계 대박 익절 완주!

### ③ 포지션 보유 중 반대 청산 및 초고속 쿨타임
1. **진입 직후 60초 안전 락다운:** 진입 후 60초간의 잔파도 페이크 청산을 완벽 차단.
2. **반대 신호 청산:** 오직 반대 세력의 진짜 `+OI` 신호 발생 시에만 스위칭 청산 집행.
3. **초고속 자금 회전 쿨타임:** **익절 쿨타임 `10초` / 손절 쿨타임 `30초`**로 빠른 다음 파도 탑승!

## ⚡ 6. CSV 레코더 12대 영문 표준 장부 명세

`Timestamp(KST),BTC_Price($),1m_Rolling_Liq($),1m_Long_Liq($),1m_Short_Liq($),Liq_Threshold($),1m_OI_Speed(%),OI_Speed_Threshold(%),1m_Price_Delta($),1m_Price_Slope,Signal,Bot_State`

1. **`Timestamp(KST)`**: `="YYYY-MM-DD HH:MM:SS"` (엑셀 오픈 즉시 초단위 포맷)
2. **`BTC_Price($)`**: 바이낸스 선물 실시간 미드 시세
3. **`1m_Rolling_Liq($)`**: 최근 60초간 바이낸스 청산 누적 합산액 (USD)
4. **`1m_Long_Liq($)`**: 최근 60초간 바이낸스 롱 청산액 (USD)
5. **`1m_Short_Liq($)`**: 최근 60초간 바이낸스 숏 청산액 (USD)
6. **`Liq_Threshold($)`**: 세션별 청산 임계치 ($500,000 ~ $650,000)
7. **`1m_OI_Speed(%)`**: 최근 60초간 미결제약정(OI) 변화율 (%)
8. **`OI_Speed_Threshold(%)`**: 세션별 OI 속도 임계치 (0.12% ~ 0.28%)
9. **`1m_Price_Delta($)`**: 최근 60초 시세 변동폭 ($)
10. **`1m_Price_Slope`**: 최근 60초 지수가중 선형회귀 추세 기울기 (EMA Slope, 15s Half-life)
11. **`Signal`**: `LONG`, `SHORT`, `NONE`
12. **`Bot_State`**: `RUNNING`, `PAUSED`

## 🏛️ 7. 100% 파이썬 실전 구현 원본 소스코드 (V6.39)

```python
# [0단계]: 필수 듀얼 임계치 검사 (청산액 >= target_liq AND OI속도 양수(+) >= target_oi)
if rolling_1m_liq_usd >= target_liq and oi_delta_1m > 0 and oi_delta_1m >= target_oi:
    
    # [Case C]: EMA추세 상승(>0), OI 증가(>0), 숏 청산 돌파(short_liq >= long_liq) ➡️ 🟢 "LONG" 추세 탑승!
    if price_slope_1m > 0 and short_liq_usd >= long_liq_usd:
        direction = "LONG"
        
    # [Case D]: EMA추세 하락(<0), OI 증가(>0), 롱 청산 돌파(long_liq >= short_liq) ➡️ 🔴 "SHORT" 추세 탑승!
    elif price_slope_1m < 0 and long_liq_usd >= short_liq_usd:
        direction = "SHORT"
        
    else:
        direction = None      # 휩쏘/불일치 시 100% NONE 기각!
else:
    direction = None          # 임계치 미달 또는 -OI(음수) 시 100% NONE 기각!
```
