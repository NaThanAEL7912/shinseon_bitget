# [기획서 394] 신선 도쿄 실전 서버 바이낸스 선물 웹소켓(fstream) 직통 교정 및 현물 우회 완전 박멸 기획서

## 1. 개요 및 배경

- **현상 분석**:
  - 현재 `shinseon_server.py`의 라인 1070에 `uri = "wss://stream.binance.com/stream?streams=btcusdt@ticker/btcusdt@aggTrade"`로 바이낸스 **현물(Spot) 웹소켓**이 연결되어 있음.
  - 라인 1666~1668에서 현물 가격(`spot_price`)을 수신한 뒤, 프리미엄 Basis를 더해서 선물 가격으로 변환(둔갑)하여 사용하고 있었음.
- **원인 추적**:
  - 과거 한국 로컬 PC에서 봇을 구동할 당시, 한국 정부/방통위(KCSC)가 바이낸스 선물 도메인(`fstream.binance.com`)을 차단하여 패킷 Drop이 발생했기 때문에, 임시 우회책으로 차단되지 않던 현물 웹소켓(`stream.binance.com`)을 사용했던 과거의 잔재임.
- **현재 상황 및 정공법 원칙**:
  - 현재 신선 실전 서버는 **일본 도쿄 AWS EC2 (`13.192.187.244`)**에서 24시간 가동 중임.
  - 일본 도쿄 서버는 한국의 방통위 차단이 전혀 없으므로, 바이낸스 진짜 100% 선물 웹소켓(`fstream.binance.com`)에 0ms 핑으로 다이렉트 직결할 수 있음.
  - 따라서 과거의 현물 우회/프리미엄 둔갑 로직을 완전히 걷어내고, **"100% 진짜 바이낸스 선물 실시간 웹소켓 (fstream)"**으로 교정하여 데이터 무결성을 달성함.

---

## 2. 작업 명세

### ① `shinseon_server.py` 웹소켓 URI 교정
- **수정 위치**: 라인 1070 부근
- **기존 (현물망 우회)**:
  ```python
  uri = "wss://stream.binance.com/stream?streams=btcusdt@ticker/btcusdt@aggTrade"
  ```
- **변경 (100% 정통 선물망 직통)**:
  ```python
  uri = "wss://fstream.binance.com/stream?streams=btcusdt@ticker/btcusdt@aggTrade"
  ```

### ② 선물 시세 다이렉트 파싱 정문화
- 현물 가격 + Basis 더하기 대신, 바이낸스 선물의 실제 실시간 종가/시가를 다이렉트로 `self.current_price`에 1:1 매핑.

### ③ 시스템 버전 삼위일체 V7.82 동기화
- `shinseon_server.py`: `self.CURRENT_VERSION = "V7.82"`
- `shinseon_client.pyw`: `self.CURRENT_VERSION = "V7.82"`
- `shinseon_config.json`: `"CURRENT_VERSION": "V7.82"`
- `docs/shinseon_whitepaper.html`: 마스터 백서 V7.82 갱신

### ④ 프로젝트 이력 대장 등재
- `docs/프로젝트_버전_관리.md`에 V7.82 이력 추가

## 3. 검증 및 배포 계획
1. `python -m py_compile shinseon_server.py` 구문 무결성 검증
2. `deploy.py V7.82` 실행하여 AWS 도쿄 실전 서버(`13.192.187.244`)에 SFTP 원격 전송 및 데몬 무중단 재기동
3. AWS 서버 실시간 로그(`shinseon_stdout.log`)에서 `fstream.binance.com` 선물 웹소켓 정상 수신 확인
