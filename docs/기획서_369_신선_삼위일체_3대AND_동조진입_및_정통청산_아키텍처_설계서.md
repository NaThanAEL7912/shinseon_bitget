## 2. 신선 삼위일체 3대 AND 진입 절대 헌법 (Entry Architecture)

### 2.1. 0단계 : 필수 거시 임계치 통과 검사
진입 신호가 격발되기 위해선 아래 2대 세력 유입 기준을 반드시 통과해야 함:
1. `1m_Rolling_Liq >= Liq_Threshold` (1분 롤링 청산액이 세션 임계치 이상 터졌는가?)
2. `abs(1m_OI_Speed) >= OI_Speed_Threshold` (1분 미결제약정 변동 속도가 임계치 이상인가?)

---

### 2.2. 🟢 찐 롱(LONG) 진입 절대 조건
0단계를 통과하고, **아래 3대 시공간 가격 지표가 동시에 이상(>= 0, 상방 동조)**이어야 함:
1. **단기 5초 변동** : `5s_Price_Delta >= 0` (5초 가격이 오르고 있거나 일시 멈춤)
2. **중기 1분 변동** : `1m_Price_Delta >= 0` (1분 가격이 양수 상승 중)
3. **1분 회귀 기울기** : `1m_Price_Slope >= 0` (선형회귀 추세 각도가 우상향 각도)
4. **보합 필터** : `not (5s_Delta == 0 and 1m_Delta == 0 and Slope == 0)` (3개 모두 0인 완전 보합은 제외)
5. **OI 방향 검증** : 
   - `1m_OI_Speed > 0` : 세력의 양수 자금 유입 대세 불장 돌파 롱!
   - `1m_OI_Speed < 0` : 개미 털기 V자 바닥 반등 저격 롱 (단, 가격 3대 지표가 반드시 양수로 턴했을 때만 진입!).

---

### 2.3. 🔴 찐 숏(SHORT) 진입 절대 조건
0단계를 통과하고, **아래 3대 시공간 가격 지표가 동시에 이하(<= 0, 하방 동조)**이어야 함:
1. **단기 5초 변동** : `5s_Price_Delta <= 0` (5초 가격이 내리고 있거나 일시 멈춤)
2. **중기 1분 변동** : `1m_Price_Delta <= 0` (1분 가격이 음수 하락 중)
3. **1분 회귀 기울기** : `1m_Price_Slope <= 0` (선형회귀 추세 각도가 우하향 폭포수 각도)
4. **보합 필터** : `not (5s_Delta == 0 and 1m_Delta == 0 and Slope == 0)` (3개 모두 0인 완전 보합은 제외)
5. **OI 방향 검증** :
   - `1m_OI_Speed > 0` : 세력의 양수 자금 유입 대세 폭락 추세 숏!
   - `1m_OI_Speed < 0` : 숏커버 소진 천장 덤핑 저격 숏 (단, 가격 3대 지표가 반드시 음수로 꺾였을 때만 진입!).

---

### 2.4. ⚪ 100% 무조건 기각 헌법 (Disqualification ➔ NONE)
- **숏 후보인데 델타/기울기가 양수(+)인 경우** (예: 28일 18:05:58) ➔ **100% 무시 (`NONE`)!**
- **롱 후보인데 델타/기울기가 음수(-)인 경우** (예: 29일 01:09:42) ➔ **100% 무시 (`NONE`)!**
- **3대 지표 중 단 1개라도 방향이 엇갈리거나 모호한 경우** ➔ **100% 무시 (`NONE`)!**

## 3. 포지션 홀딩 헌법 (Holding Architecture)

1. **롱 포지션 보유 중** :
   - 추가 `LONG` 신호 지속 발생 시 ➔ **동일 신호 패스 (롱 포지션 100% 유지 홀딩)**
   - `NONE` (관망) 발생 시 ➔ **노이즈 패스 (롱 포지션 100% 유지 홀딩)**
2. **숏 포지션 보유 중** :
   - 추가 `SHORT` 신호 지속 발생 시 ➔ **동일 신호 패스 (숏 포지션 100% 유지 홀딩)**
   - `NONE` (관망) 발생 시 ➔ **노이즈 패스 (숏 포지션 100% 유지 홀딩)**

## 4. 정통 청산 및 재진입 헌법 (Exit & Re-entry Architecture)

### 4.1. 🛑 정통 청산 (Close to Flat)
1. **롱 포지션 청산 조건** :
   - 롱 포지션 보유 중, 엄격 검증을 통과한 **유효한 🔴 `SHORT` 신호가 최초 발생**했을 때:
   - 👉 **즉시 롱 포지션 100% 전량 시장가 청산 (Close All)!**
   - 👉 **스위칭(즉시 숏 진입)하지 않고, 현금 100% 무포지션(Flat) 관망 상태로 복귀!**
2. **숏 포지션 청산 조건** :
   - 숏 포지션 보유 중, 엄격 검증을 통과한 **유효한 🟢 `LONG` 신호가 최초 발생**했을 때:
   - 👉 **즉시 숏 포지션 100% 전량 시장가 청산 (Close All)!**
   - 👉 **스위칭(즉시 롱 진입)하지 않고, 현금 100% 무포지션(Flat) 관망 상태로 복귀!**

### 4.2. 🛡️ 거래소 안전 가드레일 자동 청산
- 비트겟 거래소에 상시 등록된 2단 분할 손절선 (SL 50% / 50%) 도달 시 자동 분할 방어.
- 1차 목표가(TP1) / 2차 목표가(TP2) 도달 시 지정가 분할 익절.

### 4.3. 🎯 신규 재진입 (Re-entry)
- 무포지션(Flat) 상태에서, 시장이 충분히 호흡을 가다듬고 **새로운 0단계 임계치 및 3대 AND 동조 신호가 확정 격발될 때** 신규 포지션 오픈!
