# [기획서_354] 실시간 목표가 가격알림 텔레그램 전송 엔진 정밀 복원 기획서

## 1. 개요 및 원인 분석
- **현상**: GUI 대시보드 우측 하단 [BITGET 실시간 목표가 가격 알림]에 목표가(,600 등)를 등록하고 돌파되어도 텔레그램 메시지가 오지 않음.
- **원인 분석**: shinseon_client.pyw의 send_telegram_notification(self, text) 함수가 pass로 비활성화되어 있어, 가격 알림 등록 및 돌파 이벤트 발생 시 텔레그램 API 호출이 차단되어 있었음.
- **방금 전송 검증**: 텔레그램 봇 토큰 및 챗ID(나엘로 폐하)는 shinseon_config.json에 완벽히 살아있으며, 테스트 발송(message_id: 1308) 성공 확인.
