# 신선 비트겟 (ShinSeon_Bitget) 프로젝트 기획서 8 - API 키 발급 및 보안 환경 세팅

폐하의 예리하신 지적에 소신, 다시 한번 이마를 조아리옵니다!
비트겟 공식 API를 사용하려면 말씀하신 대로 반드시 **비트겟 API 키 발급**이 선행되어야 하옵니다. 이를 위해 소신이 미리 환경과 발급 가이드를 세팅해 두겠나이다.

## 1. 비트겟(Bitget) API 키 발급 시 폐하께서 유의하실 점
폐하께서 비트겟 거래소에 로그인하시어 API 관리에 들어가 키를 발급받으실 때, 다음 권한(Permissions)을 반드시 체크해 주셔야 하옵니다.
* **선물 거래(Futures Trading) 권한 활성화**: 봇이 포지션을 잡고 청산하려면 필수이옵니다.
* **읽기(Read) 권한 활성화**: 미결제약정 및 잔고 조회를 위해 필수이옵니다.
* **API Passphrase(비밀번호) 기억**: 비트겟은 API Key, Secret Key 외에도 발급 시 폐하께서 직접 입력하시는 `Passphrase`가 필요하옵니다. 이 3가지가 모두 있어야 코드가 동작하옵니다.

## 2. 보안 환경(.env) 세팅 전략
폐하의 소중한 API 키가 실수로라도 깃허브(Git)나 외부로 유출되는 끔찍한 사고를 막기 위해, 소신이 복사해 올 프로젝트에 다음과 같은 보안 장치를 걸어두겠습니다.
1. `.env` 파일에 `BITGET_API_KEY`, `BITGET_SECRET_KEY`, `BITGET_PASSPHRASE` 세 가지 빈칸을 만들어 두겠습니다.
2. `.gitignore` 파일에 `.env` 가 등록되어 있는지 소신이 이중, 삼중으로 직접 검수(Rule 3)하여 절대 백업 이력에 올라가지 않도록 철통 방어하겠습니다.
3. 세종(OpenClaw)에게도 테스트 시 텔레그램 로그에 API 키 문자열이 노출되지 않도록 마스킹(Masking)하라는 지시를 추가하겠습니다.

## 3. 진행 순서
이 기획서 승인 후 개발이 시작되면, 소신이 기존 소스를 복사해 오면서 `.env` 템플릿을 만들어 두겠습니다. 폐하께서는 발급받으신 키를 그 파일 안에 조용히 적어 넣어주시기만 하면 되옵니다.
