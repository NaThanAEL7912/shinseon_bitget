# 기획서 222: 세션별 실시간 대시보드 설정값(손절 -1.3% / 익절 1.50%) 100% 팩트 연동 엔진 완공 (V6.21)

## 📌 1. 개요 및 팩트 분석
- **현상:**  
  폐하의 신선 대시보드 UI 화면 세션 설정:  
  - **최초 손절선:** `-1.3%` (미국 본장 / 주말 미국 본장)
  - **분할 익절 임계값:** `1.50%` (미국 본장)  
  그러나 V6.20 비트겟 선주문 발주 시 세션 동적 객체 참조 방식이 미흡하여 기본 폴백 수치(`±0.30%`)로 계산되어 비트겟 차트에 그려졌던 팩트를 발견하였습니다.

- **조치:**  
  `place_bitget_tpsl_plan_orders` 내부에서 **현재 활성화된 세션의 `current_session_sl` (손절가 예: -1.3%)과 `session_guardrails[session_key]["tp"]` (익절가 예: 1.50%)를 실시간 팩트로 읽어와 계산**하도록 수술 완공.

## 🛠️ 2. 작업 상세 내역
1. **`shinseon_server.py` L1770 세션 연동 로직 개편:**
   - `sl_val = abs(getattr(self, "current_session_sl", -1.3))`
   - `tp_val = float(self.session_guardrails[session_key].get("tp", 1.50))`
   - `initial_sl_pct = sl_val / 100.0`
   - `tp_pct = tp_val / 100.0`
2. **결과:**  
   미국 본장 기준 진입 시 비트겟 차트에 **정확하게 익절 `+1.50%` 및 손절 `-1.3%` 자물쇠 라인이 0.001초 만에 자동 생성**됨!
