# SHINSEON 황금전성기 오더플로우 수익저격 전수백서 (V5.62)

## 📌 1. 개요 및 목적
본 문서는 SHINSEON 비트겟 선물 자동저격 트레이딩 시스템에서 가장 어마어마한 수익을 싹쓸이했던 **V2.55 황금 전성기 오더플로우 저격 알고리즘의 100% 전수 헌법 백서**입니다. 누구나 읽자마자 1초 만에 동작 원리와 조건식을 명확하게 파악할 수 있도록 작성되었습니다.

---

## 🛡️ 2. 0단계: 필수 듀얼 임계치 대전제 (AND 조건)
신규 저격 진입 및 포지션 보유 중 반대 청산 감시는 아래 2가지 조건이 **100% 동시에 넘어섰을 때(AND 조건)에만 기어가 동작**합니다. 하나라도 미달 시 진입/청산을 일절 기각(NONE)하고 휴식합니다.

1. **`1분 청산액 >= target_liq`** (세션별 기본: $500,000 이상)
2. **`abs(1분 OI속도) >= target_oi`** (세션별 기본: 0.18% 이상)

---

## 🎯 3. 1단계: 1분 가격변동(price_delta) ✕ OI속도(oi_delta) 4대 저격 매트릭스

| 경우의 수 | 1분 가격변동 (`price_delta_1m`) | 1분 OI속도 (`oi_delta_1m`) | 저격 깃발 방향 | 시장 세력 메커니즘 팩트 |
|---|---|---|---|---|
| **Case A** | 📉 **`price_delta < 0`** (가격 하락) | 📉 **`oi_delta < 0`** (OI 감소) | 🟢 **`LONG`** | **개미 롱 손절 털기 완료 ➡️ 저점 LONG 매수 저격!** |
| **Case B** | 📈 **`price_delta > 0`** (가격 상승) | 📉 **`oi_delta < 0`** (OI 감소) | 🔴 **`SHORT`** | **개미 숏커버 털기 완료 ➡️ 고점 SHORT 매도 저격!** |
| **Case C** | 📈 **`price_delta > 0`** (가격 상승) | 📈 **`oi_delta > 0`** (OI 증가) | 🟢 **`LONG`** | **세력 신규 자금 유입 ➡️ 상승 추세 LONG 탑승!** |
| **Case D** | 📉 **`price_delta < 0`** (가격 하락) | 📈 **`oi_delta > 0`** (OI 증가) | 🔴 **`SHORT`** | **세력 신규 자금 유입 ➡️ 하강 추세 SHORT 탑승!** |

---

## 🚨 4. 2단계: 실전 집행 및 포지션 보유 중 반대 청산 감시 (사진 2 명세)

### ① 포지션 미보유 시 (신규 진입)
- 위의 4대 매트릭스에서 결정된 깃발(`direction`)대로 **비트겟 거래소 시장가 주문을 쏘고, CSV 장부 파일에도 100% 동일한 문자를 인쇄 기록**합니다.

### ② 포지션 보유 중일 때 (Holding Position)
1. **동일 방향 깃발 수신 시:** 온전히 홀딩 유지 (추세 탑승).
2. **반대 방향 깃발 수신 시:**
   - **`oi_delta_1m < 0` (OI 감소):** 🛡️ **청산 찌꺼기 무시 ➡️ 기존 포지션 철통 홀딩!**
   - **`oi_delta_1m > 0` (OI 증가):** 🚨 **진짜 반대 세력 자금 유입 ➡️ 전량 익절 청산 ➡️ 15초 쿨타임 후 반대 스위칭 승차!**

## 🏛️ 5. 100% 파이썬 실전 구현 원본 소스코드 (V5.62)

```python
# [0단계]: 최근 1분 동안 터진 청산 금액과 OI속도가 우리가 목표한 최소 기준치(임계치)를 넘어섰는지 제일 먼저 검사해요!
if rolling_1m_liq_usd >= target_liq and abs(oi_delta_1m) >= target_oi:
    
    # --------------------------------------------------------------------------
    # 1단계: 1분 가격이 움직인 방향(price_delta_1m)과 사탕/자금 속도(oi_delta_1m)를 합쳐서 깃발(direction) 색깔을 정해요!
    # --------------------------------------------------------------------------
    
    # [Case A]: 가격이 떨어지고(<0) 사탕도 감소하면(<0) 개미가 손절을 다 턴 거니까 저점에서 🟢 "LONG(매수)" 깃발을 들어요!
    if price_delta_1m < 0 and oi_delta_1m < 0:
        direction = "LONG"
        
    # [Case B]: 가격이 올라가고(>0) 사탕이 감소하면(<0) 숏 세력이 손절을 다 턴 거니까 고점에서 🔴 "SHORT(매도)" 깃발을 들어요!
    elif price_delta_1m > 0 and oi_delta_1m < 0:
        direction = "SHORT"
        
    # [Case C]: 가격도 올라가고(>0) 사탕도 펑펑 늘어나면(>0) 세력이 돈을 쏟아붓는 거니까 상승 🟢 "LONG(매수)" 깃발을 들어요!
    elif price_delta_1m > 0 and oi_delta_1m > 0:
        direction = "LONG"
        
    # [Case D]: 가격도 떨어지고(<0) 사탕이 펑펑 늘어나면(>0) 세력이 하방으로 돈을 쏘는 거니까 하강 🔴 "SHORT(매도)" 깃발을 들어요!
    elif price_delta_1m < 0 and oi_delta_1m > 0:
        direction = "SHORT"
        
    # 4가지 경우에 다 안 맞으면 깃발을 들지 않아요! (None)
    else:
        direction = None

    # --------------------------------------------------------------------------
    # 2단계: 손에 포지션 장난감이 있는지 확인해서 주문을 넣거나 반대 청산을 감시해요!
    # --------------------------------------------------------------------------
    
    # [신규 진입]: 지금 손에 들고 있는 포지션 장난감이 없고(not active) 깃발이 정해졌으면 비트겟 주문을 쏘고 CSV에도 똑같이 기록해요!
    if not self.is_position_active and direction:
        await self.execute_entry(direction)
        
    # [보유 중 감시]: 이미 손에 포지션 장난감을 쥐고 있는 상태라면!
    elif self.is_position_active:
        
        # 새로 온 깃발 방향이 내가 들고 있는 포지션 방향과 똑같으면 아무것도 안 하고 신나게 홀딩(pass)해요!
        if direction == self.entry_direction:
            pass
            
        # 새로 온 깃발 방향이 내가 들고 있는 포지션 방향과 반대 색깔일 때 아래를 검사해요!
        elif direction and direction != self.entry_direction:
            
            # 반대 깃발이어도 사탕(OI)이 줄어들고 있으면(<0) 가짜 청산 찌꺼기니까 무시하고 철통 홀딩(pass)해요!
            if oi_delta_1m < 0:
                pass
                
            # 반대 깃발이고 사탕(OI)도 펑펑 늘어나고 있으면(>0) 진짜 세력 자금이 들어온 거니까 전량 익절 청산하고 스위칭해요!
            elif oi_delta_1m > 0:
                await self.execute_exit_and_switch(direction)

# [임계치 미달]: 1분 청산 금액이나 OI속도가 최소 기준치보다 작으면 심심하니까 아무것도 안 하고 푹 쉬어요! (None)
else:
    direction = None
```
