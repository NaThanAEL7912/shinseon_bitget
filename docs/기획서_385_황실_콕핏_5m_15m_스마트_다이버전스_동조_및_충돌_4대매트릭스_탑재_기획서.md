# [기획서 385] 황실 콕핏 5m+15m 스마트 다이버전스 동조 및 충돌 4대 매트릭스 탑재 기획서

---

## 1. 개발 배경 및 목적

- **배경**:
  - 국왕 폐하께서 **"5m과 15m 둘 다 다이버전스가 뜨면 어떻게 뜨냐? 하나는 하락이고 하나는 상승으로 충돌하면 어떻게 뜨냐?"**는 실전 매매의 핵심 엣지케이스를 하사하심.
  - 소신이 제안한 **[ 2중 동조 시 '🔥 강력 다이버전스' & 상충 충돌 시 '⚠️ 본세 vs 단기반등 충돌' 4대 스마트 매트릭스 ]**에 대해 군주께서 **"오케이 굿! 고고"** 어명을 내리심.

- **목적**:
  1. `shinseon_cockpit.pyw`의 다이버전스 뱃지 렌더링 엔진에 **[ 2중 동조 / 상충 충돌 / 단독 발생 스마트 4대 매트릭스 ]**를 완벽 구현.
  2. 5m과 15m이 일치할 때는 200% 신뢰도의 강력 진입 신호를 주고, 서로 충돌할 때는 섣부른 뇌동매매를 막고 관망할 수 있도록 직관적인 경고 뱃지 제공.
  3. 콕핏 버전을 **V1.05**로 순차 상향 및 이력 관리 대장 등재.

## 2. 세부 개발 명세

### ① 스마트 다이버전스 4대 매트릭스 알고리즘

```python
# 1. 2중 하락 동조 (5m BEARISH + 15m BEARISH)
if self.div_5m == "BEARISH" and self.div_15m == "BEARISH":
    self.lbl_hint_badge.setText("🔥 5m+15m 강력 하락 다이버전스! (숏 저격)")
    self.lbl_hint_badge.setStyleSheet("background: qlineargradient(x1:0, y1:0, x2:1, y2:0, stop:0 #800020, stop:1 #C80036); border: 2px solid #FF0055; border-radius: 6px; color: #FFFFFF; font-size: 14px; font-weight: 900; padding: 6px;")

# 2. 2중 상승 동조 (5m BULLISH + 15m BULLISH)
elif self.div_5m == "BULLISH" and self.div_15m == "BULLISH":
    self.lbl_hint_badge.setText("🔥 5m+15m 강력 상승 다이버전스! (롱 저격)")
    self.lbl_hint_badge.setStyleSheet("background: qlineargradient(x1:0, y1:0, x2:1, y2:0, stop:0 #005A2E, stop:1 #00B050); border: 2px solid #00FFCC; border-radius: 6px; color: #FFFFFF; font-size: 14px; font-weight: 900; padding: 6px;")

# 3. 충돌 Case A: 15m 하락(본세) vs 5m 상승(단기반등)
elif self.div_15m == "BEARISH" and self.div_5m == "BULLISH":
    self.lbl_hint_badge.setText("⚠️ 15m 하락본세 vs 5m 단기반등 충돌! (관망)")
    self.lbl_hint_badge.setStyleSheet("background: qlineargradient(x1:0, y1:0, x2:1, y2:0, stop:0 #4A3B00, stop:1 #806000); border: 2px solid #FFD700; border-radius: 6px; color: #FFF8DC; font-size: 13px; font-weight: 900; padding: 6px;")

# 4. 충돌 Case B: 15m 상승(본세) vs 5m 하락(단기눌림)
elif self.div_15m == "BULLISH" and self.div_5m == "BEARISH":
    self.lbl_hint_badge.setText("⚠️ 15m 상승본세 vs 5m 단기눌림 충돌! (관망)")
    self.lbl_hint_badge.setStyleSheet("background: qlineargradient(x1:0, y1:0, x2:1, y2:0, stop:0 #4A3B00, stop:1 #806000); border: 2px solid #FFD700; border-radius: 6px; color: #FFF8DC; font-size: 13px; font-weight: 900; padding: 6px;")

# 5. 단독 발생 (15m 우선 ➔ 5m 순)
elif self.div_15m == "BEARISH":
    self.lbl_hint_badge.setText("🐻 15m 하락 다이버전스 감지! (숏 저격)")
elif self.div_5m == "BEARISH":
    self.lbl_hint_badge.setText("🐻 5m 하락 다이버전스 감지! (숏 저격)")
elif self.div_15m == "BULLISH":
    self.lbl_hint_badge.setText("🐂 15m 상승 다이버전스 감지! (롱 저격)")
elif self.div_5m == "BULLISH":
    self.lbl_hint_badge.setText("🐂 5m 상승 다이버전스 감지! (롱 저격)")
```
