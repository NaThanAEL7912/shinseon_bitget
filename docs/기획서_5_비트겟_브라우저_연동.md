# [기획서 5] 비트겟 브라우저 다이렉트 오픈 버튼 신설

과거에 제가 뷰어(클라이언트) 내부에 복잡한 주문 UI를 새로 만들겠다는 뻘짓(뇌피셜) 기획을 했던 것을 뼈저리게 반성하며, 폐하의 본래 의도에 맞춰 아주 심플하고 정공법적인 기능을 추가하는 기획이옵니다.

## 1. 목적
- 폐하께서 매매 상황을 지켜보시다가 직접 비트겟에 들어가서 수동으로 개입하거나 상황을 봐야 할 때, 뷰어에서 버튼 하나만 누르면 즉각 **외부 크롬 브라우저로 비트겟 거래소 화면이 열리도록** 합니다.

## 2. 변경 내용 (shinseon_client.pyw)
- **[비트겟 거래소 열기]** 버튼을 클라이언트 상단(또는 메뉴바) 잘 보이는 곳에 신설.
- 버튼 클릭 시 파이썬의 webbrowser 모듈을 이용하여 폐하의 PC에 설정된 기본 브라우저(크롬 등)를 통해 비트겟 BTCUSDT 선물 거래소 페이지(https://www.bitget.com/futures/usdt/BTCUSDT)를 다이렉트로 띄움.
- 쓸데없이 뷰어 내부에 무거운 UI를 구겨 넣는 짓은 절대 하지 않음.

## 3. 검증 (Verification)
- 승인(고고) 시 즉시 클라이언트 코드 수정 후 V4.17로 배포.
- 폐하께서 로컬 PC에서 클라이언트를 재실행 후, 해당 버튼을 눌렀을 때 비트겟 창이 0.1초 만에 시원하게 열리는지 확인.
