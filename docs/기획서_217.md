# 기획서 217: 비트겟 체결 복원기 가중 평단가 및 분할체결 병합 완치 (V6.15)

## 📌 1. 개요 및 팩트 분석
- **현상:**  
  비트겟 웹 거래소 화면(1번 캡처)과 신선 GUI 상세 보고서 센터(2번 캡처)의 매매 내역을 비교한 결과 3가지 불일치가 팩트로 포착되었습니다:
  1. **총 거래 건수 불일치:** 웹 거래소는 **6건**인데 보고서 센터는 **7건**으로 표출됨. (01:39:36 매매가 0.0001 BTC + 0.0009 BTC 2개로 분할 쪼개짐)
  2. **진입 평단가 및 손익 오차:** 롱 포지션 진입 평단가가 웹 거래소는 `63,101.1 USDT` (손익 `+$1.08`), 보고서 센터는 `63,197.3 USDT` (손익 `+$0.76`)로 오차 발생.
  3. **최초 진입 시각 오기:** 최초 진입 시각(`01:42:31`) 대신 불타기 체결 시각(`02:22:52`)으로 표시됨.

- **원인:**  
  `shinseon_server.py` 내 `sync_past_bitget_trades_7d()` 체결 복원 로직의 결함:
  1. `last_open_price = p_val` 체결 복원기 로직이 분할 진입(물타기/불타기) 시 이전 진입가를 누적 가중평균하지 않고 마지막 체결가로 단순 덮어써 버렸습니다.
  2. 비트겟 API(`fetch_my_trades`)가 전달하는 부분 체결(Partial Fill: 0.0001 + 0.0009) 미세 패킷을 동일 포지션 1건으로 뭉치지(Merge) 못하고 각각 별개 레코드로 카운트했습니다.

- **조치:**  
  `sync_past_bitget_trades_7d()` 엔진을 전면 개편하여:
  1. **동일 주문/포지션 체결 병합(Merge):** 동일 시점 분할 체결 건을 1개의 완성 거래로 통합.
  2. **가중평균 진입 평단가(`Weighted Avg Entry Price`) 정률 산출:** 수량 ✕ 단가 누적 합산 방식으로 비트겟 웹 거래소 화면과 100% 동일한 평단가/손익/진입시각 계산 복원.
