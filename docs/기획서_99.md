## 2. 세부 개편 및 정격 구현 사양

### 가. 11개 프리미엄 칼럼 CSV 엔진 (`docs/historical_data/orderflow_history_YYYY-MM-DD.csv`)
1. **CSV 정격 헤더 (11개 칼럼)**:
   ```csv
   timestamp,btc_price,liq_1m_total,liq_1m_long,liq_1m_short,liq_threshold,oi_1m_pct,oi_threshold,signal,session,bot_state
   ```
2. **`signal` 발동 조건 (양대 임계치 동시 충족 100% AND 로직)**:
   - **`LONG` 발동 조건**: `liq_1m_total >= liq_threshold` **AND** `oi_1m_pct >= oi_threshold`
   - **`SHORT` 발동 조건**: `liq_1m_total >= liq_threshold` **AND** `oi_1m_pct <= -oi_threshold`
   - **`NONE` (미발동)**: 위 2개 조건 중 1개라도 미달 시 `NONE` 표기.

3. **스마트 듀얼 샘플링 주기 스위칭 수식**:
   - **평시 (Normal State)**: **1분 간격 (60초마다 1행 기록)**
   - **임계치 50% 활성화 (High Activity State)**:
     - `liq_1m_total >= liq_threshold * 0.5` **또는** `|oi_1m_pct| >= oi_threshold * 0.5` 도달 시
     - 즉시 **1초 간격 (1초마다 1행 기록)**으로 자동 스위칭!
