# ShinSeon Bitget 기획서_105

## 📌 개요
1분 오더플로우 저격 시그널(LONG/SHORT) 조건이 100% 충족되었음에도 실전 주문 발주가 미실행되거나 기각되는 모든 사유(쿨타임, 포지션 중복, 슬리피지 캡 초과, API 오류 등)를 명확히 진단하고, 진입 방어벽 전 과정에 상세 정밀 파일 로깅(`logger.warning`)을 추가하여 진입 기각 원인을 100% 팩트로 파악할 수 있도록 고도화합니다.

---

## 🎯 개발 및 진단 항목
- [ ] 1. **시그널 발생 후 실전 미진입 원인 4대 팩트 진단**
  - ① 쿨타임 대기 중 (`cooldown_until_time` 미완료)
  - ② 기존 포지션 보유 중 (`is_position_active == True`)
  - ③ 비트겟 슬리피지 캡 초과 (스프레드 0.30% 이상 순간 벌어짐)
  - ④ 비트겟 API 주문 전송 실패 / API 키 잔고 부족 오류
- [ ] 2. **진입 방어벽 기각 사유 100% 파일 로깅 (`logger.warning`) 보강**
  - 시그널 충족에도 불구하고 진입이 보류/기각될 경우, 기각 사유와 상세 수치를 `shinseon_trade_YYYY-MM-DD.log` 파일에 영구 기록.
- [ ] 3. **구문 검증 및 AWS 서버 배포 (V5.05)**
  - `py_compile` 검증 후 `python deploy.py V5.05` 배포 및 AWS 서버 재시작.
