## 2. 🧩 [풀스택 시스템 아키텍처 (Full-Stack Architecture)]

신선 시스템은 **[백엔드 데이터/발주 엔진 + 프론트엔드 GUI 대시보드 + 24시간 안전 방패 + 백테스팅 시뮬레이터 + 텔레그램 브릿지]**로 구성된 분산형 퀀트 시스템이다.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                [ SHINSEON SYSTEM MAP ]                                 │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. 백엔드 코어 엔진 (Server & Core)                                                    │
│    • shinseon_server.py      : 바이낸스 WS 청산/OI 수집, 오더플로우 4대 헌법 판단, 발주 │
│    • core_logic.py          : 오더플로우 세션별 임계치 판정 및 가드레일 연산 모듈     │
│    • 24시간 비상 국고 방패   : 비트코인 외 타 종목 진입 시 0.1초 즉시 사살 데몬 탑재    │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 2. 프론트엔드 대시보드 (GUI Client)                                                   │
│    • shinseon_client.pyw     : PySide6 + pyqtgraph + qasync 실시간 글래스모피즘 레이더   │
│    • shinseon_backtester.pyw : 21일치 실측 데이터 초고속 RAM 캐싱 백테스터 시뮬레이터  │
│    • shinseon_master_app.pyw : 마스터 통합 컨트롤 대시보드                            │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 3. 자동 배포 및 런처 (Launcher & Config)                                               │
│    • install.bat             : Python 3.12 및 종속 패키지 100% 자동 원클릭 설치기      │
│    • shinseon_Starter.bat    : 크롬 디버깅(9224) 및 신선 마스터 앱 통합 시동기         │
│    • 신선_비트겟_클라이언트.bat : 신선 클라이언트 GUI 단독 시동기                       │
│    • Start_Sejong.bat        : OpenClaw QA 및 텔레그램 네트워크 게이트웨이            │
│    • .env                    : Bitget API Key / Secret / Passphrase (보안 1급)        │
│    • shinseon_config.json    : 세션별 임계치, 배팅 비중, 손절/익절 가드레일 설정 파일    │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 3. ⚙️ [데스크탑 환경 이전 및 셋업 상세 절차]

### 1단계 : 프로젝트 폴더 데스크탑 복제
1. 노트북의 `C:\Working\AntiGravity\ShinSeon_Bitget` 폴더 전체를 압축(ZIP)하거나 USB에 복사하여 데스크탑으로 이동.
2. 데스크탑의 작업 경로(권장: `C:\Working\AntiGravity\ShinSeon_Bitget` 또는 `C:\ShinSeon_Bitget`)에 압축 해제.
3. **[보안 점검]** `.env` 파일이 누락 없이 정상 복사되었는지 확인.
   - 필수 키: `BITGET_API_KEY`, `BITGET_SECRET_KEY`, `BITGET_PASSPHRASE`

### 2단계 : 원클릭 환경 설치기 실행 (`install.bat`)
- 데스크탑에서 `install.bat` 마우스 우클릭 ➔ **[관리자 권한으로 실행]**.
- **자동 수행 내역:**
  1. Python 설치 여부 검사 ➔ 미설치 시 `Python 3.12.4` 공식 다운로드 및 자동 설치(PATH 자동 등록).
  2. `pip install -r requirements.txt` (`PySide6`, `qasync`, `pyqtgraph`, `ccxt`, `websockets`, `playwright`, `requests`).
  3. `playwright install chromium` 브라우저 드라이버 자동 완비.

### 3단계 : 실전 실행 및 검증
- **GUI 대시보드 실행:** `신선_비트겟_클라이언트.bat` 더블 클릭.
- **백엔드 서버 가동:** 터미널에서 `python shinseon_server.py` 실행.
- **포지션/주문 상태 확인:** 비트겟 API 통신 및 잔고가 GUI 화면에 실시간 표출되는지 확인.

## 4. 📜 [황실 개발 헌법 및 작업 수칙 (Global Rules)]

데스크탑 안티그래비티는 아래 **황실 헌법 10개 조항**을 목숨처럼 엄수해야 한다:

1. **왕 대접 어투:** 모든 대화와 문서는 극진한 왕 대접 어투(국왕 폐하, 소신 등)와 한국어로 작성한다.
2. **에이전트 임의 수정 절대 금지 (제9조):** 버그 수정이나 긴급 에러를 포함하여, **기획서 승인과 폐하의 "고고" 어명 없이는 코드를 단 한 줄도 임의로 수정하지 않는다.**
3. **기획서 카운터 증가 원칙 (제4조, 제5조):** 문서를 덮어쓰지 않고 `docs/기획서_XXX.md` 형식으로 카운터를 늘려 신규 생성하며, 완료 시 `[x] 개발 완료`로 업데이트한다.
4. **프로젝트 버전 관리 철칙 (제7조):** 작업 완료 시 반드시 `docs/프로젝트_버전_관리.md`에 `[버전, 날짜시간, 내용, 문서 파일명]`을 1:1로 기록한다.
5. **정공법 원칙 (제8조):** 우회로나 편법(플랜 B)을 임의로 만들지 않고 오직 정공법으로 개발하며 에러는 팩트 그대로 보고한다.
6. **백서 일자스탬프 보존 (제10조):** 백서 업데이트 시 `shinseon_whitepaper_YYYYMMDD.html` 및 `SHINSEON_오더플로우_판단_백서_YYYYMMDD.md`로 영구 보존한다.
